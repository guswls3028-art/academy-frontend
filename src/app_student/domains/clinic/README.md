# 학생 앱 클리닉

학생이 자신의 미통과 항목을 확인하고, 열린 클리닉 날짜와 수업을 예약하며,
승인 상태와 예정 일정을 확인하는 도메인입니다. 수업 종료 시에는
  `/student/idcard` 패스카드로 현재 합격자·대상자·예약완료 상태를 교직원에게 보여줍니다.

## 사용자 흐름

시간 선택 예약(`time_range`)의 달력·카드는 서버 `is_full`을 따르며, 하루 누적 예약
인원으로 마감을 추정하지 않는다. 카드에는 `시간 선택`을 표시하고 선택 후 availability의
각 구간 잔여 정원·예약 간격·최대 체류에 따라 시작과 종료를 고른다. 목록의 잔여 정원을
전체 수업에 공통인 인원 수로 표시하지 않는다. 서버 요약을 아직 받지 못한 경우에도
선택 구간은 availability 응답과 최종 예약 API 검증을 통과해야 저장된다.
선택 요약은 수업 운영 시간이 아니라 선택한 실제 시작·종료와 이용 길이를 표시한다.
시작을 바꿔 종료 선택이 초기화되면 요약도 선택 안내로 돌아가며, 미선택 상태에서
수업 전체 운영 시간을 예약한 것처럼 표시하지 않는다.
고정 시간대의 기존 잔여 인원·연속 세션 선택은 유지한다.

회귀 검증: `e2e/student/clinic-booking-ux.mock.spec.ts`의 시간 범위 예약 사례.

1. `/student/clinic`의 **예약하기**에서 보강이 필요한 강의·차시·사유를
   먼저 확인합니다. 미해결 항목은 생성 시각이 최근인 것부터 전부 표시하며,
   원본 시험·과제명, 단원/범위, 차시를 내부 세로 스크롤로 확인합니다. 각 항목의
   **시험 확인·제출** 또는 **과제 온라인 제출**은 서버가 준 exact source ID로
   이동하며, 과제 링크는 해당 차시와 과제를 제출 화면에서 바로 선택합니다.
2. 향후 60일의 세션을 일요일부터 시작하는 7열·42칸 월간 달력으로 탐색합니다.
   **예약 가능**·**내 예약 수**·**마감** 표식과 오늘 윤곽을 색상 외의 점·숫자·
   테두리로도 구분합니다. 날짜를 선택하면 그날의 모든 시간대가 바로 아래에
   표시되며 숨김이나 **더 보기** 단계는 없습니다. 같은 날짜의 세션은 추천 여부와
   무관하게 13시·17시·19시처럼 시작 시간순을 유지합니다.
3. 대상 강의와 맞는 세션은 **내 보강과 맞음**으로 안내하되, 최종 예약
   가능 여부와 수강 연결은 백엔드가 결정합니다.
4. 같은 날짜에서 시작 시간대를 누르고 종료 시간대를 누르면 두 끝점을 포함한
   연속 예약 가능 시간대를 자동 선택합니다. 예를 들어 17시와 20시를 누르면
   17–18시, 18–19시, 19–20시가 함께 선택됩니다. 중간에 빈 시간, 마감·기예약,
   `allow_multi_slot_booking=false` 일정이 있으면 기존 선택을 유지하고 이유를
   설명합니다. 한 타임 선택, 다른 날짜로 선택 변경, 개별 정원·예약 행은 기존처럼
   유지됩니다.
5. 세션에서 `allow_time_preference`를 허용한 경우에만 학생이 세션 범위 안의
   희망 시작·종료 시간을 함께 요청할 수 있습니다. 이는 실제 세션 시간을 바꾸는
   예약 확정값이 아니며, 출처가 분명한 학생·학부모 요청
   `student_request_memo`와 함께 교직원이 검토합니다. 희망 시간은 시간대를
   하나만 선택했을 때만 입력할 수 있습니다.
6. 학생이 세션을 고르고 신청하면 학원 설정에 따라 `pending` 또는
   `booked`가 됩니다.
7. **내 일정**에서 `pending` 예약은 다른 날짜·시간으로 원자적으로
   변경하거나 취소할 수 있습니다. `booked` 변경·취소는 학원에 요청합니다.

## 상태와 API 소유권

- 대상 요약과 패스카드는 `GET /clinic/idcard/`를 함께 사용합니다. 패스카드는
  `current_result`, `passcard_state`, 서버 시각, 학원별 3색, 수강 강의와 차시
  이력을 표시하며 2초마다 갱신합니다. 예약 생성·변경·취소 성공 시 패스카드
  query도 즉시 무효화합니다.
- 예약 가능 세션: `GET /clinic/sessions/`
- 내 예약: `GET /clinic/participants/`
- 단일·다중 신청: `POST /clinic/participants/bulk-create/`의 `session_ids`
- 일정 변경: `POST /clinic/participants/{id}/change-booking/`
- 취소: `PATCH /clinic/participants/{id}/set_status/`
- 희망 시간: 신청·변경 payload의 `preferred_start_time` + `preferred_end_time`
- 학생·학부모 요청: 신청·변경 payload와 응답의 `student_request_memo`만 사용합니다.
  작성 주체가 불명확한 기존 `memo`는 학생 화면에서 읽거나 표시하지 않습니다.
- 교직원 내부 메모: `PATCH /clinic/participants/{id}/staff-memo/`이며 학생 응답에는
  `staff_memo`를 포함하지 않습니다.
- 예약·출석은 일정 상태이며 `ClinicLink`를 해소하지 않습니다. 시험·과제
  통과 또는 관리자 수동 처리만 미통과 대상을 해소합니다.
- 학생·학부모 요청은 현재 선택된 학생과 테넌트로 실패 폐쇄됩니다.

## 패스카드 운영 경계

- 학생은 퇴실할 때 **홈 → 클리닉 패스카드**로 바로 열 수 있습니다. 기존
  **더보기 → 클리닉 패스카드**와 직접 `/student/idcard` 진입도 유지됩니다.
- 관리자는 **클리닉 → 패스카드**에서 합격 화면의 3색과 매일 자동 변경 여부를
  설정합니다. 저장은 `PATCH /clinic/settings/`이며 현재 테넌트에만 적용됩니다.
- `PASSED`는 미해소 항목이 없는 **합격자** 상태입니다. 활성 예약이 별도로 있어도
  예약 상태와 가까운 예정 일정은 숨기지 않습니다.
- `CLINIC_REQUIRED`는 미해소 항목이 있고 확정 예약이 없는 **대상자** 상태로,
  검은색 경고 화면과 예약 진입점을 표시합니다.
- `BOOKING_CONFIRMED`는 미해소 항목은 유지되지만 오늘·미래 `booked` 예약 또는
  아직 수강완료 처리되지 않은 `attended`가 확인된 **예약완료** 상태입니다.
  대표 일정의 날짜·시작 시각·장소를 표시하고, 날짜가 지나도 `completed_at`이
  기록될 때까지 유지합니다. 수강완료 즉시 미해소 항목이 남으면
  `CLINIC_REQUIRED`, 모두 해소되었으면 `PASSED`가 됩니다.
  `cancelled`/`rejected`/`no_show`는 예약완료로 인정하지 않습니다.
- `pending`은 **승인 대기** 일정은 표시하지만 확정 예약이 아니며, 승인 전까지
  `CLINIC_REQUIRED`를 유지합니다.
- 패스카드의 학원 3색과 합격자·대상자·예약완료 상태 색상은 신원 확인용 표시이므로
  학생 앱의 라이트·다크 모드와 무관하게 동일하게 유지합니다.
- 관리자 화면의 학생 이름 노란 하이라이트도 패스카드 상태를 그대로 따릅니다.
  `CLINIC_REQUIRED`에서만 보이고 `BOOKING_CONFIRMED`와 `PASSED`에서는 꺼집니다.
  확정 예약은 학생의 모든 미해결 강의 하이라이트를 함께 해제하며, 수강완료 뒤
  과락이 남으면 패스카드와 동시에 다시 표시합니다.
- 판정값이 없거나 잘못된 응답은 합격으로 추정하지 않고 재시도 오류 화면으로
  실패 폐쇄합니다.
- 합격·대상 판정은 미해결 `ClinicLink`가 소유하고 예약은 이를 해소하지 않습니다.
  패스카드는 읽기 화면이며 예약·출석·미통과 데이터를 직접 변경하지 않습니다.

## 화면 상태와 반응형

- 로딩은 예약·세션 스켈레톤으로, 전체 조회 실패는 재시도 화면으로,
  대상 요약만 실패한 경우는 해당 카드 안에서 재시도합니다.
- 세션이 없으면 일정 개설 후 표시된다는 빈 상태를 제공합니다.
- 열린 일정 머리글은 예약 가능한 날짜 수와 전체 시간대 수를, 날짜표는 해당
  날짜의 수업 수를 함께 보여 줍니다. 날짜표 오른쪽의 시간 카드들은 개설
  시간·종료 시간·장소·잔여 정원 순으로 읽을 수 있습니다.
- 달력 날짜는 방향키 왼쪽·오른쪽으로 하루, 위·아래로 일주일 이동하고 Enter로
  선택합니다. 오늘은 `aria-current="date"`, 선택일은 `aria-pressed`, 예약 가능·
  내 예약·마감은 접근성 이름과 상태 속성으로도 전달합니다.
- 예약 입력 영역은 첫 화면에서 자동으로 펼치지 않으며, 학생이 원하는
  시간 카드를 선택한 경우에만 해당 날짜의 시간 카드 아래에 표시합니다.
  선택된 시간대는 개별 칩과 전체 이용 범위를 함께 표시합니다.
- 1366px 데스크톱과 390px 모바일에서 달력·날짜표·시간·장소·상태·행동 버튼이
  가로로 넘치지 않아야
  하며, 보강 항목이 많아도 페이지 가로 폭은 늘어나지 않아야 합니다. 키보드
  포커스와 `prefers-reduced-motion`을 지원합니다.
- 패스카드는 라이트·다크 모드에서 배경, 판정, 예약, 차시 영역의 계산 색상이
  동일해야 합니다.
