# 다원 클리닉 신청 관리

원장은 클리닉에서 전체 신청을, 강사는 클리닉 운영의 신청 탭에서 담당 반의 신청을 봅니다. 반·처리 상태·학생 이름으로 검색하고 25건씩 이동합니다. 상세를 닫으면 조회 조건이 유지됩니다. 강사의 첫 화면은 승인 대기 목록입니다.

상세에 예약 승인·신청 반려가 표시되면 기존 클리닉 예약 API로 처리합니다. 처리한 상태는 학생 신청 내역에도 표시됩니다. 같은 신청을 동시에 처리하면 먼저 저장한 상태가 유지되며 다음 처리자는 오류 메시지와 최신 상태를 확인할 수 있습니다. 목록은 열려 있는 동안 15초마다 갱신됩니다.

검증은 격리된 다원 예시 학생의 신청을 사용합니다. 학생 신청 → 담당 강사 또는 원장 처리 → 학생 내역 재조회와 담당 밖 반 조회 거부를 확인합니다. 서버 범위는 backend/docs/domain/clinic-booking.md에 있습니다.
