# 교직원 게시판

모든 학원의 관리자 사이드바와 모바일 메뉴에서 **교직원 게시판**을 연다. 현재 학원의 원장·관리자·강사·조교가 공지사항, 자료실, 자유게시글에 글과 댓글을 쓸 수 있다. 학생·학부모와 소통하는 기존 커뮤니티는 별도로 운영한다.

대시보드의 **학원 내부 공지**는 최신 세 건의 제목과 작성일을 보여 준다. 제목을 누르면 본문과 댓글이 열리고, **전체 보기**로 공지 목록을 연다. 간편 업무 홈에서도 같은 공지를 읽을 수 있다. 대시보드를 열어 두면 1분마다 새 공지를 확인한다.

게시판 주소는 `/workspace/staff-board`이고 분류는 `notice`, `resource`, `free`이다. 각 글에 다시 열 수 있는 고유 주소가 있다. 목록은 최신순으로 20건씩 표시한다. 자료실 글에는 10 MiB 이하 파일 한 개를 첨부할 수 있다. 본인이 쓴 글은 상세 화면에서 제목과 내용을 수정할 수 있다. 파일을 잘못 올렸으면 작성자나 원장·관리자가 상세 화면에서 제거한다. 확인을 거치면 새 다운로드가 차단되며 글과 댓글은 계속 읽을 수 있다. 권한과 저장소 정리 흐름은 백엔드에서 관리한다. [교직원 게시판 API](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/staff-board.md)

목록과 공지 영역은 불러오는 중, 빈 목록, 오류를 구분한다. 조회 실패는 해당 영역에서 다시 시도한다. 글·댓글 등록 실패 시 입력을 보존하며 같은 내용을 다시 제출할 때 기존 등록 결과를 사용한다. 다운로드는 교직원 인증을 거쳐 파일을 받고, 실패하면 상세 화면에 재시도 안내를 표시한다. 작성 중 취소하면 계속 작성하거나 변경을 버릴 수 있다. 작은 화면에서는 작성자와 날짜를 제목 아래에 표시하며 모션 감소 설정을 따른다.

격리 개발 환경의 `board-attachments-realuse.spec.ts`에서 사이드바 진입, 교직원 글 등록·수정, 조교 댓글, 대시보드에서 상세 열기, 글·댓글 중복 방지, 원본 다운로드, 학생 접근 거절과 첨부 제거 후 재조회·다운로드 거절을 확인한다. 대시보드 및 공지 상세의 캡처 폭은 1366·1100·390px이다. 게시글·댓글·자료는 시나리오 전용 학원의 정리 범위에 포함된다.
