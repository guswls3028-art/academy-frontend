# 교직원 게시판

모든 학원의 관리자 사이드바와 모바일 메뉴에서 **교직원 게시판**을 연다. 현재 학원의 원장·관리자·강사·조교가 공지사항, 자료실, 자유게시글에 글과 댓글을 쓸 수 있다. 학생·학부모와 소통하는 기존 커뮤니티는 별도로 운영한다.

게시판에 들어가면 **전체 글**에서 세 분류의 글을 최신순으로 읽고 한 번에 검색한다. PC에서는 제목·게시판·작성자·작성일을 열로 나란히 비교한다. 제목 옆에 댓글 수, 제목 아래에 첨부 파일명이 표시된다. 행을 누르면 상세가 열린다. 검색창과 **글쓰기**는 목록 상단 한 줄에 있다. 전체 글에서 글쓰기를 누르면 자유게시글로 시작하며 작성 창에서 공지사항이나 자료실을 선택할 수 있다. 분류 탭에서 작성할 때는 해당 분류가 적용된다. 전체 목록과 상세는 `/all`과 `/all/{id}` 경로를 사용하고 기존 분류별 주소와 대시보드 공지 링크도 계속 열린다.

상세 화면에서 작성자는 자신의 글과 댓글을 수정·삭제할 수 있다. 원장과 관리자는 같은 학원 글과 댓글을 삭제할 수 있다. 삭제 전 확인창에 대상과 영향이 표시된다. 글을 삭제하면 댓글과 첨부파일도 게시판에서 접근할 수 없고 목록으로 돌아간다. 댓글을 삭제하면 상세와 목록의 댓글 수가 갱신된다. 작성자 계정 기록이 없는 기존 댓글은 읽을 수 있으며 원장·관리자가 삭제할 수 있다. 댓글 수정에 실패하면 입력한 내용을 유지해 다시 저장할 수 있다.

대시보드의 **학원 내부 공지**는 최신 세 건의 제목과 작성일을 보여 준다. 제목을 누르면 본문과 댓글이 열리고, **전체 보기**로 공지 목록을 연다. 간편 업무 홈에서 공지를 누르거나 메뉴의 **오늘 업무 → 교직원 게시판**을 선택하면 간편 업무 게시판이 열린다. 글을 읽거나 작성해도 하단 메뉴가 유지되며 대시보드로 돌아갈 수 있다. 대시보드를 열어 두면 1분마다 새 공지를 확인한다.

전체 업무 게시판 주소는 `/workspace/staff-board`, 간편 업무 게시판 주소는 `/workspace/mobile/staff-board`다. 분류는 `notice`, `resource`, `free`이다. 각 글에 다시 열 수 있는 고유 주소가 있다. 목록은 최신순으로 20건씩 표시한다. 현재 분류에서 제목·본문·첨부 파일명을 검색할 수 있다. 검색어는 100자까지 입력하며, **검색**을 누르면 전체 페이지에서 일치하는 글을 찾는다. 상세의 **목록**이나 브라우저의 뒤로 가기로 돌아오면 검색어와 페이지가 유지된다. 읽던 글이 결과에 남아 있으면 해당 행을 강조하고 제목에 키보드 초점을 돌려준다. 결과가 없으면 검색어를 바꾸거나 **검색 초기화**로 전체 목록을 연다.

공지사항은 **공지 작성**, 자료실은 **자료 올리기**, 자유게시글은 **글쓰기**로 작성한다. 자료실 작성 창 상단에서 10 MiB 이하 파일 한 개를 첨부할 수 있다. 자료 상세에서는 본문 위에서 파일을 내려받을 수 있다. 본인이 쓴 글은 상세 화면에서 제목과 내용을 수정할 수 있다. 파일을 잘못 올렸으면 작성자나 원장·관리자가 상세 화면에서 제거한다. 확인을 거치면 새 다운로드가 차단되며 글과 댓글은 계속 읽을 수 있다. 권한과 저장소 정리 흐름은 백엔드에서 관리한다. [교직원 게시판 API](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/staff-board.md)

목록과 공지 영역은 불러오는 중, 빈 목록, 오류를 구분한다. 조회 실패는 해당 영역에서 다시 시도한다. 글·댓글 등록 실패 시 입력을 보존하며 같은 내용을 다시 제출할 때 기존 등록 결과를 사용한다. 다운로드는 교직원 인증을 거쳐 파일을 받고, 실패하면 상세 화면에 재시도 안내를 표시한다. 작성 중 취소하면 계속 작성하거나 변경을 버릴 수 있다. 작은 화면에서는 제목과 파일명 아래에 분류·작성자·작성일을 묶어 가로 스크롤 없이 읽을 수 있다. 화면 전환은 모션 감소 설정을 따른다.

`workspace-quick-navigation.mock.spec.ts`는 1366·1100·390px에서 검색 결과 두 번째 페이지의 작성자와 게시판을 확인하고, 댓글 읽기·파일 다운로드·제목 수정 후 같은 행으로 돌아오는 흐름을 검증한다. PC에서는 표 머리글·행 높이·검색창과 작성 버튼 배치를 확인하고 세 너비에서 복귀 화면을 캡처한다.

격리 개발 환경의 `board-attachments-realuse.spec.ts`는 관리자 사이드바와 390px 조교 간편 업무 메뉴에서 각각 게시판으로 진입한다. 관리자 글 등록·검색·수정 후 목록 복귀, 조교가 등록한 댓글의 새로고침과 관리자 화면 반영, 파일명 검색·빈 결과·초기화, 원본 다운로드, 학생 접근 거절, 첨부 제거 후 재조회·다운로드 거절을 검증한다. 대시보드와 상세는 1366·1100·390px에서, 조교 간편 업무와 파일명 검색은 390px에서 가로 넘침을 검사하고 `board-layout-staff-board-*.png`로 캡처한다. 게시글·댓글·자료는 시나리오 전용 학원의 정리 범위에 포함된다.
