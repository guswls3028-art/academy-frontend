# 학생 성적표 구성 계약

학생과 학부모가 성적 보드에서 시험 결과와 교사의 오답 확인 상태를 놓치지 않고,
각 학원은 성장 그래프에 필요한 정보만 원하는 순서로 제공하기 위한 현재 계약이다.
백엔드 상태·저장 정책은 `backend/docs/domain/student-grade-report.md`를 따른다.

## 사용자 흐름

### 학원 관리자

1. 관리자 또는 교사 모바일 앱의 **설정 → 학원 정보 → 학생 성적표**로 이동한다.
2. 각 섹션의 눈 아이콘으로 표시/숨김을 바꾸고 위·아래 버튼으로 순서를 조정한다.
   **성적 비교 요약 항목**에서는 평균 득점률, 통과율, 상태를 각각 켜거나 끈다.
3. 오른쪽 또는 하단의 **학생 화면 미리보기**에서 실제 노출 순서를 확인한다.
4. **구성 저장**을 누르면 같은 학원의 모든 학생·학부모 성장 그래프에 반영된다.
5. **전체 표시로 되돌리기**는 초안만 전체 표시·기본 순서로 바꾸며, 저장 전에는
   학생 화면을 변경하지 않는다.

설정은 학원 전체 공개 정책이므로 같은 테넌트의 `owner`와 `admin`만 변경한다.
일반 교사·직원, 학생, 학부모는 설정 API에 접근할 수 없다. 한 섹션도 표시하지 않는
초안은 저장할 수 없으며 이유를 화면에 표시한다.

### 학생·학부모

- **성적 보드 → 시험 성적** 카드의 오답 정보 옆에 `오답 완료` 또는
  `오답 미완료` 배지를 표시한다.
- 시험 성적 상단의 `전체·확인 필요·처리됨` 필터로 후속 확인이 남은 시험만 모아보고,
  시험 상세에서도 동일한 `테스트 오답` 상태와 다음 행동 안내를 확인한다.
- 이 배지는 점수나 오답 개수로 프론트엔드가 추측하지 않고, 교사가 차시 성적표에서
  저장한 백엔드 `correction_status`를 그대로 사용한다.
- 만점이라 별도 확인이 필요 없거나 시험의 차시를 안전하게 하나로 확정할 수 없으면
  완료/미완료 배지를 표시하지 않는다.
- 교사가 완료한 뒤 실제 점수나 답안이 바뀌면 서버가 다시 미완료로 판정한다.
- 시험 원점수가 합격 기준보다 낮아도 교사가 현장 해결을 확인한 최종 상태는 원점수를
  그대로 표시하면서 `보강/교사 통과` 완료로 읽고 재시험 필요·미통과 통계에서 제외한다.
- 과제는 점수·제출 여부와 독립적인 `teacher_resolved`를 읽는다. 점수 없는 미제출
  과제도 교사가 완료한 경우 원래 `–/만점` 표기를 유지하면서 초록색 **교사 확인 완료**
  배지를 표시하고, `확인 필요`/재제출 대상/미통과 대시보드에서는 제외한다. 교사가
  해제하면 현재 점수·제출 상태가 다시 보인다.
- 교사 사유·완료 시각은 학생·학부모에게 노출하지 않는다. 학부모는 선택한 자녀의
  같은 `/student/grades/` 응답을 사용하므로 다른 자녀 상태를 추정하거나 합치지 않는다.
- **추이 분석**은 `report_layout.sections`의 순서와 `visible` 값을 따른다. 응답이 없거나
  오래된 형식이면 기존과 같은 전체 표시 기본값을 사용한다.
- 시험 설정에서 학생 성적이 비공개인 시험은 카드·추이·분석에 포함하지 않는다. 시험
  화면에서는 점수 대신 **성적 공개 전** 안내를 표시하고, 교직원이 다시 공개하면 기존
  저장 결과를 그대로 확인한다.
- 시험 등수와 상위 비율은 1차 점수 기준의 표준 공동 순위를 사용한다. 동점자는 같은
  등수이고 다음 등수는 동점 인원만큼 건너뛰며(`1, 2, 2, 4`), 프론트엔드는 서버가
  계산한 값을 다시 매기지 않는다.
- 학생용 **회차별 성적 추이**는 여러 강좌의 결과를 `전체`로 합치지 않는다. 학생의 활성
  수강 강좌가 하나면 드롭다운 대신 현재 강좌 티켓을 표시하고, 둘 이상이면 첫 강좌부터
  폭이 제한된 선택 상자에 표시한다. 긴 강좌명은 한 줄에서 말줄임하고, 브라우저의 세로
  강좌 목록에서는 강좌 딱지와 전체 이름으로 전환한다. 선택한 강좌에 점수가 없으면 해당
  강좌의 빈 상태를 유지한다. 지표는 `등수 → 상위 % → 득점률` 순이며, 선택 강좌에 석차
  데이터가 없으면 득점률로 안전하게 전환한다. 관리자·교사의 전체 강좌 분석 필터는
  기존대로 유지한다.

## 섹션 경계

| ID | 화면 이름 | 포함 정보 |
|---|---|---|
| `score_trend` | 회차별 성적 추이 | 점수·등수·상위 비율 누적 그래프 |
| `score_comparison` | 성적 비교 | 선택한 평균·통과율·상태 요약과 전체 평균 비교 그래프 |
| `lecture_average` | 강좌별 평균 | 강좌별 평균 득점률 |
| `improvement_priority` | 보완 우선순위 | 반복 오답, 최근/약점 시험, 자동 해석 문구 |
| `exam_summary` | 시험 성적 요약 | 평균, 합격률, 시험 수, 평균 등수 |
| `rank_position` | 내 위치 분석 | 상·중·하위권 횟수와 최고/보완 시험 |
| `weakest_lecture` | 약점 강좌 | 낮은 평균 강좌 안내 |
| `homework_summary` | 과제 현황 | 채점, 평균 득점률, 합격률 |

`score_comparison_metrics`의 `average_score`, `pass_rate`, `status`가 성적 비교 상단
요약 항목을 각각 제어한다. 과거 응답에 이 값이 없으면 세 항목을 모두 표시한다.

YMath의 초기 구성은 `score_trend`, `score_comparison`, `lecture_average`만 표시하고,
성적 비교에서는 평균 득점률만 유지하며 통과율과 상태를 숨긴다.
이는 프론트엔드 도메인 분기가 아니라 저장된 학원 설정이므로 관리자가 언제든 바꿀 수
있다. 다른 학원은 기존과 같이 모든 섹션을 표시한다.

## 상태와 실패 처리

- 설정 조회 중에는 로딩 안내, 실패 시에는 같은 자리의 재시도 버튼을 표시한다.
- 저장 중에는 중복 저장을 막고, 성공/실패 결과를 토스트로 알린다.
- 미저장 초안이 있으면 포커스 복귀나 백그라운드 재조회가 편집 내용을 덮지 않는다.
- 분석 기반 섹션을 모두 숨긴 구성은 분석 API를 호출하지 않는다.
- 합격/불합격 라벨이 빈 문자열인 구설정은 기본 문구 `합격`/`불합격`으로 보완한다.
- 분석 API가 실패해도 회차별 성적과 다른 독립 섹션은 유지한다.
- 저장하지 않은 편집 초안은 브라우저를 벗어나면 폐기되며 서버 설정을 바꾸지 않는다.
- 모바일 390px에서는 섹션 목록과 미리보기를 세로로 배치하고, 가로 스크롤을 만들지
  않는다. 순서 버튼과 표시 스위치는 키보드 포커스와 접근성 이름을 제공한다.
- 학생의 강좌가 둘 이상일 때만 선택 상자가 모바일 터치 크기와 키보드 포커스를 제공하고,
  하나면 현재 강좌를 비상호작용 티켓으로 명확히 표시한다. 선택한 강좌의 회차·요약·그래프만
  표시한다. API가 활성 강좌 목록을 제공하지 않는 구버전 호환 상황은
  공개된 추이 데이터의 강좌만 복구하되 `전체` 항목을 만들지 않는다.
- 활성 강좌가 있으면 `등수 → 상위 % → 득점률` 지표 탭을 항상 같은 순서로 유지한다.
  선택 강좌에 석차가 없으면 등수와 상위 %를 비활성화하고, 응시 인원 조건을 모바일에서도
  바로 읽을 수 있는 문장으로 안내하며 득점률을 표시한다.
