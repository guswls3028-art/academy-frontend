# 학생 사용 가이드

---

## 1. 시작하기

### 1-1. 가입하기

**선생님이 등록한 경우:**
- 학생 명부에만 등록된 동안에는 알림톡이 오지 않습니다
- 실제 강의의 수강생으로 처음 확정되면 카카오톡으로 계정 안내 알림톡이 옵니다
- 알림톡에 **아이디**, **비밀번호**, **접속 링크**가 적혀 있습니다
- 링크를 눌러서 바로 로그인할 수 있습니다

**직접 가입하는 경우:**
1. 학원 앱 주소에 접속합니다
2. **회원가입** 버튼을 누릅니다
3. 이름, 전화번호, 비밀번호를 입력합니다
4. 선생님이 승인하면 로그인할 수 있습니다
5. 승인만으로는 알림이 오지 않으며, 실제 강의의 수강생으로 처음 확정되면 카카오톡으로 계정 안내가 옵니다

> 💡 학부모 계정도 함께 만들어집니다. 학부모 아이디는 **학부모 전화번호**이며, 신규 학부모 계정의 초기 비밀번호는 전화번호 **뒤 4자리**입니다. 이미 있는 학부모 계정은 비밀번호가 변경되지 않습니다.

### 1-2. 로그인
1. 학원 앱 주소에 접속합니다
2. **로그인** 버튼을 누릅니다
3. 아이디와 비밀번호를 입력합니다
4. **로그인**을 누르면 홈 화면이 나타납니다

### 1-3. 비밀번호를 잊었을 때
1. 로그인 화면에서 **비밀번호 찾기**를 누릅니다
2. 등록된 전화번호를 입력합니다
3. 카카오톡으로 **인증번호**가 옵니다 (10분 이내 입력)
4. 인증 후 **임시 비밀번호**가 카카오톡으로 전송됩니다
5. 임시 비밀번호로 로그인한 후 반드시 비밀번호를 변경하세요

## 2. 홈 화면

로그인하면 가장 먼저 보이는 화면입니다.

### 화면 구성

**위쪽:**
- 📢 **공지사항** — 학원 공지 미리보기 (터치하면 전체 보기)

**가운데:**
- ⚡ **오늘 할 일** (해당되는 경우만 표시)
  - 불합격한 과제가 있으면 "과제 미완료 N건" 표시
  - 재시험이 필요하면 "재시험 N건" 표시
  - 클리닉 예약이 있으면 표시

**아래쪽: 빠른 메뉴 (8개 타일)**

| 메뉴 | 설명 |
|------|------|
| ⭐ 성적 | 내 시험·과제 성적 확인하기 |
| 📝 시험 | 시험 목록 보기 / 응시하기 |
| 📤 과제 | 과제 제출하기 |
| 🏥 클리닉 | 보충 수업 예약하기 |
| ✅ 출결 | 내 출결 기록 확인하기 |
| 📢 공지 | 학원 공지 확인하기 |
| 📦 보관함 | 내 파일 관리 |
| 🎫 클리닉 패스카드 | 수업 종료 시 선생님께 바로 보여주기 |

빠른 메뉴의 **내 정보** 타일은 패스카드 바로가기로 바뀌지만, 내 정보 기능은
상단 **프로필 메뉴 → 내 정보** 또는 **더보기 → 프로필**에서 계속 열 수 있습니다.

**하단 탭바 (항상 표시):**

| 🏠 홈 | ▶ 영상 | 📅 일정 | 🔔 알림 | 💬 커뮤니티 |
|--------|--------|--------|--------|------------|

## 3. 영상 보기

### 3-1. 영상 찾기

**하단 탭 → 영상**

1. 수강 중인 강의가 카드로 표시됩니다
   - 각 카드: 강의명, 영상 수, 총 재생 시간
   - 카드 위 **강의 공지**에서 수강 중인 강의의 공지를 한 번에 확인합니다
2. 강의 카드를 터치합니다
3. 차시(수업) 목록이 나타납니다
   - 각 차시: 제목, 영상 수, 시간
   - **이 강의 공지**를 터치하면 선택한 강의의 공지만 모아 볼 수 있습니다
4. 차시를 터치하면 영상 목록이 나옵니다
5. 영상을 터치하면 재생이 시작됩니다
- YouTube 링크 영상은 썸네일과 목록에 **YouTube 링크**로 표시됩니다
- 같은 제목 뒤에 `- 1`, `- 2`, `- 3`처럼 번호가 붙은 영상은 번호 순서대로 정렬됩니다

### 3-2. 영상 시청

- **재생/일시정지**: 화면을 터치합니다
- **이어보기**: 지난번에 본 위치에서 자동으로 이어서 재생됩니다
- **10초 건너뛰기**: 기본 제한 영상은 `+10초` 버튼이나 화면 오른쪽 두 번 터치로
  앞으로 이동할 수 있습니다. 영상마다 재생 시간의 20%까지 사용할 수 있고, 긴
  영상도 최대 30분까지만 가능합니다. 화면에 남은 시간이 표시되며 새로고침하거나
  다른 기기로 바꿔도 초기화되지 않습니다
- **뒤로 이동**: `-10초` 버튼이나 화면 왼쪽 두 번 터치로 제한 없이 다시 볼 수
  있습니다. 제한 영상의 재생 막대를 끌어 임의로 앞으로 이동할 수는 없습니다
- **YouTube 링크**: 일반 영상과 같은 화면에서 재생되며, YouTube 제공 자막/화면 정보가 함께 보일 수 있습니다
- **좋아요**: ❤️ 버튼으로 좋아요를 누를 수 있습니다
- **댓글**: 영상 아래에서 댓글을 남길 수 있습니다
- **다음 영상**: 영상이 끝나면 다음 영상으로 자동 전환 카운트다운이 나옵니다

> 💡 영상 시청 기록은 자동으로 저장됩니다. 다시 들어오면 멈춘 위치부터 재생됩니다.
> 영상 길이를 확인할 수 없거나 사용할 수 있는 시간을 모두 쓴 경우 `+10초` 버튼이
> 비활성화되고 이유가 화면에 표시됩니다.

## 4. 일정 확인

### 4-1. 달력

**하단 탭 → 일정**

- 수업이 있는 날짜에 **색상 점**이 표시됩니다
  - 🟢 초록: 예정된 수업
  - 🟡 노랑: 진행 중인 수업
  - ⚫ 회색: 지난 수업
- 날짜를 터치하면 그 날의 수업 목록이 아래에 나타납니다

### 4-2. 수업 상세

수업 항목을 터치하면 상세 페이지가 열립니다.

**이동할 수 있는 곳:**
- **영상 보기**: "이 수업의 영상을 볼 수 있어요" → 해당 차시 영상 목록으로 이동
- **시험 보기**: 해당 차시의 시험으로 이동 (시험이 있는 경우)
  - 시험이 1개면 "시험 보기"
  - 시험이 여러 개면 "1차 시험", "2차 시험" 등으로 표시
- **과제 제출**: 과제 제출 페이지로 이동
- **성적 보기**: 성적 확인 페이지로 이동

## 5. 시험

### 5-1. 시험 목록

**홈 → 시험** 또는 **더보기 → 시험**

시험 목록 서버가 일시적으로 응답하지 않으면 한 번 자동 재시도한 뒤 빈 화면으로
남지 않고 **시험을 불러오지 못했습니다**와 **다시 시도**를 표시합니다. 권한·입력
오류는 자동 반복하지 않습니다.

| 표시 색상 | 의미 |
|----------|------|
| 🔴 빨간색 | 마감이 24시간 이내! 서둘러 응시하세요 |
| 🔵 파란색 | 응시 가능 (여유 있음) |
| ⚫ 회색 | 아직 열리지 않았거나 이미 마감 |

### 5-2. 시험 응시

1. 시험을 터치합니다
2. **시험 보기** 버튼을 누릅니다
3. 문항별로 답을 입력합니다
   - 객관식: 1~5번 중 선택
   - 수학 숫자 단답형: `0~999` 사이의 정수 입력
   - 그 외 주관식: 답을 직접 입력
4. **제출하기**를 누릅니다
5. 확인 팝업:
   - 안 푼 문항이 있으면 "X개 문항 미응답" 안내
   - **제출**을 누르면 완료

> 💡 **중간 저장**: 답을 입력하면 자동으로 저장됩니다. 실수로 나갔다가 다시 들어와도 이전 답이 그대로 있습니다.

> ⚠️ 한 번 제출하면 수정할 수 없습니다. 제출 전에 꼭 확인하세요!

### 5-3. 시험 결과

제출 후 자동으로 결과가 표시됩니다:

- **점수**: 받은 점수 / 총점 (예: 85 / 100)
- **합격 여부**: 합격 ✅ 또는 불합격 ❌
- **문항별 결과** (선생님이 공개한 경우):
  - 내 답, 정답, 맞음/틀림
  - 선생님이 비공개로 설정했으면 "정답은 비공개입니다" 표시

### 5-4. 재시험

- 불합격이고 선생님이 재시험을 허용했으면 **재시험 보기** 버튼이 나타납니다
- 재시험은 처음부터 다시 응시합니다
- 최대 응시 횟수가 정해져 있을 수 있습니다

### 5-5. ⭐ 시험과 클리닉의 관계

**이 부분이 중요합니다!**

```
시험에서 불합격 → 자동으로 "클리닉 대상자"가 됨
    ↓
클리닉 예약 → 보충 수업 참석 → 재시험/과제 통과
    ↓
클리닉 대상 해소
```

**클리닉 대상이 되는 경우:**
- 시험 점수가 합격점보다 낮을 때 (예: 합격점 60점인데 40점 받음)
- OMR 답안지의 마킹이 불분명할 때
- 같은 문제를 여러 번 응시해도 계속 틀릴 때
- 수업 영상을 충분히 보지 않았을 때 (90% 미만)

**클리닉 대상이 되면:**
- 홈 화면에 "클리닉 대상" 알림이 표시됩니다
- 클리닉 패스카드에 "클리닉 예약 대상자"가 표시됩니다
- 클리닉 예약 화면에 보강이 필요한 강의·차시·사유가 표시됩니다
- 해당 강의와 맞는 일정에는 **내 보강과 맞음**이 표시됩니다

**중요:** 예약이나 출석 기록만으로 시험·과제 미통과가 사라지지는 않습니다.
재시험 또는 과제를 통과하거나 선생님이 통과/면제 처리하면 대상에서 해제됩니다.

## 6. 성적 확인

**홈 → 성적** 또는 **더보기 → 성적**

### 6-1. 시험 성적
- 선생님이 공개한 시험 결과가 표시됩니다
- 각 시험: 시험명, 강의명, 점수, 합격/불합격 배지
- 시험을 터치하면 문항별 상세 결과를 볼 수 있습니다
- 아직 공개하지 않은 시험은 점수 대신 **성적 공개 전**으로 안내되며, 공개 뒤 같은
  화면에서 기존 결과를 확인할 수 있습니다

### 6-2. 과제 성적
- 아래쪽에 과제별 점수가 표시됩니다
- 합격/불합격 상태 확인

### 6-3. 정답 확인
- 선생님이 **정답 공개**로 설정한 시험만 정답을 볼 수 있습니다
- 비공개 시험은 점수만 보이고 "정답은 비공개입니다" 메시지가 표시됩니다

### 6-4. 회차별 성적 추이
- **통계** 탭에서 현재 수강 중인 강좌를 선택해 등수, 상위 %, 득점률의 회차별
  흐름을 확인합니다
- 최근·누적·평균·최고 값과 **직전 대비**는 표시하지만, 수업 성격에 따라
  의미가 달라질 수 있는 **첫 회차 대비**는 학생 화면에 표시하지 않습니다
- 이 표시 변경은 기존 점수와 회차 데이터를 삭제하거나 바꾸지 않으며, 교직원의
  학생 상담용 성적 추이 화면에는 첫 회차 대비가 계속 표시됩니다
- 성적 추이를 불러오지 못해도 시험·과제 성적은 계속 확인할 수 있고, 아직 점수가
  없는 강좌는 빈 상태로 안내됩니다

## 7. 과제/성적표 제출

**홈 → 제출** 또는 **더보기 → 제출**

### 7-1. 성적표 제출
1. **성적표 제출** 선택
2. 시험 종류를 **학교 내신 / 전국연합학력평가 / 평가원 모의평가** 중에서 선택합니다
3. 학년도와 시험 시기, 과목, 받은 점수와 만점을 입력합니다
   - 학교 내신: 1·2학기, 1차 지필평가(중간고사) 또는 2차 지필평가(기말고사)
   - 전국연합학력평가: 시험을 본 월
   - 평가원 모의평가: 해당 연도 성적표에 기재된 실제 시행 월
   - 학교 성적의 등급을 입력할 때는 성적표에 적힌 5등급제/9등급제를 먼저 선택합니다. 성취도, 과목 평균, 표준편차, 수강자 수는 성적표에 있을 때만 입력합니다
   - 모의고사의 등급, 표준점수, 백분위도 성적표에 있을 때만 입력합니다
   - 과목별 변화가 정확히 이어지도록 한 번에 한 과목씩 제출합니다
4. 이름과 점수가 보이는 성적표 사진 또는 PDF를 선택합니다
5. **성적표 보내기**를 누릅니다
6. 최근 제출에서 **확인 대기 / 반영 완료 / 반영 보류** 상태를 확인합니다

> 학생이 입력한 점수는 바로 통계에 들어가지 않습니다. 선생님이 성적표 원본과
> 입력값을 확인한 뒤 승인한 성적만 누적 성적에 반영됩니다.

### 7-2. 과제 제출
1. **과제 제출** 선택
2. 사진이나 영상 파일을 선택합니다
3. **제출** 버튼을 누릅니다

### 7-3. 내 보관함
- 제출한 모든 파일이 보관됩니다
- 폴더를 만들어 정리할 수 있습니다
- 파일 업로드, 다운로드, 삭제 가능 (검수 기록과 연결된 성적표 원본은 삭제할 수 없음)
- 최대 파일 크기: 100MB

## 8. 클리닉 (보충 수업)

### 8-1. 클리닉이란?

클리닉은 **시험에서 불합격하거나 학습이 부족한 학생을 위한 보충 수업**입니다.

**흐름:**
```
시험 불합격 → 클리닉 대상자로 자동 지정
    ↓
클리닉 세션 확인 → 예약 → 보충 수업 참석
    ↓
클리닉 완료 → 다음 단계로 진행
```

### 8-2. 예약하기

**홈 → 클리닉** 또는 **더보기 → 클리닉**

**예약하기 탭:**
1. **열린 일정**에서 학원이 실제로 개설한 날짜를 확인합니다
   - 월/일과 요일이 큰 날짜표로 표시됩니다
   - 빈 날짜는 나오지 않습니다
2. 같은 날짜 아래에서 원하는 수업을 선택합니다
   - 시간, 제목, 장소, 대상 강의, 잔여 인원 표시
   - 내 미통과 강의와 맞는 일정에는 **내 보강과 맞음** 표시
   - "정원 마감" 또는 이미 신청한 일정은 다시 선택할 수 없습니다
3. 일정에 **학생 희망 시간 받기**가 켜져 있으면 일정 안의 희망 시작·종료 시간을
   함께 입력할 수 있습니다 (선택)
   - 예: 운영시간 17:00~22:00 안에서 희망시간 19:00~21:00
   - 희망 시간은 요청사항이며 실제 예약 시간은 선생님이 최종 배정합니다
4. 요청사항을 입력할 수 있습니다 (선택)
   - 예: "7시에 국어 학원이 있어요", "8시까지 끝내주세요"
5. **이 일정 예약하기** 버튼을 누릅니다

**예약 후:**
- 학원 설정에 따라 즉시 확정되거나, 선생님 승인 후 확정됩니다
- 확정되면 **내 일정** 탭에서 확인할 수 있습니다

> ⚠️ **같은 세션에 중복 예약은 불가능합니다.** 이미 예약했다면 "이미 예약된 학생입니다" 메시지가 표시됩니다.

> ⚠️ **정원이 찼으면 예약할 수 없습니다.** 다른 시간대를 선택하세요.

### 8-3. 내 일정 확인

**클리닉 → 내 일정 탭**

| 상태 | 의미 | 취소 가능? |
|------|------|-----------|
| 대기 중 | 선생님 승인 전 | ✅ 변경·취소 가능 |
| 확정됨 | 승인 완료, 참석 예정 | ❌ 선생님에게 요청 |

- 대기 중인 예약: **일정 바꾸기**로 다른 날짜·시간을 안전하게 선택하거나 **예약 취소** 가능
- 일정 변경에 실패하면 기존 예약은 그대로 유지됩니다
- 확정된 예약: 직접 취소 불가 → 선생님에게 요청
- 입력한 희망 시간과 요청사항은 **내 일정**에서 함께 확인할 수 있습니다

### 8-4. 클리닉 패스카드

**홈 → 클리닉 패스카드** (또는 **더보기 → 클리닉 패스카드**)

- 수업이 끝나면 패스카드를 열어 선생님에게 보여주세요
- LIVE 표시와 시계가 매초 움직이므로 캡처 화면과 구분할 수 있습니다
- **합격**이면 학원에서 지정한 3색 화면이, 미통과 항목이 있으면
  **클리닉 예약 대상자** 화면이 표시됩니다
- 대상 화면의 **클리닉 일정 예약하기**를 누르면 예약 화면으로 이동합니다

### 8-5. 클리닉 요건 해소 규칙 (중요!)

| 상황 | 클리닉 대상 상태 |
|------|-----------------|
| 시험 불합격 | ❌ 클리닉 대상이 됨 |
| 클리닉 예약/출석 | ❌ 대상 유지 (일정·출석 기록) |
| 재시험 통과 | ✅ 시험 대상 해소 |
| 과제 통과 | ✅ 과제 대상 해소 |
| 선생님 수동 통과/면제 | ✅ 대상 해소 |

## 9. 커뮤니티

**하단 탭 → 커뮤니티**

5개 탭으로 구성:

### 9-1. 공지사항
- 학원 공지를 확인합니다
- 전체공지 / 강의별 공지 / 차시별 공지로 구분
- 영상의 **강의 공지**에서는 모든 강의 공지로, 강의 상세의 **이 강의 공지**에서는 해당 강의 공지만 바로 열립니다
- 터치하면 전체 내용을 볼 수 있습니다

### 9-2. 게시판
- 자유 게시판 글을 읽을 수 있습니다

### 9-3. 자료실
- 학습 자료(PDF, 이미지 등)를 다운로드합니다

### 9-4. QnA (질문하기)
1. **QnA** 탭으로 이동합니다
2. **질문하기** 버튼을 누릅니다
3. 제목과 내용을 입력합니다
   - 글꼴 서식(굵게, 이탤릭 등) 사용 가능
   - 이미지 첨부 가능
4. **질문 보내기**를 누릅니다
5. "질문이 등록되었습니다" 메시지가 표시됩니다

**답변 확인:**
- 선생님이 답변하면 **알림** 탭에 알림이 옵니다
- QnA 탭에서 내 질문을 터치하면 답변을 볼 수 있습니다
- 답변이 있는 질문에는 "답변완료" 배지가 표시됩니다

### 9-5. 상담 신청
1. **상담 신청** 탭으로 이동합니다
2. 제목과 내용을 입력합니다
   - 예: "수업 시간 변경 요청", "학습 상담 요청"
3. **보내기**를 누릅니다
4. "상담 요청이 등록되었습니다" 메시지가 표시됩니다
5. 선생님 답변은 같은 곳에서 확인할 수 있습니다

- 📢 새 공지사항

## 11. 프로필

**더보기 → 프로필**

### 11-1. 내 정보 수정
- 오른쪽 위 **편집** 버튼을 누릅니다
- 수정 가능: 이름, 전화번호, 성별, 학교, 학년, 반, 주소
- **저장** 버튼으로 저장합니다

### 11-2. 프로필 사진 변경
- 프로필 사진 영역을 터치합니다
- 사진을 선택합니다 (최대 5MB)

### 11-3. 아이디 변경
- **아이디 변경하기**를 터치합니다
- 새 아이디를 입력합니다
- 이미 사용 중인 아이디는 사용할 수 없습니다

### 11-4. 비밀번호 변경
- **비밀번호 변경하기**를 터치합니다
- 현재 비밀번호와 새 비밀번호를 입력합니다
- **변경** 버튼을 누릅니다

## 15. 자주 묻는 질문

### 비밀번호를 잊었어요
로그인 화면 → **비밀번호 찾기** → 전화번호 입력 → 카카오톡으로 인증번호 → 임시 비밀번호 발급

### 시험 답을 실수로 제출했어요
- 선생님이 재시험을 허용했으면 **재시험 보기** 버튼이 나타납니다
- 허용되지 않았으면 선생님에게 직접 문의하세요

### 시험에서 떨어졌는데 클리닉이 뭔가요?
- 클리닉은 **보충 학습 시간**입니다
- 시험 불합격 시 자동으로 클리닉 대상이 됩니다
- 클리닉 탭에서 내 보강 항목과 맞는 일정을 확인해 예약합니다
- 참석 후 재시험·과제를 통과하거나 선생님이 처리하면 대상이 해소됩니다

### 클리닉 예약을 취소하고 싶어요
- 아직 승인 전(대기 중)이면 **내 일정**에서 취소할 수 있습니다
- 이미 승인된 예약은 선생님에게 취소를 요청하세요

### 영상이 안 재생돼요
- 인터넷 연결을 확인하세요
- 앱을 새로고침(위에서 아래로 당기기)해 보세요
- 계속 안 되면 선생님에게 문의하세요

### 화면이 이상하게 보여요
- "업데이트가 있습니다" 메시지가 나오면 **새로고침** 버튼을 누르세요
- 그래도 이상하면 브라우저 캐시를 삭제하고 다시 접속하세요
