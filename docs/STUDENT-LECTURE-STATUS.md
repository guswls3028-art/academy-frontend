# 학생 이름의 강의 표시와 종료 강의

관리자 학생 목록·학생 상세 제목과 조교 모바일 학생 목록·상세 제목의 강의 딱지는
학생의 **현재 수강**을 요약한다. `/students/`와 `/students/{id}/`는 이력을
보존하려고 종료·비활성 수강까지 내려주므로, 이름 옆에는 수강 상태가 `ACTIVE`이고
강의 `lecture_active=true`인 항목만 표시한다. 현재 수강이 없으면 딱지를
표시하지 않는다. 학생 이름과 프로필은 계속 보이며 다른 활성 강의의 딱지는 남는다.

관리자 학생 상세의 수강 이력 탭에서는 종료 강의를 **강의 종료**로 구분해
계속 조회할 수 있다. 종료·복원은 성적·출석·예약·수강 기록을 지우지 않는다.
기존 클리닉 예약의 학생 이름 옆 딱지도 참가자 API의 `lecture_current=false`면
숨기되, 예약 이력에 저장된 강의 제목은 그대로 조회할 수 있다.
관리자가 강의 설정에서 종료하거나 복원하면 성공 피드백을 보여 주고 강의,
학생 목록·상세, 클리닉 대상·강의 선택 캐시를 다시 읽는다. API 실패 시 모달을
유지하고 실패 사유를 표시한다. 화면을 새로고침해도 서버의 상태가 같은 딱지와
수강 이력에 반영되어야 한다.

긴 학생 이름이나 여러 활성 강의에서도 기존 딱지 크기·줄바꿈 계약을 유지한다.
키보드로 학생 상세를 열고 종료·복원한 뒤 되돌아와도 현재 상태가 반영되어야
하며, 390px 모바일 목록에서 이름·딱지가 화면 밖으로 넘치지 않아야 한다.

클리닉 대상·예약 자격의 서버 정책은
[백엔드 클리닉 대상 계약](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/clinic-targets.md)이 소유한다.
