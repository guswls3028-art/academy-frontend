# 강의 정규 수업·보강 진입 계약

## 목적과 진입점

원장과 선생님은 관리자 앱의 **강의 → 강의 상세**에서 기존처럼 전체 수업을
순서대로 보거나, 정규 진도 수업과 보강 수업을 나눠 관리한다. 화면 상단의
`보기 방식` 필터가 `전체 보기`와 `정규·보강 나눠 보기`를 전환한다. 나눠 보기의
`정규 수업`과 `보강` 탭은 해당 유형의 수업 수를 함께 보여 준다.

데이터와 권한 규칙은
[backend/docs/domain/lecture-sessions.md](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/lecture-sessions.md)가
소유한다.

## 상호작용

1. 강의 상세에 처음 들어오면 호환 기본값인 `전체 보기`를 선택하고 정규·보강
   수업을 기존 순서대로 함께 보여 준다.
2. `정규·보강 나눠 보기`를 선택하면 `정규 수업`과 `보강` 탭을 노출한다.
   처음에는 정규 수업을 보여 주되, 현재 수업 상세에서는 그 수업의 유형을 맞춘다.
3. 나눠 보기에서 `보강`을 누르면 주말 클리닉 같은 보강 수업만 보여 준다.
4. 차시 상세에서 유형을 바꾸면 현재 반을 우선해 그 유형의 첫 수업으로
   이동하고, 출결·성적·시험·과제 등 현재 업무 탭은 유지한다.
5. 전체 보기로 돌아갈 때는 현재 수업과 업무 탭을 유지하고 목록만 다시 합친다.
6. 해당 유형에 수업이 없으면 첫 수업을 추가하도록 안내한다.
7. 나눠 보기의 추가 버튼은 생성 모달에서 같은 유형을 미리 선택한다. 전체 보기의
   추가 버튼은 기존 생성 흐름을 열어 사용자가 유형을 고르게 한다.
8. 보강 생성 시 `보강 이름`을 입력한다. 저장 이름은 강의 카드, breadcrumb,
   출결·성적 등 수업 표시에 재사용된다.
9. 보강 카드의 설정 메뉴에서 이름과 날짜를 수정한다. 이름 수정은 현재 상세
   화면을 닫거나 다른 경로로 이동시키지 않으며, 저장 후 재조회해 유지한다.
10. 차시·클리닉 시간 선택기는 30분 간격 목록과 `+30분`·`+1시간` 빠른 조정을
    유지하면서 `분 단위 직접 입력`을 함께 제공한다. 따라서 `19:20~22:00`,
    `16:30~19:10`처럼 학원 운영 시각을 반올림하지 않고 저장한다.
11. 차시 상세의 `공지·게시판` 탭은 현재 강의·차시 문맥을 쿼리에 담아 커뮤니티
    공지로 이동한다. 조교가 기능 위치를 추측하거나 강의 문맥을 다시 찾지 않아도
    과제·준비물 공지를 확인하고 작성할 수 있어야 한다.

보기 방식은 화면 방문마다 `전체 보기`로 시작하며 서버나 브라우저 저장소에
사용자 선택을 기록하지 않는다. 반 편성 기능을 사용하는 tenant에서도 동일한
보기 필터를 적용한 뒤 공통 수업과 반별 수업 레인을 보여 준다. 필터를 바꿔도 반
구조나 수업 ID는 바뀌지 않는다.

강의의 **출석 관리** 표는 참여 인원이 많은 정규 운영을 우선하도록 화면 방문마다
`정규`를 기본값으로 사용한다. 상단의 `정규·보강·전체` 분할 필터는 각 차시 수를
표시하며, 선택 범위의 차시 열만 최근 차시부터 보여 준다. 보강 출결 데이터는
삭제하거나 숨은 기본값으로 저장하지 않고 `보강` 또는 `전체`를 누르면 즉시 다시
표시한다. 학생 검색·선택과 출결 값은 필터 전환에도 유지한다.

## 상태와 실패 처리

- 로딩 중에는 목록 로딩 상태를 표시한다.
- 목록 조회 실패 시 오류 문구와 `다시 불러오기`를 제공한다.
- 전체 목록이 비어 있거나 선택 유형이 비어 있으면 현재 보기 방식에 맞는 추가
  CTA를 제공한다.
- 생성·수정 실패는 서버 메시지를 가능한 범위에서 보여 주고 기존 카드 이름을
  유지한다.
- 이름이 긴 보강은 카드 안에서 두 줄로 제한하지만 상세 경로와 접근 가능한 이름은
  전체 저장값을 사용한다.

## 접근성과 반응형

- 보기 방식 필터는 `group`과 `aria-pressed`를 사용한다.
- 시간 선택 목록은 빠른 30분 선택과 접근 가능한 `type=time` 직접 입력을 모두
  제공하며, 잘못된 값은 적용하지 않고 입력 가까이에 오류를 표시한다.
- 출석 관리의 차시 범위 필터도 `group`과 `aria-pressed`를 사용하며, 기본
  `정규` 선택을 보조기기에 전달한다.
- 나눠 보기의 유형 전환은 `tablist`/`tab`과 `aria-selected`를 사용한다.
- 현재 수업 카드는 기존 `aria-current`/선택 윤곽 계약을 유지한다.
- 보강 설정과 추가 버튼은 각각 `보강 설정`, `보강 추가`라는 명확한 접근 가능한
  이름을 가진다.
- 1366px, 1100px 데스크톱과 390px 모바일에서 보기 방식 필터, 두 유형 탭,
  현재 범위의 첫 수업에 키보드·터치로 접근할 수 있어야 한다.
