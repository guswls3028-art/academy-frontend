# 선생님/관리자 사용 가이드

---

## 1. 시작하기

### 1-1. 로그인
1. 학원 전용 주소(예: tchul.com)에 접속합니다
2. **로그인** 버튼을 누릅니다
3. 아이디와 비밀번호를 입력합니다
4. **로그인**을 누르면 대시보드가 나타납니다

> 💡 비밀번호를 잊었다면 **비밀번호 찾기**를 누르세요. 등록된 전화번호로 임시 비밀번호가 카카오톡으로 전송됩니다.

### 1-2. 화면 구성
- **왼쪽 사이드바**: 모든 메뉴 (접기/펼치기 가능)
- **상단 헤더**: 근무 시간 타이머, 알림 벨, 프로필
- **가운데**: 선택한 메뉴의 내용

### 1-3. 대시보드
로그인 후 첫 화면입니다.

| 항목 | 설명 |
|------|------|
| 미답변 질문 | 학생이 보낸 QnA 중 아직 답변하지 않은 수 |
| 대기 제출물 | 학생이 제출한 성적표/과제 중 처리 대기 건수 |
| 활성 시험 | 현재 진행 중인 시험 수 |
| 알림톡 잔액 | 공용 카카오 알림톡 발송 가능 잔여 건수 |

각 숫자를 클릭하면 해당 페이지로 바로 이동합니다.

## 2. 학생 관리

### 2-0. 학원별 맞춤 컬럼

학생 목록의 **맞춤 컬럼 관리**에서 학원에 필요한 정보를 직접 추가할 수
있습니다. 예: MBTI, 취미, 목표대학, 작년 평균등급, 메가스터디 아이디.

1. 컬럼 이름과 입력 형식(텍스트·숫자·날짜·선택 목록)을 정합니다.
2. 기존 엑셀에서 다른 헤더명을 쓰고 있다면 **엑셀 별칭**에 쉼표로
   구분해 입력합니다.
3. 만든 컬럼은 학생 한 명 등록/수정, 학생 상세, 교사용 모바일, 엑셀
   양식과 내보내기에 함께 표시됩니다.
4. 목록의 **컬럼 표시**에서 선생님마다 필요한 열만 보이게 설정할 수
   있습니다. 이 표시 설정은 현재 브라우저에 저장되며 다른 선생님의
   화면이나 학생 데이터에는 영향을 주지 않습니다.
5. 더 이상 당장 쓰지 않는 컬럼은 **숨기기**를 사용합니다. 학생에게
   입력된 값과 엑셀 연결은 삭제되지 않으며 **다시 사용**하면 복원됩니다.

컬럼 이름을 바꾸더라도 기존 학생 값은 유지되고, 이전 이름은 엑셀
별칭으로 자동 보존됩니다. 이름·전화번호·학교 같은 기본 컬럼명과
겹치는 맞춤 컬럼은 만들 수 없습니다.

### 2-1. 학생 등록

**1명씩 등록하기:**
1. 사이드바 **학생** → 오른쪽 상단 **학생 등록**
2. **1명만 등록** 선택
3. 다음 정보를 입력합니다:

| 항목 | 필수 | 설명 |
|------|------|------|
| 이름 | ✅ | 학생 이름 |
| 초기 비밀번호 | ✅ | 학생이 첫 로그인에 사용할 비밀번호 |
| 학부모 전화번호 | ✅ | 010으로 시작하는 11자리. 학부모 아이디 겸 연락처 |
| 학생 전화번호 | 선택 | 입력하면 학생 아이디로 사용. 비워두면 자동 부여 |
| 성별 | 선택 | 남/여 |
| 학교/학년/반 | 선택 | XX고, XX중 입력 시 학교유형 자동 판별 |

4. **가입 안내 알림톡 발송** 토글:
   - **켜면**: 학생 전화번호와 학부모 전화번호로 카카오 알림톡이 발송됩니다
   - 알림톡 내용: 아이디, 비밀번호, 접속 링크
   - 학부모에게는 학부모 아이디(=학부모 전화번호), 학부모 비밀번호 안내, 학생 아이디/비밀번호가 함께 전송됩니다
5. **등록** 버튼을 누르면 완료

> 💡 학부모 아이디는 **학부모 전화번호** 그 자체입니다. 신규 학부모 계정의 초기 비밀번호는 하이픈을 제외한 전화번호 **뒤 4자리**이며, 이미 있는 학부모 계정은 비밀번호가 변경되지 않습니다.

**엑셀로 일괄 등록하기:**
1. **엑셀 업로드** 선택
2. **엑셀 양식 다운로드**를 눌러 현재 활성 맞춤 컬럼까지 포함된 양식 파일을 받습니다
3. 양식에 학생 정보를 작성합니다 (필수: 이름, 학부모전화번호)
4. 작성한 파일을 업로드합니다
5. 신규 학생의 초기 비밀번호 방식을 선택합니다:
   - **학생 휴대폰 번호 뒤 4자리**(기본): 엑셀의 학생 전화번호로 자동 설정
   - **공통 비밀번호 직접 입력**: 4자 이상 입력해 모든 신규 학생에게 동일 적용
   - **학생별 랜덤 비밀번호**: 등록 완료 후 이름·아이디·비밀번호 목록 엑셀이 자동 다운로드(완료 후 1시간 안에 작업박스에서 다시 다운로드 가능)
6. 휴대폰 번호 뒤 4자리 방식을 사용할 때 학생 전화번호가 없는 행이 있으면 엑셀을 수정한 뒤 다시 선택합니다
7. **등록**을 누르면 백그라운드에서 처리됩니다
8. 오른쪽 아래 진행 상태 바에서 처리 현황을 확인할 수 있습니다

엑셀로 새로 만든 학생은 첫 로그인에서 반드시 비밀번호를 변경합니다.

### 2-2. 학생 목록

- **검색**: 이름, 전화번호, 학교명으로 검색
- **정렬**: 이름, 등록일, 학교 등 기준으로 정렬
- **컬럼 설정**: 표에 보이는 열을 원하는 대로 선택
- **학생 클릭** → 오른쪽에 상세 패널이 열립니다:
  - 기본 정보, 수강 강의, 태그, 메모
  - **시험 탭**에서 1회차부터 최근 회차까지 득점률 추이, 평균·최고·직전 대비 확인
  - 수정, 삭제, 메시지 발송, 비밀번호 초기화 가능

### 2-3. 학생 대량 작업

학생을 체크박스로 선택한 후 상단 도구 모음:

| 버튼 | 동작 |
|------|------|
| 메시지 발송 | 선택한 학생/학부모에게 공용 카카오 알림톡 발송 |
| 엑셀 다운로드 | 선택한 학생의 기본 정보와 현재 활성 맞춤 컬럼을 엑셀 파일로 내보내기 |
| 태그 추가 | 분류용 태그(색상 라벨) 일괄 부여 |
| 삭제 | 소프트 삭제 → 30일간 "삭제됨" 탭에 보관 후 자동 삭제 |

### 2-4. 가입 신청 관리

학생이 직접 회원가입한 경우:
1. 사이드바 **학생** → **가입 신청** 탭
2. 대기 중인 신청 목록이 표시됩니다
3. **승인**: 학생 계정이 생성되고 알림톡이 자동 발송됩니다
4. **거절**: 신청이 거절됩니다

> 💡 학원 설정에서 **자동 승인**을 켜면 학생 가입 신청 시 바로 승인됩니다.

## 3. 강의 관리

### 3-1. 강의 생성
1. 사이드바 **강의** → **+ 강의 추가**
2. 입력 항목:

| 항목 | 필수 | 설명 |
|------|------|------|
| 강의명 | ✅ | 예: "수학 기초반", "영어 심화반" |
| 과목 | ✅ | 예: 수학, 영어, 과학 |
| 담당 강사 | 선택 | 직원 목록에서 선택 |
| 운영 기간 | 선택 | 시작일~종료일 |
| 수업 시간 | 선택 | 예: "화,목 14:00~16:00" |
| 색상 | 선택 | 시간표/카드에서 강의 구분용 |

3. **생성** 버튼을 누르면 완료

### 3-2. 수강생 관리

강의 카드를 클릭하면 해당 강의의 상세 페이지가 열립니다.

**수강생 추가:**
1. **수강생** 탭으로 이동
2. **학생 추가** 버튼 클릭
3. 세 가지 방법:
   - **기존 학생 선택**: 등록된 학생 목록에서 검색하여 추가
   - **신규 학생 등록**: 학생 등록 모달에서 바로 등록 후 추가
   - **엑셀 업로드**: 수강생 명단 엑셀로 일괄 등록

**수강생 목록에서 볼 수 있는 정보:**
- 학생 이름, 전화번호
- 차시별 출결 현황 (매트릭스 형태)
- 메시지 발송, 엑셀 다운로드 가능

### 3-3. 차시(수업) 관리

**차시 추가:**
1. 차시 바에서 **+** 버튼 클릭
2. 자동으로 다음 회차 번호, 날짜(+7일), 시간(강의 시간)이 채워집니다
3. **보강 차시**: 별도로 추가 가능 (날짜/시간 직접 입력)

**차시를 선택하면 기본 5개 탭이 나타납니다. 정규 클리닉 모드에서는 정규 클리닉 탭이 추가됩니다:**

| 탭 | 설명 |
|------|------|
| **출결** | 학생별 출석/지각/결석 등 상태 관리 |
| **성적** | 시험/과제 점수 입력 및 조회 |
| **시험** | 시험 생성, 문항 관리, 학생 응시 현황 |
| **과제** | 과제 생성, 제출 현황, 채점 |
| **영상** | 수업 영상 업로드 및 관리 |
| **정규 클리닉** | 정규 클리닉반 차시 운영 (정규 클리닉 모드에서만 표시) |

실제 운영 기본 동선은 **강의 목록 → 강의 선택 → 차시 선택 → 성적/시험/과제 탭**입니다. 성적·시험·과제 탭에서도 차시 바가 유지되며, 다른 차시를 누르면 현재 작업 중인 탭(예: 성적)을 유지한 채 해당 차시로 이동합니다.

### 3-4. 강의 종료/복원/삭제

강의 카드의 **⚙️(설정)** 클릭:
- **강의 종료**: "지난강의" 탭으로 이동. 데이터 보존. 언제든 복원 가능
  - 확인 팝업: "강의를 종료하시겠습니까? 종료된 강의는 '지난강의' 탭에서 다시 복원할 수 있습니다."
- **강의 복원**: 지난강의 탭에서 다시 운영 중으로 돌림
- **강의 삭제**: 모든 데이터(차시, 수강생, 출결, 성적) 영구 삭제
  - 확인 팝업: "모든 관련 정보가 제거됩니다"

## 4. 출결 관리

### 4-1. 출결 입력

**강의 → 차시 선택 → 출결 탭**

| 출결 상태 | 의미 | 학생앱 표시 |
|----------|------|-----------|
| 현장 | 직접 출석 | 현 |
| 영상 | 온라인 수업 참여 | 영 |
| 보강 | 보강 수업 출석 | 보 |
| 지각 | 지각 출석 | 지 |
| 조퇴 | 조기 퇴실 | 조 |
| 결석 | 미출석 | 결 |
| 출튀 | 출석 후 무단 이탈 | 출 |
| 자료 | 자료만 제공 | 자 |
| 부재 | 장기 부재 | 부 |
| 퇴원 | 퇴원 처리 | 퇴 |

**조작 방법:**
- 학생 이름 옆 상태 배지를 클릭 → 팝오버에서 상태 선택
- **전체 출석** 버튼: 모든 학생을 "현장"으로 일괄 변경
- 메모: 각 학생별 출결 메모 입력 가능

### 4-2. 출결 매트릭스

**강의 상세 → 수강생 탭**에서 전체 차시의 출결 현황을 한눈에 볼 수 있습니다.
- 행: 학생
- 열: 차시(1차시, 2차시, ...)
- 셀: 출결 상태 약자(현/영/결/지...)

## 5. 시험 관리

### 5-1. 시험 생성

**차시 → 시험 탭 → 시험 추가**

처음 화면에서 목적에 맞는 생성 방식을 선택합니다.

| 생성 방식 | 사용할 때 |
|-----------|-----------|
| **시험지로 만들기** | 원본 시험지, 채점 방식과 점수 기준을 함께 등록할 때 |
| **빠르게 여러 개 만들기** | 시험명·만점·커트라인만 입력해 여러 시험을 만들 때 |
| **이전 시험 가져오기** | 저장된 시험지 양식을 불러올 때 |
| **다른 차시에서 복사** | 다른 차시의 양식을 독립된 시험으로 복사할 때 |

**시험지로 만들기**에서는 시험명, 만점, 커트라인, 원본 파일과 아래
채점 방식을 선택합니다.

| 시험 구성 | 채점 흐름 |
|-----------|-----------|
| 선택형 | OMR 자동 채점 |
| 답변형 | 조교가 정오 또는 문항별 점수를 직접 입력 |
| 혼합형 | 앞쪽 선택형은 OMR, 나머지 답변형은 직접 입력 |

답변형이 있으면 **정오 입력(O/X/0)** 또는 **점수 입력(부분점수)**을
선택합니다. 혼합형은 앞쪽 선택형 문항 수도 입력합니다. 시험 문항이
생성된 뒤에는 채점 방식과 선택형 경계를 바꿀 수 없습니다.

원본은 PDF, PNG, JPG/JPEG, HWP/HWPX를 최대 50MB까지 올릴 수 있습니다.
PDF와 이미지는 문항 분리를 시작합니다. HWP/HWPX는 원본을 보관하지만
수식과 쪽 배치를 안전하게 유지하기 위해 PDF로 저장한 파일을 다시
올리라는 안내가 표시됩니다. `문항 분리 중`에는 기다리고, 실패 안내가
나오면 원본과 시험 상태를 확인한 뒤 다시 시도합니다. 기존 문항이나
성적이 있는 시험의 원본은 자동으로 덮어쓰지 않습니다.

| 항목 | 설명 |
|------|------|
| 시험명 | 예: "1차 중간고사", "단원평가 3장" |
| 총점 | 시험 만점 (예: 100) |
| 합격점 | 이 점수 이상이면 합격 (예: 60) |
| 재시험 허용 | 켜면 학생이 불합격 시 재응시 가능 |
| 최대 응시 횟수 | 재시험 포함 총 응시 가능 횟수 |
| 정답 공개 | 학생에게 정답을 보여줄지 여부 |
| 채점 구성 | 선택형 / 답변형 / 혼합형 |
| 답변형 채점 | 정오 입력(O/X/0) 또는 문항별 점수 입력 |
| 앞쪽 선택형 문항 수 | 혼합형 시험에서 OMR로 채점할 앞쪽 문항 수 |

**문항 추가:**
- **답안 등록 → 문항별 유형**에서 전체 문항 수를 입력한 뒤 각 번호를 눌러 객관식/단답형을 지정하고 **유형 저장**을 누릅니다.
- 유형 순서는 자유롭습니다. 예를 들어 1번 객관식, 2번 단답형, 3번 객관식으로 구성할 수 있습니다.
- 객관식: 5지선다 (정답 번호 지정)
- 수학 단답형: 정답을 `0~999` 정수로 등록하면 자동 채점
- 그 외 주관식/서술형: 정답 텍스트와 교사 수동 채점
- 서술형: 교사가 수동 채점

**정답지 등록:**
- 정답 번호를 한 번에 입력할 수 있습니다 (클릭 한 번으로 붙여넣기)
- 배점도 문항별로 설정 가능
- OMR 답안지는 객관식과 숫자 단답형을 별도 영역에 배치하지만 각 행에 원래 시험 번호를 표시하므로 섞인 문항 순서도 그대로 채점됩니다.

### 5-2. 시험 운영

신규 시험은 생성 즉시 차시에 연결되어 운영됩니다. 시험 단위 **종료** 버튼은 현재 운영 UI에서 사용하지 않습니다.

- 학생별 응시/미응시/채점/검토 상태는 **성적 탭 점수 셀과 제출관리**가 기준입니다.
- 시험·과제 목록 순서는 성적 탭의 컬럼 순서와 동일하게 표시됩니다.
- 정답 공개 여부는 **정답 공개** 설정으로 별도 관리합니다.
- DRAFT/OPEN/CLOSED 값은 기존 데이터 호환용 상태 필드이며, 신규 운영 흐름의 주 조작 단위가 아닙니다.

### 5-3. 채점

- **객관식**: 정답지 기준으로 자동 채점
- **수학 숫자 단답형**: `0~999` 정답지 기준으로 자동 채점 (`007`과 `7`은 같은 답)
- **그 외 주관식/서술형**: 교사가 직접 점수 입력
- 채점 결과: 합격/불합격 자동 판정 (합격점 기준)

#### 문항별 직접 채점

**차시 → 성적 탭에서 시험명 클릭**으로 조교가 엑셀처럼 학생별 문항을
입력합니다. 기존 **시험 → 채점·결과 → 문항별 직접 채점**에서도 같은
표를 열 수 있습니다.

1. 학생의 **응시/결시**를 확인합니다.
2. 정오 방식이면 첫 입력칸에 자동으로 초점이 잡힙니다. 셀을 누르거나
   키보드 `O`, `X`, `0`을 입력하면 다음 칸으로 자동 이동합니다.
   - `O`: 정답, 문항 만점, 오답노트 제외
   - `X`: 오답, 0점, 오답노트 포함
   - `0`: 정답과 문항 만점은 유지하지만 복습을 위해 오답노트에 포함
   - 방향키: 상하좌우 이동, `Enter`/`Tab`: 다음 칸, `Shift+Tab`: 이전 칸
   - `Backspace`/`Delete`: 입력 지우기, `Shift+?`: 단축키 설정 열기
   - **단축키 설정**에서 정답·오답·복습 키를 원하는 한 글자로 바꿀 수
     있으며 현재 기기의 브라우저에 저장됩니다. 서로 같은 키나 이동
     전용 키는 지정할 수 없습니다.
3. 점수 방식이면 0점부터 문항 만점 사이의 점수를 입력합니다. 만점
   문항도 **복습**을 켜면 오답노트에 포함할 수 있습니다.
4. **입력 내용 확인**으로 학생 수, 결시, 계산 점수와 덮어쓸 기존
   결과를 확인합니다. 이 단계에서는 통계가 바뀌지 않습니다.
5. 오류가 없을 때 **성적 확정**을 눌러 한 번에 반영합니다.

자동채점된 선택형 시험도 이 표에서 학생별 O/X 목록을 확인할 수
있습니다. 필요한 문항은 직접 보정할 수 있으며, 확정해도 스캔에서 읽은
학생 답안 자체는 보존됩니다.

각 문항 번호 아래의 배점을 수정하면 모든 학생의 계산 점수가 즉시
갱신됩니다. **배점 합계 + 시험 가감점 합계**가 시험 만점과 같아야
미리보기와 확정이 가능합니다. 다른 화면에서 배점이 먼저 바뀌었다면
확정을 중단하고 최신 값을 다시 불러옵니다.

시험에 문항이 하나도 없으면 채점 표에서 다음 중 하나를 선택합니다.

- 객관식 위주 시험은 **객관식 답안 등록**으로 기존 답안 등록 화면을 엽니다.
- 문항 수와 정오만 먼저 입력할 시험은 **문항 수로 바로 시작**에서
  문항 수를 넣어 채점 표를 만든 뒤, 같은 표의 문항 머리글에서 배점을
  조정합니다.

혼합형의 선택형 셀은 수정할 수 없습니다. OMR 채점을 먼저 마쳐야
답변형 점수를 확정할 수 있으며, 확정해도 기존 선택형 OMR 결과는
보존됩니다. 다른 직원이나 탭에서 같은 학생의 결과가 바뀌면 확정을
중단하므로 **다시 불러오기** 후 최신 표에서 작업합니다.

- 확정 전에는 **되돌리기**로 마지막 서버 저장 상태를 다시 불러올 수 있습니다.
- 불러오기 실패 화면에서는 **다시 불러오기**를 사용할 수 있습니다. 미리보기나
  확정이 실패해도 실제 성적은 일부만 저장되지 않습니다.
- 확정 후 다시 열면 저장한 O/X/0 또는 부분점수와 복습 상태가 그대로 표시됩니다.

#### 직접 채점한 결과를 엑셀로 넣기

**시험 → 채점·결과 → 엑셀로 채점 결과 넣기**에서 사용합니다.

1. **전용 양식 받기**를 눌러 시험 학생과 문항 번호가 들어 있는 엑셀을 내려받습니다.
2. 학생별로 틀린 문항만 `X`로 표시합니다. 정답은 빈칸 또는 `O`로 둡니다.
   - 기존 Ymath 표의 문항 셀 `.`은 오답, 숫자 `0`은 정답이지만
     오답노트에 넣을 복습 문항으로 읽습니다.
   - Ymath 표의 응시 여부 열에 있는 `.`은 결시로 읽습니다.
   - 전 문항이 비어 있으면 만점과 결시를 자동으로 구분할 수 없으므로 **응시 여부** 열에서 `응시` 또는 `결시`를 선택합니다.
   - 선택하지 않은 전 문항 공란 행은 미리보기에서 안내되며, 확인 전에는 성적을 반영할 수 없습니다.
3. 엑셀을 선택하면 학생·문항·점수를 먼저 확인합니다.
4. 오류가 없으면 **결과 반영**을 눌러 저장합니다.

- 객관식과 단답형이 섞인 시험도 문항 번호 기준으로 함께 반영됩니다.
- 기존에 쓰던 채점표도 이름(또는 학생 연락처)과 `1, 2, 3…` 문항 열이 있으면 확인할 수 있습니다.
- 학급별 시트처럼 학생이 겹치지 않는 여러 시트는 함께 읽습니다. 같은
  학생이 겹치는 후보 시트가 둘 이상이면 임의로 고르지 않고 오류를
  표시합니다.
- 동명이인이나 같은 연락처가 있으면 전용 양식의 `수강등록ID`로 정확히 구분합니다.
- 기존 결과가 있는 학생은 확인 화면에 표시되며, 반영 시 새 엑셀 내용으로 갱신됩니다.
- 결시 학생은 상세 인원 기록에는 남지만 점수·석차·평균·합불·문항 통계에 0점으로 들어가지 않습니다. 누적 미응시가 있는 학생 이름에는 음영이 유지되며, 마우스를 올리면 누적 횟수를 확인할 수 있습니다.
- 결시를 잘못 선택한 경우 같은 학생의 정상 문항 결과를 다시 반영하면 해당 시험의 결시 상태가 해제됩니다.

## 6. 성적 관리

### 6-1. 성적 입력 (엑셀식)

**차시 → 성적 탭**

1. 필요하면 성적 탭 상단의 **성적 도구 → 시험 추가/과제 추가**
2. 점수가 하나도 없는 첫 성적표는 바로 입력하고, 기존 점수가 있으면 **수정**을 누름
3. 표에서 학생별 시험/과제 점수를 입력
   - Tab, 화살표 키로 셀 간 이동
   - 셀을 벗어나면 실제 성적에 자동 저장
   - `Ctrl+S`: 입력 중인 셀까지 즉시 저장
   - `Ctrl+Z`: 마지막 셀 변경 실행 취소
   - `Ctrl+Shift+Z` 또는 `Ctrl+Y`: 다시 실행
4. 입력을 마치면 **저장하고 잠금**을 눌러 완료

- 잠금 상태에서는 점수 셀이 수정되지 않아 실수 입력을 막습니다. 다시 바꾸려면 **수정**을 누릅니다.
- 점수가 하나도 없는 첫 입력에서는 바로 수정 상태로 열립니다. **저장하고 잠금**을 누른 뒤에는 자동으로 다시 열리지 않습니다.
- 셀을 확정하면 즉시 자동 저장을 시작하며, 자동 저장이 실패해도 입력값은 유지됩니다.
- 이전 작업이 비정상 종료되어 복구할 입력이 있으면, 복원하거나 버리기 전에는 발송·출력을 사용할 수 없습니다.
- 같은 차시는 한 번에 한 화면에서만 수정할 수 있습니다. 다른 직원이나 탭에서 수정 중이면 저장 후 잠글 때까지 기다린 뒤 **다시 확인**을 누릅니다.
- 학생 상세의 재시험 점수와 답안 보정도 **수정** 상태에서만 가능합니다.

**성적 도구:**
- OMR 스캔 등록: 시험이 있으면 성적 탭 상단에서 바로 업로드
- 엑셀 다운로드: 성적표를 파일로 내보내기
- 성적표 출력: 학원 로고·브랜드색이 적용된 교사용 전체 현황을 A4 가로
  페이지에 맞게 자동 분할해 PDF로 다운로드
- 개인 성적표: **성적 도구 → 개인 성적표**에서 한 명 또는 여러 명을
  선택하고 `요약 1쪽` 또는 `상세 2쪽 이상`을 한 PDF로 다운로드
- 클리닉 대상: 대상자 확인·출력
- 학생 이름 클릭 → 오른쪽 드로어에서 개별 성적 상세, 시험 이력 확인

**개인 성적표 만들기:**

1. **차시 → 성적 탭 → 성적 도구 → 개인 성적표**를 누릅니다.
2. 오른쪽 학생 목록이나 이전/다음 버튼으로 미리볼 학생을 바꿉니다.
   표에서 학생을 미리 선택했다면 그 학생들이 출력 대상으로 선택됩니다.
3. 빠른 전달은 **요약 1쪽**, 누적 시험 기록·문항별 득점·상담 체크포인트까지 필요하면 **상세 2쪽**을 선택합니다.
4. 체크박스로 필요한 학생을 더 선택하거나 **전체 선택**을 누릅니다.
5. 미리보기를 확인한 뒤 **N명 성적표 PDF**를 누르면 학생별 페이지가
   순서대로 들어간 한 파일로 내려받아집니다.

- 현재 차시의 시험·과제·출결과 같은 강의의 누적 시험 기록만 사용합니다.
- 문항별 정오답이 아니라 저장된 문항별 득점(만점·부분득점·0점)을 표시합니다.
- 저장되지 않은 점수가 있으면 먼저 저장한 뒤 최신 성적으로 성적표를 구성합니다.

**학생별 누적 추이 확인:**

1. **학생 → 학생 선택 → 시험 탭**으로 이동합니다. 선생님 화면에서도 **학생 → 학생 선택 → 시험** 순서가 같습니다.
2. 점수가 확정된 서로 다른 정규 시험이 시간순으로 `1회차, 2회차, 3회차…` 자동 누적됩니다. 새 시험을 따로 등록할 필요는 없습니다.
3. 만점이 다른 시험은 득점률(%)로 환산해 비교하며, 마우스를 올리면 원점수와 시험·강의·차시 정보를 확인할 수 있습니다.
4. 여러 강의를 수강하는 학생은 강의 칩으로 추이를 좁혀 볼 수 있습니다. 미응시 시험은 이력에는 남지만 0점으로 간주해 평균이나 추이선을 낮추지 않습니다.
5. 보관된 시험도 과거 이력에서 유지되며 `보관됨`으로 구분됩니다.

### 6-2. 오답노트 만들기

1. **차시 → 성적 탭**에서 학생 이름을 누르고 **오답노트 만들기** 탭을 엽니다.
2. **이번 시험**은 현재 시험만, **강의 누적**은 1주차부터 현재까지 틀린 문항을
   주차별로 모읍니다.
3. 수록 문항과 문제 이미지 준비 수를 확인한 뒤 **오답노트 PDF 만들기**를 누릅니다.
4. 버튼이 **PDF 다운로드**로 바뀌면 파일을 열어 학생에게 전달하거나 인쇄합니다.

문제 사진이 비어 있으면 해당 문항도 답안 정보와 함께 수록됩니다. 사진까지 넣으려면
해당 시험의 **시험 설정 → 답안 등록 → 이미지 등록**에서 문항별 문제 이미지를 붙이고
**이미지·해설 저장**을 누릅니다. 이후 다시 PDF를 만들면 저장한 이미지가 자동 반영됩니다.

재채점이나 대표 재시험 결과에서 정답으로 바뀐 문항은 누적 오답에서 자동으로 빠집니다.
직접 채점에서 `0` 또는 **복습**으로 지정한 문항은 정답·만점이어도
오답노트에 `정답 · 복습 지정`으로 남습니다. 복습 지정을 해제하면
오답이 아닌 문항은 다음 오답노트에서 빠집니다.
한 번에 최대 100문항까지 만들 수 있으므로 누적 오답이 더 많으면 **이번 시험** 범위로
나누어 다운로드합니다.

채점·권한·저장 API의 기술 계약은
[`backend/docs/domain/exam-grading.md`](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/exam-grading.md)를
참고합니다.

### 6-3. ⭐ 성적과 클리닉의 연결 (핵심!)

**이것이 시스템의 핵심 흐름입니다:**

```
시험 응시/채점 → 성적 계산 → 불합격 판정 → 클리닉 대상자 자동 지정
                                              ↓
                              교사 확인 → 클리닉 세션 배정 → 학생 예약
                                              ↓
                              학생 출석 → 재시험/과제 통과 → 다음 차시 진행
```

**자동 클리닉 대상자 지정 조건:**

성적이 저장되면 시스템이 자동으로 다음을 확인합니다:

| 조건 | 설명 | 예시 |
|------|------|------|
| **시험 불합격** | 시험 점수 < 합격점 | 40점 / 합격점 60점 → 클리닉 대상 |
| **OMR 신뢰도 낮음** | OMR 인식 시 2개 이상 문항이 확신도 부족 | 마킹이 불분명한 답안 |
| **반복 오답** | 같은 문항을 2회 이상 응시에서 연속 틀림 | 재시험에서도 같은 문제를 틀림 |
| **차시 미이수** | 영상 시청 부족(<90%), 시험 불합격, 과제 미제출 | 종합적으로 차시 완료 조건 불충족 |

**이 중 하나라도 해당하면 학생은 자동으로 "클리닉 대상자"가 됩니다.**

## 7. 클리닉 관리 (보충 학습)

### 7-1. 전체 흐름

```
① 시험/과제 채점 → 불합격 학생 자동 감지
     ↓
② 교사: 클리닉 → 오늘에서 "이번 주 미예약 학생" 확인
     ↓
③ 교사: 클리닉 세션 생성 (날짜, 시간, 장소, 정원)
     ↓
④ 학생 배정: 교사가 수동 배정 또는 학생이 직접 예약
     ↓
⑤ 클리닉 당일: 교사가 출석 확인
     ↓
⑥ 재시험/과제 통과 또는 교사 수동 처리로 클리닉 요건 해소
```

### 7-2. 클리닉 대상자 확인

**클리닉 → 미통과 관리**

- **클리닉 대상자** 테이블이 표시됩니다
- 각 대상자 정보:

| 항목 | 의미 |
|------|------|
| 학생 이름 | 클리닉이 필요한 학생 |
| 차시명 | 어떤 수업에서 미달됐는지 |
| 사유 | "점수 미달" 또는 "OMR 신뢰도" |
| 시험 점수 | 실제 받은 점수 |
| 합격 기준점 | 넘어야 하는 점수 |
| 처리 상태 | 진행중 / 통과 / 면제 / 이월 |

- 학생별 보기는 학생 ID 기준으로 묶으므로 여러 강의를 수강해도 학생 수가 중복 집계되지 않습니다
- 각 미통과 항목에서 재시험 점수를 입력하거나 통과·면제·이월 처리할 수 있습니다

### 7-3. 예약 일정과 클리닉 세션 생성

**클리닉 → 예약 일정**

1. 월요일부터 일요일까지 한 주의 세션·예약 인원·학생 명단을 한 화면에서 확인합니다
2. 빈 날짜의 **이 날짜에 만들기** 또는 상단의 **클리닉 만들기**를 클릭합니다
3. 입력 항목:

| 항목 | 필수 | 설명 |
|------|------|------|
| 제목 | 선택 | 예: "수학 보충", "영어 재시험" |
| 시간 | ✅ | 시작 시간 (예: 14:00) |
| 시간(분) | ✅ | 소요 시간 (기본 60분) |
| 장소 | ✅ | 예: "보충학습실 A", "3층 교실" |
| 정원 | ✅ | 최대 참가 인원 |
| 대상 학년 | 선택 | 전체/1학년/2학년/3학년 |
| 대상 학교유형 | 선택 | 전체/고등/중등 |
| 대상 강의 | 선택 | 특정 강의 수강생만 |

4. **클리닉 만들기** 버튼 클릭
5. 성공 메시지 확인

> 💡 미통과 대상자를 먼저 선택해도 정원은 선택 인원으로 줄어들지 않습니다. 예를 들어 3명을 배정하고 정원 10명으로 만들면 나머지 7명은 학생 앱에서 예약할 수 있습니다.

> 💡 반복 일정은 **이전 주 불러오기**로 같은 요일에 한꺼번에 만들거나, 세션 카드의 **복사**로 시간·장소·정원 설정을 불러와 새로 만들 수 있습니다. 학생 명단은 복사되지 않습니다.

### 7-4. 학생 배정 방식

**방법 1: 교사가 수동 배정**
- 예약 일정의 세션 카드에서 **학생 추가** 클릭
- **미통과 대상자** 또는 **전체 학생** 명단에서 이름을 검색해 한 명 이상 선택
- 두 탭은 `수강 ID`와 `학생 ID`가 달라 탭을 바꾸면 기존 선택이 초기화됩니다
- 세션에 배정하면 바로 **"예약됨(booked)"** 상태가 됩니다
- 학생 앱의 "내 일정"에 즉시 반영됩니다

**방법 2: 학생이 직접 예약**
- 학생이 앱에서 클리닉 → 예약 탭에서 세션을 선택하고 예약합니다
- **자동 승인 설정**에 따라:
  - 자동 승인 **켜짐**: 예약 즉시 확정 (booked)
  - 자동 승인 **꺼짐**: "대기(pending)" 상태 → 교사가 승인/거절 필요

### 7-5. 클리닉 요건 해소 규칙

| 상황 | 클리닉 요건 상태 |
|------|----------------|
| 학생 예약/교사 배정 | ❌ 미해소 유지 — 일정 연결만 생성 |
| 출석/미출석 처리 | ❌ 미해소 유지 — 출결 기록만 변경 |
| 재시험 통과 | ✅ 시험 대상 해소 |
| 과제 통과 | ✅ 과제 대상 해소 |
| 교사 수동 통과/면제 | ✅ 대상 해소 |
| 다음 차수 이월 | 현재 항목 종료 후 다음 차수 대상으로 생성 |

> ⚠️ **핵심**: 예약·출석과 학습 요건 해소는 별도 상태입니다. 예약이나 출석만으로 시험/과제 미통과를 자동 해소하지 않습니다.

### 7-6. 클리닉 홈 (당일 운영)

**클리닉 → 오늘**

- 오늘 예정된 클리닉 세션이 타임라인으로 표시됩니다
- 각 세션에서:
  - 예약 학생 목록 확인
  - **출석/미출석** 상태 변경 (버튼 클릭)
  - 메모 작성
- **대기 승인**: 학생이 신청한 예약 중 승인 대기 건이 있으면 상단에 표시됩니다

### 7-7. 클리닉 패스카드

**클리닉 → 설정(패스카드)**

- 패스카드 배경색 3가지를 설정할 수 있습니다
- **매일 자동 변경** 옵션: 켜면 매일 색상이 자동으로 바뀝니다
- 학생은 앱에서 패스카드 화면을 보여줍니다
- 패스카드에는:
  - 학생 이름, 프로필 사진, 활성 수강 강의
  - 실시간 시계 (매초 업데이트)
  - 강의별 차시 합격/클리닉 대상 이력
  - 배경색 (매초 미세 변화 → 스크린샷/녹화 방지)

### 7-8. 클리닉 운영 콘솔

**클리닉 → 당일 진행**

- 왼쪽: 캘린더 + 세션 목록
- 오른쪽: 선택한 세션의 참가자 상세
  - 참가자별 출석 상태 토글
  - 미통과 항목(어떤 시험에서 떨어졌는지) 표시
  - 학생 이름 클릭 → 학생 상세 오버레이

## 8. 영상 관리

### 8-1. 영상 업로드

**사이드바 → 영상**

1. 왼쪽 트리에서 강의 → 차시를 선택
2. **영상 추가** 클릭
3. 업로드 방식을 선택합니다
   - **파일 업로드**: MP4, MOV 등 파일을 올립니다
   - **YouTube 링크**: 공개 또는 일부공개 YouTube 주소를 붙여넣습니다
4. 파일 업로드는 업로드 진행률이 표시되고, 완료 후 자동으로 인코딩이 시작됩니다
5. YouTube 링크 영상은 인코딩 없이 바로 시청 가능 상태로 추가됩니다

### 8-2. 영상 처리 상태

| 상태 | 의미 | 학생 시청 |
|------|------|----------|
| 대기 중 (PENDING) | 업로드 직후 | ❌ |
| 처리 중 (PROCESSING) | 인코딩 진행 중 | ❌ |
| 완료 (READY) | 인코딩 완료 | ✅ 시청 가능 |
| 실패 (FAILED) | 인코딩 오류 | ❌ 재시도 필요 |

- 실패 시 **재시도** 버튼으로 다시 시도할 수 있습니다
- YouTube 링크 영상은 실패 재시도/인코딩 대상이 아니며, 학생 목록에서 **YouTube 링크**로 표시됩니다
- 30분 이하 영상: 빠른 처리 (보통 수 분)
- 30분 초과 영상: 별도 처리 (최대 수 시간)

### 8-3. 영상 상세

영상 카드를 클릭하면:
- 조회수, 좋아요 수, 댓글 수
- 학생별 시청 현황 (누가 얼마나 봤는지)
- 영상 공개/비공개 설정
- 시청 제한: 자유 시청 / 1회 제한 / 차단
- 워터마크 표시 여부
- 삭제 (확인 팝업 → 6개월 보관 후 영구 삭제)

## 9. 커뮤니티

### 9-1. 공지사항

**커뮤니티 → 공지사항**

**공지 작성:**
1. **+ 추가** 버튼 클릭
2. 제목 입력
3. 내용 작성 (리치 텍스트 에디터: 굵게, 이탤릭, 링크, 이미지 삽입 가능)
4. **등록** 클릭

- 공지 범위: 전체 공지 / 특정 강의 공지 / 특정 차시 공지
- 학생 앱의 공지사항 탭에 즉시 반영됩니다

### 9-2. QnA 답변

**커뮤니티 → QnA**

1. 왼쪽에 학생 질문 목록이 표시됩니다
   - 미답변 질문에 빨간 표시
   - 삭제된 학생의 질문은 "삭제된 학생" 표시
2. 질문을 클릭하면 오른쪽에 대화 스레드가 열립니다
3. 아래쪽 입력란에 답변을 작성합니다
4. **답변 등록** 클릭 (또는 Ctrl+Enter)
5. 자동발송 설정이 켜져 있으면 학생에게 알림톡이 발송됩니다

### 9-3. 상담

**커뮤니티 → 상담**

- QnA와 같은 형태이지만 상담 요청 전용입니다
- 학생/학부모의 수업 시간 변경, 상담 요청 등을 처리합니다

### 9-4. 게시판 / 자료실

- **게시판**: 자유 게시판 관리 (글 작성, 수정, 삭제, 댓글)
- **자료실**: 학습 자료 업로드 (PDF, 이미지, 문서). 학생이 다운로드 가능

## 10. 메시지 관리

### 10-1. 직접 발송

학생 목록/수강생 목록에서 학생을 선택 → **메시지 발송**

| 발송 방식 | 설명 |
|----------|------|
| 알림톡 | 카카오톡 알림톡 (사전 승인된 템플릿만 가능) |

발송 버튼을 누르면 마지막 확인 화면에서 카카오톡과 같은 형태로 최종 문구를 확인할 수 있습니다. 학원명·학생명·링크·빈 항목은 실제 발송에 쓰이는 값 그대로 표시됩니다. 여러 학생을 선택한 경우 **전체 학생 열기**를 누른 뒤 학생 이름을 선택하면, 발송 대상은 유지한 채 해당 학생에게 적용될 이름·성적 등으로 미리보기가 바뀝니다. 전화번호가 없는 대상은 발송에서 제외되며 마지막 확인 화면에 표시됩니다.

### 10-2. 템플릿 관리

**메시지 → 템플릿**

- 자주 사용하는 자유 본문을 문구로 저장·수정합니다
- 변수 사용 가능: `#{학생이름}`, `#{강의명}`, `#{시험명}` 등
- 시스템 기본 문구와 실제 발송에 쓰는 승인 봉투는 읽기 전용입니다
- 학원별 PFID/API key 입력이나 신규 템플릿 검수 신청은 하지 않습니다. 공용
  승인 봉투가 없으면 다른 템플릿이나 문자로 대체하지 않고 발송이 실패합니다

### 10-3. 자동 발송

**메시지 → 자동발송**

이벤트 발생 시 자동으로 메시지를 보낼 수 있습니다:

| 이벤트 | 수신 대상 | 예시 |
|--------|----------|------|
| 가입 안내 | 학생 + 학부모 | 아이디/비밀번호 안내 |
| 수업 시작 전 | 학생 + 학부모 | "오늘 수업이 시작됩니다" |
| 입실 완료 | 학부모 | "학생이 입실했습니다" |
| 결석 발생 | 학부모 | "결석이 발생했습니다" |
| 시험 예정 | 학생 | "시험이 예정되어 있습니다" |
| 성적 공개 | 학생 + 학부모 | "성적이 공개되었습니다" |
| 과제 등록 | 학생 | "새 과제가 등록되었습니다" |
| 클리닉 예약 | 학생 | "예약이 완료되었습니다" |
| 퇴원 처리 | 학생 + 학부모 | "퇴원 처리가 완료되었습니다" |

각 이벤트별로 **켜기/끄기**, 사용할 **템플릿**, **발송 시점**(즉시 / N분 전)을 설정할 수 있습니다.

### 10-4. 발송 기록

**메시지 → 로그**

- 모든 발송 이력이 기록됩니다
- 성공/실패 상태, 수신자, 발송 시간 확인
- 실패한 메시지의 원인 확인 가능

## 15. 전체 업무 흐름 요약

### 새 학기 세팅
```
학생 등록(엑셀) → 알림톡 발송 → 강의 생성 → 수강생 배정 → 차시 추가 → 영상/자료 업로드
```

### 매 수업
```
출결 입력 → 시험/과제 채점 → 성적 저장
                ↓
     불합격 학생 자동 감지 (클리닉 대상)
                ↓
     클리닉 세션 생성 → 학생 배정/예약 → 당일 출석 확인
```

### 시험 운영
```
시험 생성 → 문항 입력 → 정답지 설정 → 학생 공지(알림톡)
    ↓
학생 응시 → 자동 채점 (객관식·수학 숫자 단답) + 수동 채점 (그 외 서술형)
    ↓
합격/불합격 판정 → 불합격 시 클리닉 대상 자동 등록
    ↓
재시험 허용된 경우 → 학생 재응시 가능
```

### 커뮤니티 관리
```
학생 질문 → 교사 답변 → 학생 확인 (알림톡 자동 발송)
공지 작성 → 학생 앱에 즉시 반영
자료 업로드 → 학생 다운로드 가능
```
