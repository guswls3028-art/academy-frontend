# 선생님/관리자 사용 가이드

---

## 1. 시작하기

### 1-1. 로그인
1. 학원 전용 주소(예: tchul.com)에 접속합니다
2. **로그인** 버튼을 누릅니다
3. 아이디와 비밀번호를 입력합니다
4. **로그인**을 누르면 대시보드가 나타납니다

> 💡 비밀번호를 잊었다면 **비밀번호 찾기**를 누르세요. 등록된 전화번호로 임시 비밀번호가 카카오톡으로 전송됩니다.

### 1-2. 화면 구성
- **왼쪽 사이드바**: 모든 메뉴 (접기/펼치기 가능)
- **상단 헤더**: 근무 시간 타이머, 알림 벨, 프로필
- **가운데**: 선택한 메뉴의 내용

### 1-3. 대시보드
로그인 후 첫 화면입니다.

| 항목 | 설명 |
|------|------|
| 미답변 질문 | 학생이 보낸 QnA 중 아직 답변하지 않은 수 |
| 대기 제출물 | 학생이 제출한 성적표/과제 중 처리 대기 건수 |
| 활성 시험 | 현재 진행 중인 시험 수 |
| 알림톡 잔액 | 공용 카카오 알림톡 발송 가능 잔여 건수 |

각 숫자를 클릭하면 해당 페이지로 바로 이동합니다.

상단 왼쪽의 학원 로고·이름은 대시보드 이동을 함께 담당합니다. 별도 홈
아이콘을 중복 배치하지 않아 메뉴 열기와 대시보드 이동을 구분하며, 좁은
화면에서는 로고 표식만 남겨 작업박스·알림·가이드·프로필 버튼을 가리지
않습니다. 각 드롭다운 버튼은 현재 열림 상태를 보조기기에 전달합니다.

## 2. 학생 관리

학생·강의·직원처럼 목록을 다루는 화면은 첫 줄에 총계·검색·주요 추가
작업을, 다음 줄에 필터와 보기 설정을 둡니다. 학생을 선택해야 가능한 엑셀,
태그, 메시지, 비밀번호, 삭제·복원 작업은 선택 전에는 표시하지 않고 선택한
뒤에만 나타납니다. 페이지 이동은 선택 작업과 별개로 계속 표시됩니다.

### 2-0. 학원별 맞춤 컬럼

학생 목록의 **맞춤 컬럼 관리**에서 학원에 필요한 정보를 직접 추가할 수
있습니다. 예: MBTI, 취미, 목표대학, 작년 평균등급, 메가스터디 아이디.

1. 컬럼 이름과 입력 형식(텍스트·숫자·날짜·선택 목록)을 정합니다.
2. 기존 엑셀에서 다른 헤더명을 쓰고 있다면 **엑셀 별칭**에 쉼표로
   구분해 입력합니다.
3. 만든 컬럼은 학생 한 명 등록/수정, 학생 상세, 교사용 모바일, 엑셀
   양식과 내보내기에 함께 표시됩니다.
4. 목록의 **컬럼 표시**에서 선생님마다 필요한 열만 보이게 설정할 수
   있습니다. 이 표시 설정은 현재 브라우저에 저장되며 다른 선생님의
   화면이나 학생 데이터에는 영향을 주지 않습니다.
5. 더 이상 당장 쓰지 않는 컬럼은 **숨기기**를 사용합니다. 학생에게
   입력된 값과 엑셀 연결은 삭제되지 않으며 **다시 사용**하면 복원됩니다.

컬럼 이름을 바꾸더라도 기존 학생 값은 유지되고, 이전 이름은 엑셀
별칭으로 자동 보존됩니다. 이름·전화번호·학교 같은 기본 컬럼명과
겹치는 맞춤 컬럼은 만들 수 없습니다.

### 2-0-1. 업무 화면에서 학생 상세 열기

학생이 업무의 직접 대상인 출결·강의 수강생·성적·과제 제출/결과·클리닉
예약/일정/통과 목록과 수납 현황에서는 학생 이름을 누르면 현재 화면 위에
학생 상세가 열립니다. 클리닉 대상자를 고르는 팝업에서도 이름으로 상세를
확인한 뒤 선택 상태를 잃지 않고 돌아올 수 있습니다. 출결처럼 별도 행 동작이
없는 목록은 이름 외의 행 영역을 눌러도 같은 상세가 열립니다. 학생 관리 화면이
아닌 업무 화면에서는 현재 URL과 업무 도메인을 바꾸지 않고 상세 오버레이만
열리며, 닫기와 브라우저 뒤로가기는 직전 화면과 목록 상태를 그대로 복원합니다.

체크박스, 출결 상태, 점수 입력, 승인·거절, 목록 펼치기처럼 자체 목적이 있는
컨트롤은 학생 상세를 열지 않고 원래 동작만 수행합니다. 서버 응답에 유효한
학생 ID가 없는 항목도 잘못된 학생을 추정하지 않으며 이름을 일반 텍스트로
표시합니다. 상세를 닫으면 직전에 보던 업무 화면과 목록 상태로 돌아갑니다.

상세 헤더는 학생 신원, 아이디·시험코드, 학생 상태, 지원·계정·수정·삭제 작업을 분리해
표시합니다. 상태 버튼은 현재 활성/비활성을 먼저 보여 주고 누르면 반대 상태로
변경합니다. **학생 화면 보기**는 390px 학생앱을 별도 지원 창으로 열며 교직원은
학생이 보는 화면을 직접 조작할 수 있습니다. 이 접속은 학생 로그인으로 남지
않습니다. 대리보기 화면 활동은 교직원 actor로 구분되어 기본 학생 이용 기록에서
제외되고, 지원 시작과 변경 동작은 교직원 감사 기록에 남습니다. 지원 창은 15분 뒤
자동 만료되며 창을 닫으면 그 창에 저장된 access token을 지웁니다.

**계정정보 알림톡**은 저장된 비밀번호를 보여 주는 기능이 아닙니다. 학생·학부모의
새 임시 비밀번호를 발급하고 기존 세션을 무효화한 뒤 승인된 학생/학부모 계정
알림톡으로만 보냅니다. **활동** 탭은 학생이 직접 수행한 로그인, 과제 열람,
영상 열기, 시험 결과 확인을 7일·30일·90일 및 종류별로 확인합니다. 기본 목록은
학생 활동만 최대 100건이며, 필요할 때만 교직원 대리보기 활동을 함께 표시합니다.

수강·시험·과제·클리닉·질문·활동 탭은 선택된 항목을 배경·윤곽과
`aria-selected`로 함께 구분하며, 좁은 화면에서는 가로로 스크롤할 수 있습니다.
클리닉 탭의 이력은 **출석·진행 열기**로 표시되고, 누르면 해당 날짜와 세션이
선택된 클리닉 출석·진행 화면으로 바로 이동합니다.

### 2-1. 학생 등록

**1명씩 등록하기:**
1. 사이드바 **학생** → 오른쪽 상단 **학생 등록**
2. **1명만 등록** 선택
3. 다음 정보를 입력합니다:

| 항목 | 필수 | 설명 |
|------|------|------|
| 이름 | ✅ | 학생 이름 |
| 초기 비밀번호 | ✅ | 학생이 첫 로그인에 사용할 비밀번호 |
| 학부모 전화번호 | ✅ | 010으로 시작하는 11자리. 학부모 아이디 겸 연락처 |
| 학생 전화번호 | 선택 | 입력하면 학생 아이디로 사용. 비워두면 자동 부여 |
| 성별 | 선택 | 남/여 |
| 학교/학년/반 | 선택 | XX고, XX중 입력 시 학교유형 자동 판별 |

4. **등록**을 누르면 바로 저장하지 않고 **학생 등록 최종 확인**에서 이름·로그인 ID·학생/학부모 연락처·학교/학년을 다시 보여줍니다. 비밀번호 값은 다시 표시하지 않으며, **확인하고 등록**해야 학생 명부에 저장됩니다. 이 단계에서는 알림톡이 발송되지 않습니다
5. 삭제 대기 학생과 충돌하면 먼저 **복원**을 사용합니다. **즉시삭제 후 재등록**은 기존 기록을 복구할 수 없고 새 등록 실패 시 삭제만 남을 수 있으므로, 기존·신규 학생 정보를 표시하는 별도 위험 확인을 통과해야 합니다
6. 학생을 실제 강의의 수강생으로 처음 확정하면 학생·학부모에게 계정 안내 알림톡이 한 번 발송됩니다
   - 알림톡 내용: 아이디, 초기 비밀번호 안내, 접속 링크
   - 학부모에게는 학부모 아이디(=학부모 전화번호), 학부모 비밀번호 안내, 학생 아이디/비밀번호가 함께 전송됩니다

> 💡 학부모 아이디는 **학부모 전화번호** 그 자체입니다. 신규 학부모 계정의 초기 비밀번호는 하이픈을 제외한 전화번호 **뒤 4자리**이며, 이미 있는 학부모 계정은 비밀번호가 변경되지 않습니다.

**엑셀로 일괄 등록하기:**
1. **엑셀 업로드** 선택
2. **엑셀 양식 다운로드**를 눌러 현재 활성 맞춤 컬럼까지 포함된 양식 파일을 받습니다
3. 양식에 학생 정보를 작성합니다 (필수: 이름, 학부모전화번호). Excel,
   Google Sheets 및 통합 문서 메타데이터를 비표준으로 저장하는 일부
   프로그램의 `.xlsx`도 업로드 전에 안전하게 호환 처리합니다. 한셀에서
   다시 저장한 파일도 지원하되, 손상 ZIP·XLSX 위장 파일·위험한 XML 선언은
   일반 파일과 동일하게 차단합니다. 표준 파일과 복구 파일 모두 Excel 파서에
   넘기기 전에 `[Content_Types].xml`, 문서 속성, 워크시트와 `.rels` 관계 파일을
   포함한 모든 XML 항목의 개별/전체 크기와 위험 선언을 먼저 검사합니다. 이미지 등
   바이너리 항목은 XML 검사 대상으로 오인하지 않습니다
4. 작성한 `.xlsx` 파일을 업로드합니다 (최대 10MB)
   - 파일을 읽으면 **읽은 학생 / 학생 전화번호 있음 / 없음·식별번호 사용** 인원을 등록 전에 표시합니다
   - 이름 뒤 문자·숫자·괄호는 잘라내지 않고 이름 그대로 저장합니다 (`김지우a`, `김지우1` 등)
   - 기존 학생은 같은 학생 전화번호를 먼저 확인하고, 일치하지 않으면 이름 전체와 학부모 전화번호가 모두 같은 학생을 확인합니다
   - 형제·자매는 같은 학부모 전화번호를 사용할 수 있습니다
   - 학생 전화번호 뒤 4자리 방식을 선택한 상태에서 번호가 없는 학생은 **제외 인원**으로 표시합니다. 모두 등록하려면 공통 비밀번호 또는 학생별 랜덤 비밀번호를 선택합니다
   - 현재 방식으로 등록 가능한 학생이 0명이면 등록 요청을 시작하지 않습니다
5. 신규 학생의 초기 비밀번호 방식을 선택합니다:
   - **학생 휴대폰 번호 뒤 4자리**(기본): 엑셀의 학생 전화번호로 자동 설정
   - **공통 비밀번호 직접 입력**: 4자 이상 입력해 모든 신규 학생에게 동일 적용
   - **학생별 랜덤 비밀번호**: 등록 완료 후 이름·아이디·비밀번호 목록 엑셀이 자동 다운로드(완료 후 1시간 안에 작업박스에서 다시 다운로드 가능)
6. 휴대폰 번호 뒤 4자리 방식을 사용할 때 학생 전화번호가 없는 행은 등록에서 제외됩니다. 나머지 정상 행은 계속 등록됩니다
7. **등록**을 누르면 파일명·전체 행·실제 등록 요청 인원·제외 인원·초기 비밀번호 방식을 보여주는 **학생 일괄 등록 최종 확인**이 열립니다. **N명 등록 요청**을 확인해야 백그라운드 처리가 시작됩니다
8. 처리가 끝나면 큰 **학생 등록 결과** 창이 열립니다. 전체·신규·복원·이미
   등록·확인 필요 인원과 각 Excel 행의 이름/상태를 확인하고, 실패 행은 안전한
   사용자용 사유를 함께 봅니다. 유형별 전체 인원은 10,000건 작업에서도 별도로
   보존하며, 행별 목록은 브라우저 저장을 위해 유형별 최대 500명의 표본으로
   표시합니다. 새로고침해도 1시간 안에는 미확인 결과가 다시 열리며, 닫은 뒤에는
   작업박스의 완료 항목을 눌러 다시 볼 수 있습니다. 390px 모바일 작업박스는
   화면 좌우 안전 여백 안에서 열려 긴 실패 사유의 시작 부분도 잘리지 않습니다
9. 탭을 숨긴 동안 새 작업이 생겨도 서버 폴링은 멈춰 불필요한 요청을 만들지
   않습니다. 탭으로 돌아오면 즉시 다시 확인하며, 새 작업은 이전 장기 작업의 느린
   조회 간격을 물려받지 않습니다

파일이 손상되었거나 이름·전화번호 헤더를 찾을 수 없으면 업로드를 시작할 수 없습니다. 그 외 행별 입력 오류는 정상 학생의 등록을 막지 않으며, 부분 성공은 작업박스에서 실패 작업처럼 빨간색으로 표시하지 않습니다.

엑셀로 새로 만든 학생은 첫 로그인에서 반드시 비밀번호를 변경합니다.

### 2-2. 학생 목록

- **검색**: 이름, 전화번호, 학교명으로 검색. `010-1234-5678`과
  `01012345678`은 같은 전화번호로 정확히 검색됩니다
- **정렬**: 이름, 등록일, 학교 등 기준으로 정렬
- **컬럼 설정**: 표에 보이는 열을 원하는 대로 선택
- **학생 클릭** → 오른쪽에 상세 패널이 열립니다:
  - 기본 정보, 수강 강의, 태그, 메모
  - **시험 탭**에서 1회차부터 최근 회차까지 득점률 추이, 평균·최고·직전 대비 확인
  - 수정, 삭제, 메시지 발송, 비밀번호 초기화 가능

### 2-3. 학생 대량 작업

학생을 체크박스로 선택한 후 상단 도구 모음:

| 버튼 | 동작 |
|------|------|
| 알림톡 보내기 | 선택한 학생/학부모에게 공용 카카오 알림톡 발송 |
| 엑셀 다운로드 | 선택한 학생의 기본 정보와 현재 활성 맞춤 컬럼을 엑셀 파일로 내보내기 |
| 태그 추가 | 분류용 태그(색상 라벨) 일괄 부여 |
| 삭제 | 소프트 삭제 → 30일간 "삭제됨" 탭에 보관 후 자동 삭제 |

### 2-4. 가입 신청 관리

학생이 직접 회원가입한 경우:
1. 사이드바 **학생** → **가입 신청** 탭
2. 대기 중인 신청 목록이 표시됩니다
3. **승인**: 학생 계정이 생성되지만 알림톡은 아직 발송되지 않습니다. 실제 강의의 첫 수강생 등록이 확정되면 계정 안내가 자동 발송됩니다
4. **거절**: 신청이 거절됩니다

> 💡 학원 설정에서 **자동 승인**을 켜면 학생 가입 신청 시 바로 승인됩니다.

## 3. 강의 관리

### 3-1. 강의 생성
1. 사이드바 **강의** → **+ 강의 추가**
2. 입력 항목:

| 항목 | 필수 | 설명 |
|------|------|------|
| 강의 이름 | ✅ | 예: "수학 기초반", "영어 심화반" |
| 과목 | ✅ | 예: 수학, 영어, 과학 |
| 담당 강사 | ✅ | 직원 목록에서 선택 |
| 시작일 | ✅ | 강의 운영 시작일 |
| 종료일 | 선택 | 종료가 정해진 강의만 입력 |
| 수업 시간 | ✅ | 시작·종료 시간을 선택 |
| 색상 | 선택 | 시간표/카드에서 강의 구분용 |
| 아이콘 | 선택 | 강의 딱지에 표시할 2글자 |
| 설명 | 선택 | 강의 운영 메모 |

자주 쓰는 과목은 저장한 뒤 다시 불러올 수 있으며, 저장 목록은 현재 학원에만 적용됩니다. 모바일에서는 담당 강사와 과목이 한 줄씩 배치되고 시간 조정 버튼이 화면 안에 유지됩니다.

3. **등록**을 누르면 강의명·담당·과목·운영 기간·수업 시간을 보여주는 **강의 생성 최종 확인**이 열립니다. **확인하고 만들기**를 눌러야 강의 기본정보가 저장되며, 차시와 수강생은 자동으로 등록되지 않습니다

### 3-2. 수강생 관리

강의 카드를 클릭하면 해당 강의의 상세 페이지가 열립니다.

**수강생 추가:**
1. **수강생** 탭으로 이동
2. **학생 추가** 버튼 클릭
3. 세 가지 방법:
   - **기존 학생 선택**: 등록된 학생 목록에서 검색하여 추가
   - **신규 학생 등록**: 학생 등록 모달에서 바로 등록 후 추가
   - **엑셀 업로드**: 현재 학원의 학생 명부에 이미 등록된 활성 학생만 이름·학부모 전화번호로 찾아 일괄 수강 등록

엑셀 수강 등록에서는 초기 비밀번호를 묻거나 계정을 다시 만들지 않습니다. 학생번호가 적혀 있으면 같은 학원의 학생번호를 최우선으로 찾고, 공란이면 이름과 학부모 전화번호로 찾습니다. `김지우a/b/1/2`처럼 이름 뒤 문자가 다른 학생은 서로 다른 이름으로 처리하며, 형제·쌍둥이의 학부모 전화번호가 같아도 이름이 다르면 중복이 아닙니다. 학생 전화번호 공란도 매칭 실패 사유가 아닙니다. 명부에 없는 학생, 삭제된 학생, 다른 학원의 학생은 생성·복원하지 않으며, 이름·학부모 전화번호까지 같은 활성 학생이 복수이면 임의 학생을 고르지 않고 그 행을 제외합니다. 작업박스는 등록·명부 없음·명부 중복 인원을 구분해 표시하므로, 제외된 학생은 **학생 관리 > 학생 등록**에서 선등록하거나 중복 명부를 정리한 뒤 다시 업로드하세요. 기존 학생의 아이디·비밀번호는 변경되지 않으며, 신규 학생의 초기 비밀번호 선택은 학생 등록 Excel에서만 제공됩니다.

**수강생 목록에서 볼 수 있는 정보:**
- 학생 이름, 전화번호
- 차시별 출결 현황 (매트릭스 형태)
- 메시지 발송, 엑셀 다운로드 가능

### 3-3. 차시(수업) 관리

**차시 추가:**
1. 차시 바에서 **+** 버튼 클릭
2. 자동으로 다음 회차 번호, 날짜(+7일), 시간(강의 시간)이 채워집니다
3. 시간은 30분 간격 목록으로 빠르게 고르거나 **분 단위 직접 입력**으로
   `19:20~22:00`처럼 정확히 설정할 수 있습니다
4. **보강 차시**: 별도로 추가 가능 (날짜/시간 직접 입력)
5. 저장 전 **차시 생성 최종 확인**에서 강의·반·차시 유형·날짜·시간을 검토합니다. 차시만 추가되며 수강생과 출결 상태는 자동으로 등록되지 않습니다

**차시를 선택하면 기본 6개 탭이 나타납니다. 정규 클리닉 모드에서는 정규 클리닉 탭이 추가됩니다:**

| 탭 | 설명 |
|------|------|
| **출결** | 학생별 출석/지각/결석 등 상태 관리 |
| **성적** | 시험/과제 점수 입력 및 조회 |
| **시험** | 시험 생성, 문항 관리, 학생 응시 현황 |
| **과제** | 과제 생성, 제출 현황, 채점 |
| **공지·게시판** | 현재 강의·차시 문맥으로 공지 게시판 열기 |
| **영상** | 수업 영상 업로드 및 관리 |
| **정규 클리닉** | 정규 클리닉반 차시 운영 (정규 클리닉 모드에서만 표시) |

실제 운영 기본 동선은 **강의 목록 → 강의 선택 → 차시 선택 → 성적/시험/과제 탭**입니다. 성적·시험·과제 탭에서도 차시 바가 유지되며, 다른 차시를 누르면 현재 작업 중인 탭(예: 성적)을 유지한 채 해당 차시로 이동합니다.

성적 탭의 **수업결과 알림톡 발송**은 학생별 성적 문구를 먼저 서버에서
검증하고 미리보기를 완성한 뒤에만 발송 버튼을 엽니다. 화면용 성적 변수는
실제 본문과 승인 봉투에 필요한 값만 압축해 전송하며, 검증 실패 시 서버가
반환한 필드 오류를 모달에 표시합니다.

저장한 문구는 다른 업무에서도 다시 사용할 수 있지만, 알림톡 봉투는 현재 진입 화면이
결정합니다. 따라서 성적 화면에서 클리닉 문구를 불러와도 발송 전 미리보기와 실제
도착 메시지는 `성적 안내` 봉투를 유지하며, 장소·날짜·시간이 `-`인 클리닉 안내로
바뀌지 않습니다. 가입·결제처럼 본문과 승인 양식이 고정된 시스템 문구는 예외로 해당
시스템 봉투를 유지하며, 승인 양식이 준비되지 않았으면 발송하지 않습니다.

### 3-4. 강의 종료/복원/삭제

강의 카드의 **⚙️(설정)** 클릭:
- **강의 종료**: "지난강의" 탭으로 이동. 데이터 보존. 언제든 복원 가능
  - 확인 팝업: "강의를 종료하시겠습니까? 종료된 강의는 '지난강의' 탭에서 다시 복원할 수 있습니다."
  - 학생앱의 차시·시험 응시·과제 제출·영상 재생은 즉시 닫힙니다. 학생·학부모는
    접힌 **종료된 강의**에서 과거 성적과 영상 완료/누적 시청 기록만 읽을 수 있습니다.
- **강의 복원**: 지난강의 탭에서 다시 운영 중으로 돌림
- **강의 삭제**: 모든 데이터(차시, 수강생, 출결, 성적) 영구 삭제
  - 확인 팝업: "모든 관련 정보가 제거됩니다"

## 4. 출결 관리

### 4-1. 출결 입력

**강의 → 차시 선택 → 출결 탭**

| 출결 상태 | 의미 | 학생앱 표시 |
|----------|------|-----------|
| 미입력 | 아직 출결을 정하지 않음 | - |
| 현장 | 직접 출석 | 현 |
| 영상 | 온라인 수업 참여 | 영 |
| 보강 | 보강 수업 출석 | 보 |
| 지각 | 지각 출석 | 지 |
| 조퇴 | 조기 퇴실 | 조 |
| 결석 | 미출석 | 결 |
| 출튀 | 출석 후 무단 이탈 | 출 |
| 자료 | 자료만 제공 | 자 |
| 부재 | 장기 부재 | 부 |
| 퇴원 | 퇴원 처리 | 퇴 |

**조작 방법:**
- **수강생 등록**에서 전체 학생·직전 차시·강의 수강생을 불러오면 바로
  저장되지 않고 오른쪽 선택 목록에만 담깁니다. 목록은 되돌리기/다시 실행으로
  검토하고 대상 차시·대표 학생·인원·초기 출결을 보여주는 최종 확인을 거쳐
  저장합니다. 강의 수강 등록이 없으면 함께 생성되고 자동 수납 항목이 배정될 수
  있으며, 이 선택 등록 화면에서 계정 안내 알림톡을 즉시 보내지는 않습니다.
  일반 Enter는 등록을 실행하지 않습니다.
- 차시의 **엑셀로 일괄 등록**도 파일 선택만으로 요청하지 않습니다. 대상 차시·파일명·
  매칭 요청 인원·매칭 기준·초기 출결을 다시 확인한 뒤에만 작업박스 등록을 시작합니다.
  강의 수강이 없던 학생은 수강 등록과 첫 수강 계정 안내 예약이 적용될 수 있지만,
  이 엑셀 등록 경로에서는 자동 수납 항목을 만들지 않습니다.
- 차시에 학생을 일괄 배정하면 처음에는 **미입력**으로 표시됩니다. 학생이
  등원하거나 수업 참여 방식이 확인된 뒤 현장·영상·결석 등을 선택합니다.
- 학생 이름 옆 상태 배지를 클릭 → 팝오버에서 상태 선택
- **전체 현장 출석** 버튼: 퇴원·비활성 학생과 이미 현장인 학생은 건드리지
  않고 나머지를 현장으로 바꿉니다. 성공 후 나타나는 **최근 일괄 출결 작업**의
  되돌리기로 10분 안에 각 학생의 직전 상태를 한 번에 복구할 수 있습니다.
  일부 대상의 현재 상태가 더 이상 현장이 아니면 안전을 위해 전체 되돌리기를
  거부합니다.
- 메모: 각 학생별 출결 메모 입력 가능

### 4-2. 출결 매트릭스

**강의 상세 → 수강생 탭**에서 전체 차시의 출결 현황을 한눈에 볼 수 있습니다.
- 행: 학생
- 열: 차시(1차시, 2차시, ...)
- 셀: 출결 상태 약자(현/영/결/지...)

## 5. 시험 관리

### 5-1. 시험 생성

**차시 → 시험 탭 → 시험 추가**

처음 화면에서 목적에 맞는 생성 방식을 선택합니다.

| 생성 방식 | 사용할 때 |
|-----------|-----------|
| **시험 설정해서 만들기** | 채점 방식과 점수 기준을 먼저 정하고, 원본은 지금 또는 나중에 등록할 때 |
| **빠르게 여러 개 만들기** | 시험명·만점·커트라인만 입력해 여러 시험을 만들 때 |
| **이전 시험 가져오기** | 저장된 시험지 양식을 불러올 때 |
| **다른 차시에서 복사** | 다른 차시의 양식을 독립된 시험으로 복사할 때 |

**시험 설정해서 만들기**에서는 시험명, 만점, 커트라인과 아래 채점 방식을
선택합니다. 원본 파일은 선택 사항입니다. 현장에 원본이 없으면 시험부터 만든 뒤
시험 상세의 **시험 자료 업로드**에서 나중에 추가할 수 있습니다.

| 채점 흐름 | 운영 방식 |
|-----------|-----------|
| OMR 자동채점 | 학생 답안을 인식해 정답과 대조하고, 인식 오류는 OMR 검토에서 보정 |
| 직접 채점 | 종이에서 채점한 정오 또는 점수를 조교가 학생별로 입력 |
| OMR + 직접 채점 | 앞쪽 선택형은 OMR, 나머지 문항은 직접 입력 |

종이에서 채점을 마친 뒤 학생별 O/X만 서버에 기록할 시험은 문제 모양이
객관식이어도 **직접 채점**을 선택합니다. 직접 채점 문항이 있으면
**정오 입력(O/X/오답노트)** 또는 **점수 입력(부분점수)**을 선택합니다. 혼합형은
OMR로 채점할 앞쪽 문항 수도 입력합니다. 시험 문항이 생성된 뒤에는 채점
방식과 선택형 경계를 바꿀 수 없습니다.

**시험 자료 올리기** 한 화면에서 파일 역할을 섞지 않고 다음처럼 선택합니다.

- **문제지(필수)**: 답 표시가 없는 학생용 문제 원본
- **정답지(선택)**: 문항 번호와 정답이 적힌 원본
- **해설지(선택)**: 선생님 풀이·수식·필기가 있는 원본

정답지와 해설지는 각각 별도 선택 칸에 올립니다. 파일명이나 올린 순서로 역할을
추정하지 않습니다. 한 파일 뒤쪽에 정답·해설이 함께 있는 통합 원본은 문제지만
올려도 되지만, 현장에 별도 정답지/해설지가 있으면 함께 올리는 편이 번호 인식과
검수가 명확합니다.

실행 파일·스크립트·브라우저 실행 형식을 제외한 안전한 원본은 확장자와 관계없이
파일당 최대 50MB까지 받습니다. PDF·PNG·JPG/JPEG·HWP/HWPX는 자동 문항 분리를
시도합니다. 그 밖의 형식도 원본을 그대로 보관하며 시험 상세에서 문항과 해설을
직접 등록해 검수할 수 있으므로 PDF로 다시 만들 필요는 없습니다.
템플릿의 **OMR 답안지** 첨부도 같은 방식으로 안전한 원본 형식을 받으므로
PDF로 변환하지 않고 DOCX·PPTX·HWP/HWPX·이미지 등을 그대로 올릴 수 있습니다.
PDF/이미지/HWP/HWPX 조합에서는 문제·정답·해설의 **표시된 문항 번호만** 연결하고
임의 순서로 맞추지 않습니다. 완료되면 **문항·정답·해설 맞춤 확인**에서 문제,
인식 정답, 선생님 원본 해설을 함께 확인해 번호·정답을 수정하거나 제외한 뒤
확정합니다. 필기·수식·그림은 OCR 문장으로 대체하지 않고 원본 페이지 링크/이미지를
보존합니다. 자동 인식이 일부만 되면 `부분 인식`, 누락 번호와 불일치 원본을 명시하며
인식된 항목만 후보로 보여 줍니다. AI가 선생님 해설을 새로 쓰거나 문장을 바꾸지
않습니다. 그 전에는 채점 문항·정답이 되지 않습니다. `문항 분리 중`에는 기다리고,
부분 인식·실패 안내가 나오면 원본을 직접 확인하거나 같은 세 역할로 **다시 처리**할
수 있습니다. 기존 문항이나 성적이 있는 운영 시험의 원본은 자동으로 덮어쓰지 않습니다.

한 HWP/HWPX에 본문 문제와 번호별 미주 해설이 함께 있으면 파일 하나만 올릴 수
있습니다. 서버는 미주 번호를 연결 키로 사용해 본문의 문자·수식·삽화를 답 표시
없는 문제 이미지로 만들고, 같은 번호의 미주 원본 그림은 해설로 따로 보존합니다.
검수 화면에 **한글 본문·미주 분리** 표시가 나오며 새 후보에는 해설 이미지를 잘라
쓰는 문제 영역 슬라이더가 없습니다. 일부 미주 그림이나 본문 문항을 완전하게
재현하지 못하면 성공으로 표시하지 않고 원본을 보관한 뒤 직접 등록·검수를
안내합니다.

| 항목 | 설명 |
|------|------|
| 시험명 | 예: "1차 중간고사", "단원평가 3장" |
| 총점 | 시험 만점 (예: 100) |
| 합격점 | 이 점수 이상이면 합격 (예: 60) |
| 재시험 허용 | 켜면 학생이 불합격 시 재응시 가능 |
| 최대 응시 횟수 | 재시험 포함 총 응시 가능 횟수 |
| 학생 성적 공개 | 켜면 학생·학부모 성적 목록과 분석에 표시, 끄면 교직원만 확인 |
| 정답 공개 | 학생에게 정답을 보여줄지 여부 |
| 채점 흐름 | OMR 자동채점 / 직접 채점 / OMR + 직접 채점 |
| 직접입력 방식 | 정오 입력(O/X/오답노트) 또는 문항별 점수 입력 |
| 앞쪽 선택형 문항 수 | 혼합형 시험에서 OMR로 채점할 앞쪽 문항 수 |

**문항 추가:**
- **답안 등록 → 문항별 유형**에서 전체 문항 수를 입력한 뒤 각 번호를 눌러 객관식/단답형을 지정하고 **유형 저장**을 누릅니다.
- 유형 순서는 자유롭습니다. 예를 들어 1번 객관식, 2번 단답형, 3번 객관식으로 구성할 수 있습니다.
- 객관식: 5지선다 (정답 번호 지정)
- 수학 단답형: 정답을 `0~999` 정수로 등록하면 자동 채점
- 그 외 주관식/서술형: 정답 텍스트와 교사 수동 채점
- 서술형: 교사가 수동 채점

**정답지 등록:**
- 정답 번호를 한 번에 입력할 수 있습니다 (클릭 한 번으로 붙여넣기)
- 배점도 문항별로 설정 가능
- OMR 답안지는 객관식과 숫자 단답형을 별도 영역에 배치하지만 각 행에 원래 시험 번호를 표시하므로 섞인 문항 순서도 그대로 채점됩니다.

### 5-2. 시험 운영

신규 시험은 생성 즉시 차시에 연결되어 운영됩니다. 시험 단위 **종료** 버튼은 현재 운영 UI에서 사용하지 않습니다.

- 학생별 응시/미응시/채점/검토 상태는 **성적 탭 점수 셀과 제출관리**가 기준입니다.
- 시험·과제 목록 순서는 성적 탭의 컬럼 순서와 동일하게 표시됩니다.
- PC에서는 시험·과제 헤더를 끌어 순서를 바꾸고, 모바일에서는 헤더의 **이전/다음**
  화살표를 사용합니다. 첫 항목과 마지막 항목은 이동할 수 없는 방향과 이유를 표시하며,
  저장 실패 시 화면 순서를 유지하므로 같은 버튼으로 다시 시도할 수 있습니다.
- **학생 성적 공개**를 끄면 채점과 교직원 성적표는 유지하면서 학생·학부모의 점수,
  문항별 결과, 추이와 분석만 공개 전 상태로 둡니다. 상단 점검선에서 현재 공개 여부를
  확인하고 바로 설정으로 이동할 수 있습니다.
- 정답 공개 여부는 **정답 공개** 설정으로 별도 관리합니다.
- DRAFT/OPEN/CLOSED 값은 기존 데이터 호환용 상태 필드이며, 신규 운영 흐름의 주 조작 단위가 아닙니다.

**제출함에서 미식별 제출 확인:**

1. **성적 → 제출함 → 대기 중**에서 파일명·형식·크기를 먼저 확인합니다.
2. **제출물 확인**을 누르면 이미지는 큰 미리보기로 확인합니다. PDF와 화면에서 바로
   볼 수 없는 파일은 **새 창에서 원본 열기**로 확인한 뒤 확인란을 직접 선택합니다.
3. 파일 주소를 받았더라도 이미지가 실제로 열리기 전에는 학생 지정으로 넘어가지
   않습니다. 로드 실패 시 오류와 재시도를 표시하며, 실제 파일이 확인될 때까지
   지정 버튼을 잠급니다.
4. 확인이 끝나면 **확인하고 학생 지정**으로 학생을 연결합니다. 파일 정보가 없는
   제출은 잘못 추정하지 않고 파일 없음 상태를 명시합니다.
5. 미리보기 주소는 제출 번호를 기준으로 서버가 같은 학원 교직원에게만 짧게 발급합니다.
   저장소 파일 주소나 원본 객체 키를 입력값으로 재사용하지 않으며, 권한·파일 확인이
   실패하면 학생 지정도 함께 잠깁니다.

### 5-3. 채점

- **객관식**: 정답지 기준으로 자동 채점
- **수학 숫자 단답형**: `0~999` 정답지 기준으로 자동 채점 (`007`과 `7`은 같은 답)
- **그 외 주관식/서술형**: 교사가 직접 점수 입력
- 채점 결과: 합격/불합격 자동 판정 (합격점 기준)

#### OMR 검토와 직접 채점 워크스페이스

**차시 → 성적 탭 → 시험명**을 누르면 시험 설정에 따라 **정오표 작성** 또는
**문항별 점수 입력**, **OMR 검토**, **시험 설정**을 한 메뉴에서 고를 수 있습니다.

- OMR 자동채점: **OMR 검토**를 열어 인식이 틀린 학생 답안을 보정하고
  재채점합니다. 상단 **OMR 답안 등록**에서 현재 시험의 스캔 파일을 바로
  추가할 수 있으며, 답안이 하나도 없을 때는 같은 등록 동선을 안내합니다.
  직접 채점표에서 O/X를 덮어쓰지 않습니다.
- 시험 **제출관리**에서 완료된 답안의 **보기**를 누르면 제출 번호 기준의
  권한 확인된 미리보기를 새 창으로 엽니다. 연속으로 눌러도 같은 요청과 창을
  중복 생성하지 않으며, 열기에 실패한 창은 닫고 해당 동작의 오류를 한 번만
  안내합니다. 저장소 객체 키를 미리보기 요청에 사용하지 않습니다.
- **식별 필요** 답안은 **식별하기**를 눌러 그 답안이 선택된 OMR 검토로 바로
  이동합니다. 현재 시험 목록에 실제 답안 번호가 없으면 목록의 첫 답안을
  선택하므로 다른 시험 답안을 추정해 열지 않습니다.
- 스캔이 옆이나 거꾸로 보이면 중앙 도구의 왼쪽·오른쪽 회전으로 90도씩
  돌립니다. 현재 방향은 0/90/180/270도로 표시되고 이미지와 문항 영역 표시가
  함께 회전합니다. 회전은 화면 확인용이며 답안·좌표·원본 파일에는 저장되지
  않고 다른 제출을 선택하면 0도로 초기화됩니다.
- 정오표 작성: 학생별 O/X/오답노트를 기록하는 **정오 직접입력**을 엽니다.
- 문항별 점수 입력: 서답형의 부분점수를 문항별로 입력합니다.
- 혼합 채점: OMR 문항은 잠그고 직접 채점 문항만 입력합니다.
  채점표 상단의 **이 시험 작업**에서 현재 시험의 **OMR 답안 등록**과
  **OMR 결과 보정**을 열 수 있습니다.
  OMR 검토를 닫으면 뒤의 직접 채점표도 최신 정오·점수로 다시 조회됩니다.
- 시험의 채점 방식과 맞지 않는 작업은 메뉴에서 비활성화됩니다. **시험 설정**에서
  `OMR 자동채점`, `정오표 직접입력 (O/X/오답노트)`, `문항별 점수 직접입력` 중
  실제 운영 방식을 고를 수 있습니다. 저장하면 메뉴의 사용 가능한 작업이
  즉시 바뀝니다.
- 채점 방식 전환은 기존 문항·정답·입력된 성적을 삭제하지 않습니다.
  OMR에서 정오표로 바꾼 뒤 새 정오를 확정하면 그 값이 성적과 오답노트에
  반영됩니다. 다시 OMR로 바꾸면 기존 결과는 보존되지만 정오표는 잠기고
  OMR 등록·검토 흐름을 사용합니다.
- 혼합형 시험은 기존 객관식/직접 채점 문항 구성을 유지한 채 직접 문항의
  입력 방식을 정오 또는 점수로 바꿀 수 있습니다. 문항 생성 뒤에는 혼합형의
  객관식 경계 자체를 바꾸지 않습니다.

OMR 등록 창에는 현재 시험명이 표시됩니다. 다른 시험을 다시 고르지 않고
현재 시험에만 파일을 올리므로 잘못된 시험에 등록하는 실수를 줄입니다.
직접 채점표에 확정하지 않은 변경이 있거나 OMR 답안을 수정 중이면 OMR 등록·
보정 전환은 잠깁니다. 먼저 저장하거나 초기화한 뒤 이동합니다. 등록 창을
닫으면 OMR 검토 목록, 직접 채점표, 성적표를 다시 조회합니다.

기존 **시험 → 채점·결과**에서도 OMR 검토와 직접 채점이 같은 기준으로
분리되어 있습니다.

**학생별 결과**의 등수는 첫 응시의 1차점수 기준입니다. 재시험이나 점수 정정으로
현재 최종점수가 달라지면 1차점수 아래에 `최종 N`을 함께 표시하므로 등수와
최종점수의 관계를 바로 확인할 수 있습니다. 이름 검색, 결과 상태 필터와
등수·1차점수·최종점수·이름 정렬을 사용할 수 있으며, 수동·엑셀로 반영한 확정
점수는 별도 제출 기록이 없어도 **완료**로 표시됩니다.

1. 학생의 **응시/결시**를 확인합니다. 일부 학생의 답안만 먼저 받았다면
   **전원 결시로 설정**을 누른 뒤 제출한 학생만 다시 **응시**로 바꿉니다.
   이 버튼은 확정 전 초안만 바꾸며, **실행 취소**나 **전체 초기화**로
   되돌릴 수 있습니다.
2. 각 문항 머리글의 **객관식·단답형·서술형** 배지로 시험지의 문항
   순서를 확인합니다. 유형은 한 시험 안에서 자유롭게 섞일 수 있습니다.
3. 정오 방식이면 첫 입력칸에 자동으로 초점이 잡힙니다. 셀을 누르거나
   키보드 `O`, `X`, `0`(오답노트 기본 단축키)을 입력하면 다음 칸으로
   자동 이동합니다. 한글 입력 상태에서도 같은 위치의 영문·숫자 물리키를
   인식하므로 채점 중 한/영 키를 바꿀 필요가 없습니다. 화면에는 각각
   **O**, **X**, **노트**로 표시됩니다. 빠르게 연속 입력해도 각 키는
   한 칸씩 순서대로 반영됩니다.
   입력 버튼이나 캡슐을 따로 누르는 방식이 아니라 셀 전체가 입력면이며,
   현재 셀은 성적입력 표와 같은 굵은 테두리로 표시됩니다.
   - `O`: 정답, 문항 만점, 오답노트 제외
   - `X`: 오답, 0점, 오답노트 포함
   - `오답노트`: 정답과 문항 만점은 유지하지만 다시 볼 문제로 오답노트에 포함
   - 표 위의 **− / +**로 70~120% 사이에서 배율을 바꾸고, **화면 맞춤**으로
     현재 창 너비에 맞춥니다. 직접 고른 배율은 이 기기의 브라우저에 저장됩니다.
     학생 이름과 응시 열은 고정되며 표 안에서만 가로·세로로 이동합니다.
   - 방향키: 상하좌우 이동, `Tab`: 오른쪽, `Shift+Tab`: 왼쪽
   - `Enter`: 아래, `Shift+Enter`: 위
   - `Backspace`/`Delete`: 입력 지우기, `Shift+?`: 단축키 설정 열기
   - Windows·Linux의 `Ctrl+Z`/`Ctrl+Shift+Z`, Mac의
     `⌘Z`/`⌘Shift+Z`: 실행 취소/다시 실행
   - Windows·Linux의 `Ctrl+S`, Mac의 `⌘S`: 입력 내용 확인, 확인 완료
     후에는 성적 확정. 브라우저의 페이지 저장 창은 열리지 않습니다.
   - 틀린 문항과 오답노트 문항부터 표시한 뒤 **빈칸 N칸 O로**를 누르면
     응시 학생의 남은 미입력 칸만 정답으로 채웁니다. 기존 O/X/오답노트는
     바꾸지 않으며 한 번의 실행 취소로 되돌릴 수 있습니다.
   - **단축키 설정**에서 정답·오답·오답노트 키를 원하는 한 글자로 바꿀 수
     있으며 현재 기기의 브라우저에 저장됩니다. 서로 같은 키나 이동
     전용 키는 지정할 수 없습니다.
   - 엑셀이나 Ymath 표에서 여러 셀을 복사해 시작 셀에 붙여넣을 수
     있습니다. 빈칸/`O`/`정답`은 정답, `X`/`.`/`오답`은 오답,
     `오답노트`/`노트`는 정답이면서 오답노트에 포함, `-`는 미입력으로
     읽습니다. 기존 엑셀 호환을 위해 숫자 `0`과 `복습`도 같은 값으로
     읽습니다. 알 수 없는 값이 하나라도 있으면 아무 셀도 바꾸지 않고
     위치를 안내합니다.
4. 점수 방식이면 0점부터 문항 만점 사이의 점수를 셀에 바로 입력합니다.
   셀을 열면 기존 값이 전체 선택되고, 정오 방식과 마찬가지로
   `Tab`·`Enter`·방향키로 이동합니다. 만점 문항도 **오답노트**를 켜면
   오답노트에 포함할 수 있습니다.
5. **입력 내용 확인**으로 학생 수, 결시, 계산 점수와 덮어쓸 기존
   결과를 확인합니다. 이 단계에서는 통계가 바뀌지 않습니다.
6. 오류가 없을 때 **성적 확정**을 눌러 한 번에 반영합니다.

자동채점 문항의 O/X와 점수는 직접 채점표에서 읽기 전용입니다. 인식 오류는
OMR 검토에서 학생 답안을 고치면 정오·점수·통계가 다시 계산됩니다.

각 문항 번호 아래의 배점을 수정하면 모든 학생의 계산 점수가 즉시
갱신됩니다. **배점 합계 + 시험 가감점 합계**가 시험 만점과 같아야
미리보기와 확정이 가능합니다. 다른 화면에서 배점이 먼저 바뀌었다면
확정을 중단하고 최신 값을 다시 불러옵니다.

문항이 여러 개면 **배점 빠른 입력**을 열어 문항 순서대로 값을 붙여 넣을 수
있습니다. 쉼표·띄어쓰기·줄바꿈으로 구분하며 문항 수와 합계가 맞을 때만 한 번에
적용됩니다. 일괄 적용은 실행 취소/다시 실행에서도 한 작업으로 처리됩니다.

**문항 구성·정답**은 현재 작업을 확정하거나 전체 초기화한 뒤 열 수
있습니다. 여기서 문항 수, 순서, 유형, 정답과 배점을 함께 관리하고 닫으면
정오표가 최신 구성으로 다시 조회됩니다.

직접 채점 시험에 문항이 하나도 없으면 채점 표에서 다음 중 하나를 선택합니다.

- 객관식 위주 시험은 **객관식 답안 등록**으로 기존 답안 등록 화면을 엽니다.
- 문항 수와 정오만 먼저 입력할 시험은 **문항 수로 바로 시작**에서
  문항 수를 넣어 채점 표를 만든 뒤, 같은 표의 문항 머리글에서 배점을
  조정합니다.

혼합형의 선택형 셀은 수정할 수 없습니다. OMR 채점을 먼저 마쳐야
답변형 점수를 확정할 수 있으며, 확정해도 기존 선택형 OMR 결과는
보존됩니다. 선택형 답안 오류는 **OMR 결과 보정**에서 수정합니다. 다른
직원이나 탭에서 같은 학생의 결과가 바뀌면 확정을
중단하므로 **다시 불러오기** 후 최신 표에서 작업합니다.

- 확정 전에는 **실행 취소/다시 실행**으로 개별 작업을 되돌리거나,
  **전체 초기화**로 마지막 서버 저장 상태를 다시 불러올 수 있습니다.
- 불러오기 실패 화면에서는 **다시 불러오기**를 사용할 수 있습니다. 미리보기나
  확정이 실패해도 실제 성적은 일부만 저장되지 않습니다.
- 확정 후 다시 열면 저장한 O/X/오답노트 또는 부분점수와 오답노트 지정 상태가 그대로 표시됩니다.

#### 직접 채점한 결과를 엑셀로 넣기

**시험 → 채점·결과 → 엑셀로 채점 결과 넣기**에서 사용합니다.

1. **전용 양식 받기**를 눌러 시험 학생과 문항 번호가 들어 있는 엑셀을 내려받습니다.
2. 학생별로 틀린 문항만 `X`로 표시합니다. 정답은 빈칸 또는 `O`로 둡니다.
   - 기존 Ymath 표의 문항 셀 `.`은 오답, 숫자 `0`은 정답이지만
     오답노트에 넣을 복습 문항으로 읽습니다.
   - Ymath 표의 응시 여부 열에 있는 `.`은 결시로 읽습니다.
   - 전 문항이 비어 있으면 만점과 결시를 자동으로 구분할 수 없으므로 **응시 여부** 열에서 `응시` 또는 `결시`를 선택합니다.
   - 선택하지 않은 전 문항 공란 행은 미리보기에서 안내되며, 확인 전에는 성적을 반영할 수 없습니다.
3. 엑셀을 선택하면 학생·문항·점수를 먼저 확인합니다.
4. 오류가 없으면 **결과 반영**을 눌러 저장합니다.

- 객관식과 단답형이 섞인 시험도 문항 번호 기준으로 함께 반영됩니다.
- 기존에 쓰던 채점표도 이름(또는 학생 연락처)과 `1, 2, 3…` 문항 열이 있으면 확인할 수 있습니다.
- 학급별 시트처럼 학생이 겹치지 않는 여러 시트는 함께 읽습니다. 같은
  학생이 겹치는 후보 시트가 둘 이상이면 임의로 고르지 않고 오류를
  표시합니다.
- 동명이인이나 같은 연락처가 있으면 전용 양식의 `수강등록ID`로 정확히 구분합니다.
- 기존 결과가 있는 학생은 확인 화면에 표시되며, 반영 시 새 엑셀 내용으로 갱신됩니다.
- 결시 학생은 상세 인원 기록에는 남지만 점수·석차·평균·합불·문항 통계에 0점으로 들어가지 않습니다. 누적 미응시가 있는 학생 이름에는 음영이 유지되며, 마우스를 올리면 누적 횟수를 확인할 수 있습니다.
- 결시를 잘못 선택한 경우 같은 학생의 정상 문항 결과를 다시 반영하면 해당 시험의 결시 상태가 해제됩니다.

## 6. 성적 관리

### 6-1. 성적 입력 (엑셀식)

**차시 → 성적 탭**

1. 필요하면 성적 탭 상단의 **성적 도구 → 시험 추가/과제 추가**
2. 점수가 하나도 없는 첫 성적표는 바로 입력하고, 기존 점수가 있으면 **수정**을 누름
3. 표에서 학생별 시험/과제 점수를 입력
   - `Tab`은 오른쪽 칸, `Shift+Tab`은 왼쪽 칸, `Enter`는 같은 열의 아래 학생으로 이동
   - 시험 미응시·과제 미제출은 `/`를 입력한 뒤 `Tab` 또는 `Enter`로 확정하며, 상태를 저장한 뒤 선택한 방향으로 계속 이동
   - 응시·제출 대상에 들어가지 않은 칸은 `-` 대신 **미배정**으로 표시되며, 키보드 이동에서 자동으로 건너뜀
   - 셀을 벗어나면 실제 성적에 자동 저장
   - `Ctrl+S`: 입력 중인 셀까지 즉시 저장
   - `Ctrl+Z`: 마지막 셀 변경 실행 취소
   - `Ctrl+Shift+Z` 또는 `Ctrl+Y`: 다시 실행
4. 입력을 마치면 **저장하고 잠금**을 눌러 완료

**과제 만점과 합격 기준:**

- 과제 만점은 과제마다 따로 지정합니다. 문제 수가 다른 과제는 각각 실제
  만점을 입력하며, 성적표의 **만점 표기**에는 `점수/해당 과제 만점`이
  표시됩니다.
- 합격 기준은 과제마다 따로 지정합니다. 같은 차시에 과제가 여러 개 있어도
  각 과제에서 퍼센트/원점수 기준과 값을 독립적으로 저장할 수 있습니다.
- **원점수 기준**을 사용하면 커트라인은 해당 과제 만점 이하여야 합니다.
  이미 입력된 최고 점수나 해당 과제의 원점수 커트라인보다 만점을 낮추면 기존
  성적을 임의로 바꾸지 않고 저장을 막습니다.

- 현재 탭은 배경·윤곽·굵은 글자로 함께 표시됩니다. 버튼은 기본·마우스 올림·선택·비활성·잠금 상태에서도 글자와 배경이 구분되며, 키보드로 이동하면 포커스 윤곽이 보입니다.
- 상단의 **OMR 스캔 등록·수정·성적 도구**는 한 작업 묶음으로, 선택 학생 대상 일괄 기능과 입력 잠금 상태는 각각 별도 영역으로 표시됩니다.
- 성적표 도움말은 선택·입력 도구와 같은 줄 오른쪽에 배치됩니다. 화면이 좁으면
  도구와 도움말이 자연스럽게 다음 줄로 내려갑니다.
- 잠금 상태에서는 점수 셀이 수정되지 않아 실수 입력을 막습니다. 다시 바꾸려면 **수정**을 누릅니다.
- 점수가 하나도 없는 첫 입력에서는 바로 수정 상태로 열립니다. **저장하고 잠금**을 누른 뒤에는 자동으로 다시 열리지 않습니다.
- 셀을 확정하면 즉시 자동 저장을 시작하며, 자동 저장이 실패해도 입력값은 유지됩니다.
- 이전 작업이 비정상 종료되어 복구할 입력이 있으면, 복원하거나 버리기 전에는 발송·출력을 사용할 수 없습니다.
- 같은 차시는 한 번에 한 화면에서만 수정할 수 있습니다. 다른 직원이나 탭에서 수정 중이면 저장 후 잠글 때까지 기다린 뒤 **다시 확인**을 누릅니다.
- 아직 바꾼 점수가 없는 자동 수정/수정 상태에서 **OMR 스캔 등록**을 누르면 빈 입력 잠금을 안전하게 마치고 OMR 등록을 엽니다. 실제 점수 변경이나 복구 대기 입력이 있으면 먼저 저장·잠금 또는 복구 여부를 결정해야 합니다.
- 학생 상세의 재시험 점수와 답안 보정도 **수정** 상태에서만 가능합니다.
- 상단에 **응시·제출 배정 누락** 안내가 보이면 시험·과제별 누락 칸 수를 확인할 수 있습니다. **누락 전부 배정**을 누르면 현재 차시 수강생을 모든 시험·과제 대상으로 보강한 뒤 점수를 입력할 수 있습니다.
- **표시 옵션 → 마지막 열**에서 기존 **종합 판정**을 유지하거나 **테스트 오답**으로 바꿀 수 있습니다. Ymath는 테스트 오답이 기본이고, 다른 학원은 기존 종합 판정을 그대로 유지합니다. 직원의 명시적 선택은 테넌트·직원별로 현재 브라우저에 저장되어 다른 차시와 재접속에도 유지됩니다.
- **테스트 오답**은 점수가 만점보다 낮은지만 보는 것이 아니라 실제 저장된 교사 오답 확인 상태를 표시합니다. 오답 확인이 남았으면 `미완료`, 모두 끝났으면 `완료`, 미응시·미채점은 `채점 대기`, 만점 시험만 있으면 `오답 없음`으로 보입니다. 점수나 답안이 바뀌면 완료 확인은 안전하게 미완료로 돌아갑니다.
- **테스트 오답**을 선택하면 현재 이름 검색 범위의 `전체·미완료·채점 대기·처리됨` 인원수가 함께 표시됩니다. `처리됨`은 오답 확인 완료와 오답 없음을 함께 모아 후속 조치가 안 남은 학생을 뜻합니다. 상태를 누르면 해당 학생만 표에 남고, **현재 결과 선택**은 검색과 상태 필터에 보이는 학생만 기존 선택 목록으로 정확히 교체합니다.
- 학생 필터는 다른 차시나 재접속에 남지 않고 항상 **전체**에서 시작합니다. 빈 상태에서는 검색어나 필터를 바꾸라는 안내가 표시되며, 점수 수정 중에는 아직 저장되지 않은 값으로 대상을 잘못 선택하지 않도록 **현재 결과 선택**을 사용할 수 없습니다.
- 표시에는 성적 조회 API의 시험별 `correction_status`만 사용하며 과제와 클리닉 상태는 포함하지 않습니다. 설정 저장이 차단된 브라우저에서도 현재 화면 전환은 동작하고, 다음 접속에는 해당 학원의 기본값으로 돌아갑니다. 이 설정은 기존 성적·클리닉 대상 데이터를 변경하지 않습니다.
- 교사 모바일의 **성적 입력**에서는 학생 이름 검색과 `확인 필요·처리됨·채점 대기` 필터, 처리율을 함께 봅니다. 비만점 학생의 `오답 미완료/오답 완료`를 누르면 즉시 저장되고, 미저장 점수 초안이 있으면 점수를 먼저 저장하도록 안내합니다. **성적 → 조회**의 상태 옆 **수정**은 해당 시험의 정확한 차시 성적 입력으로 이동합니다.
- 학생 결과 드로어 우측 위의 **교사 통과**는 현장에서 오답 해결을 확인했을 때
  사용합니다. 필수 사유를 남겨 켜면 25점 같은 원점수는 그대로 두고 초록색
  `교사 통과`로 표시되며 재시험·자동 Clinic 미통과 대상에서 제외됩니다. 과제의
  **교사 완료**도 점수·제출 파일을 바꾸지 않고 같은 방식으로 완료만 확정합니다.
  학생·학부모 화면에는 사유 없이 `교사 확인 완료` 상태만 보입니다.
- 성적표에서 학생 행을 연 뒤 오른쪽 패널의 **학생 이름**을 누르면 현재 성적 화면을
  유지한 채 메인 학생 목록과 같은 학생 상세 오버레이가 열립니다. 닫으면 선택한
  학생 성적 패널로 돌아옵니다. 학생 ID가 없는 레거시 행은 잘못된 학생을 추정하지
  않고 이름만 표시합니다.
- 다른 탭에서 먼저 처리한 경우 저장을 중단하고 최신 상태를 다시 불러오라는 오류를
  표시합니다. 완료를 해제하면 현재 원점수·제출 상태로 Clinic 대상이 즉시 재평가됩니다.
  실제 재시험/과제 통과 이력은 교사 토글보다 강한 근거이므로 해제로 되돌리지 않습니다.
- 학생·학부모 성적 보드는 `전체·확인 필요·처리됨` 시험 필터와 시험 상세의 `테스트 오답` 안내를 읽기 전용으로 제공합니다. 교사 비고와 완료 시각은 노출하지 않습니다.
- 390px 화면에서 **테스트 오답**을 선택하면 네 학생 필터가 2×2로 배치되고 **현재 결과 선택**은 한 줄 전체 너비를 사용합니다. 학생 이름은 고정하고 출석 열은 함께 스크롤되어 오답 배지가 가려지지 않습니다. 회귀 검증은 `e2e/admin/score-entry-autosave.spec.ts`가 미완료·완료·오답 없음·채점 대기, 과제 제외, 테넌트 기본값, 명시적 직원 설정, 검색·선택 조합과 모바일 노출을 함께 확인합니다.

**성적 도구:**
- OMR 스캔 등록: 여러 시험 중 대상을 골라 올릴 때 성적 탭 상단에서 사용
- 시험명 → OMR 검토: 현재 시험의 답안을 등록하거나 인식 결과를 보정할 때 사용
- 엑셀 다운로드: 성적표를 파일로 내보내기
- 성적표 출력: 학원 로고·브랜드색이 적용된 교사용 전체 현황을 A4 가로
  페이지에 맞게 자동 분할해 PDF로 다운로드
- 개인 성적표: **성적 도구 → 개인 성적표**에서 한 명 또는 여러 명을
  선택하고 `요약 1쪽` 또는 `상세 2쪽 이상`을 한 PDF로 다운로드
- 클리닉 대상: **성적 도구 → 클리닉 대상**에서 해당 차시의 공식 대상자 명단을
  미리 보고 A3 PDF로 다운로드합니다. 대상 여부와 시험/과제 구분은 서버의 현재
  미해소 `ClinicLink`를 그대로 사용하며, 점수 표를 브라우저에서 다시 판정하지
  않습니다. 명단에는 `현장 출석·지각·보강` 학생만 포함하고 `영상(ONLINE)` 학생은
  제외합니다. 출결 조회가 실패하면 전체 수강생으로 대체하지 않고 생성 중단과
  **다시 시도**를 표시합니다.
- 학생 이름 클릭 → 오른쪽 드로어에서 개별 성적 상세, 시험 이력 확인

**판정 상태 읽기:**

- **미입력**: 아직 점수나 제출 결과가 없어 합격·미달을 판정할 수 없는 상태
- **검수 대기**: OMR 인식 보정이나 교사의 오답/과제 확인이 남은 상태
- **미달**: 점수가 입력되고 검수도 끝났지만 합격 기준에 미달한 상태
- **클리닉 대상**: 미해결 클리닉 후속 조치가 실제로 등록된 상태
- **미응시 확인**: 시험 미응시가 감지됐지만 면제·후속 조치가 아직 확정되지 않아
  실제 클리닉 대상과 분리한 상태. 이 수치는 클리닉 대상 인원에 합산하지 않습니다.
- **통과**: 현재 입력과 검수가 모두 끝나고 기준을 충족한 상태

학생 상세의 `현재 상태`와 종합 목록은 위 상태를 섞지 않고 항목별로 보여줍니다.
상세는 우측 위 닫기 버튼이나 `Esc`로 닫을 수 있습니다. 오답 확인·과제 검사 저장이
거부되면 서버가 알려준 사유가 그대로 표시되며, 실패한 상태는 화면에서 완료로 바뀌지
않습니다. 저장이 성공하면 새로고침 응답을 기다리는 동안에도 완료 상태를 즉시 유지합니다.
시험 점수·답안을 같은 값으로 다시 동기화한 경우에는 완료가 풀리지 않으며, 실제 점수나
답안 내용이 바뀐 경우에만 검수 대기로 돌아가 재확인을 요청합니다.

**수업 중간 분석 전달하기:**

1. 시험의 **채점·결과**에서 `이번 수업에서 바로 결정할 것`을 확인합니다.
2. 수업 방향·컷 검토·바로 할 일을 먼저 읽고 점수 분포와 보충 우선 문항으로
   근거를 확인합니다. 분석은 채점이 확정된 학생의 석차 기준 1차 점수와 현재 대표
   문항 결과만 사용합니다. 제안은 참고용이며 시험 컷이나 학생 판정을 자동으로 바꾸지 않습니다.
3. 신민쌤 등 수업 담당자에게 전달할 때는 **수업 분석 리포트 (엑셀)**을 누릅니다.
   한 파일에 브리핑, 점수 분포, 문항 우선순위, 학생별 등수와 답안이 들어갑니다.
4. 학생별 오답만 따로 전달하려면 **학생별 틀린 문항 (엑셀)**을 사용합니다.

미응시·채점 중·채점 실패·미확정 결과는 평균과 합격률에 넣지 않으며, 합격 컷이
`0`이면 전원 합격이 아니라 **기준 미설정**으로 안내합니다. 수동 통과나 재시험 통과는
원점수를 바꾸지 않고 **보충 완료**로 따로 셉니다. 만점이 100점이 아닌 시험도 득점률
구간으로 분포를 비교합니다. 전체 문항은 **전체 문항 통계 보기**를 펼쳐 확인합니다.

**개인 성적표 만들기:**

1. **차시 → 성적 탭 → 성적 도구 → 개인 성적표**를 누릅니다.
2. 오른쪽 학생 목록이나 이전/다음 버튼으로 미리볼 학생을 바꿉니다.
   표에서 학생을 미리 선택했다면 그 학생들이 출력 대상으로 선택됩니다.
3. 빠른 전달은 **요약 1쪽**, 누적 시험 기록·문항별 득점·상담 체크포인트까지 필요하면 **상세 2쪽**을 선택합니다.
4. 체크박스로 필요한 학생을 더 선택하거나 **전체 선택**을 누릅니다.
5. 미리보기를 확인한 뒤 **N명 성적표 PDF**를 누르면 학생별 페이지가
   순서대로 들어간 한 파일로 내려받아집니다.

- 현재 차시의 시험·과제·출결과 같은 강의의 누적 시험 기록만 사용합니다.
- 문항별 정오답이 아니라 저장된 문항별 득점(만점·부분득점·0점)을 표시합니다.
- 각 학생의 A4 페이지는 따로 렌더링되며, 긴 차시·시험명은 누적 기록 열 안에서
  줄바꿈됩니다. 점수·환산·판정과 머리글·꼬리글은 페이지 안전 영역 안에 유지됩니다.
- 저장되지 않은 점수가 있으면 먼저 저장한 뒤 최신 성적으로 성적표를 구성합니다.

**학생별 누적 추이 확인:**

1. 여러 학생을 비교할 때는 **성적 → 성적 콘솔 → 학원 시험**으로 이동합니다.
2. 바로 아래 **전체 결과 / 정규수업 / 보강수업** 탭에서 범위를 고릅니다. **전체 결과**는 `구분 필요`를 포함한 모든 학원 시험 기록입니다. 선택한 범위는 상단 요약, 학생 목록, 득점·변화 필터와 정렬, 선택 학생의 추이와 시험 기록에 모두 적용됩니다.
3. 각 탭의 `N건`은 현재 기간·강의·검색·학년 조건에 해당하는 시험 결과 건수입니다. 키보드에서는 좌우 방향키와 `Home`·`End`로 범위를 바꿀 수 있고, 시험 행의 `정규`·`보강` 배지로도 유형을 확인할 수 있습니다.
4. 시험이 정규와 보강 차시에 함께 연결됐거나 차시 연결이 없으면 `구분 필요`입니다. 잘못된 유형으로 섞지 않기 위해 **전체 결과**에서만 보입니다.
5. 한 학생의 전체 이력을 바로 볼 때는 **학생 → 학생 선택 → 시험 탭**으로 이동합니다. 시험 탭의 **전체 / 정규 수업 / 보강** 범위를 바꾸면 회차별 추이와 시험 목록이 함께 바뀝니다. 각 범위의 시험 건수와 시험 행의 `정규`·`보강` 배지로 분류 근거를 확인할 수 있으며, `구분 필요` 시험은 전체에서만 보입니다. 선생님 화면에서도 **학생 → 학생 선택 → 시험** 순서가 같습니다.
6. 범위 안에서 점수가 확정된 서로 다른 시험이 시간순으로 `1회차, 2회차, 3회차…` 자동 누적됩니다. 새 시험을 따로 등록할 필요는 없습니다.
7. 만점이 다른 시험은 득점률(%)로 환산해 비교하며, 마우스를 올리면 원점수와 시험·강의·차시 정보를 확인할 수 있습니다.
8. 여러 강의를 수강하는 학생은 강의 칩으로 추이를 좁혀 볼 수 있습니다. 한 시험이 같은 유형의 여러 차시에 연결된 경우 유형은 유지하지만 특정 차시를 임의로 표시하지 않습니다. 미응시 시험은 이력에는 남지만 0점으로 간주해 평균이나 추이선을 낮추지 않습니다.
9. 보관된 시험도 과거 이력에서 유지되며 `보관됨`으로 구분됩니다.
10. **성적 통계 다운로드**를 누르면 화면에 선택한 기간·강의·학년·득점·변화·검색
    조건에 맞는 학생 전체를 CSV로 받습니다. 현재 보이는 목록 페이지만 저장하지
    않으며, 파일은 한글 이름이 깨지지 않는 형식으로 내려받습니다. 학생명·학교명처럼
    외부에서 들어온 문자열의 수식·제어문자 시작은 일반 텍스트로 저장하고, 정상적인
    음수 점수 변화는 숫자로 유지합니다.

분류와 API의 기술 계약은
[`backend/docs/domain/student-performance-console.md`](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/student-performance-console.md)를
참고합니다.

### 6-2. 오답노트 만들기

1. **차시 → 성적 탭**에서 학생 이름을 누르고 **오답노트 만들기** 탭을 엽니다.
2. **이번 시험**은 현재 시험만, **회차 범위**는 시작~종료 회차의 틀린 문항을
   회차별로 모읍니다. 종료를 비우면 시작 회차부터 현재까지입니다.
3. 수록 문항, 문제 이미지와 **선생님 해설** 표시를 확인합니다.
4. **PDF** 또는 **한글 HWPX**를 고른 뒤 오답노트 만들기를 누릅니다.
5. 다운로드 버튼이 나타나면 파일을 열어 학생에게 전달하거나 인쇄합니다.

문제 사진이 비어 있으면 해당 문항도 답안 정보와 함께 수록됩니다. 사진까지 넣으려면
해당 시험의 **시험 설정 → 답안 등록 → 이미지 등록**에서 문항별 문제 이미지를 붙이고
**이미지·해설 저장**을 누릅니다. 이후 다시 만들면 저장한 이미지가 자동 반영됩니다.

재채점이나 대표 재시험 결과에서 정답으로 바뀐 문항은 누적 오답에서 자동으로 빠집니다.
직접 채점에서 **오답노트**로 지정한 문항은 정답·만점이어도
오답노트에 `정답 · 오답노트 지정`으로 남습니다. 오답노트 지정을 해제하면
오답이 아닌 문항은 다음 오답노트에서 빠집니다.
한 번에 최대 100문항까지 만들 수 있으므로 누적 오답이 더 많으면 **이번 시험** 범위로
나누어 다운로드합니다.

문서 앞쪽은 답 없는 문제와 풀이 공간이고, **정답 및 해설** 표지 뒤에 정답과
선생님이 원본에 작성한 해설이 나옵니다. HWPX는 문제·해설 원본 이미지를 보존하며
제목, 정답, **내 풀이 메모**, **추가 메모** 문단은 한글에서 수정할 수 있습니다.
원본 이미지 안의 필기·수식 자체를 편집 가능한 개체로 바꾸지는 않습니다.
세로로 긴 필기 해설은 글씨 크기를 유지하도록 내용 경계에서 여러 쪽으로 나뉘고,
문제 길이에 따라 풀이 공간의 높이가 자동으로 조절됩니다.
정오표의 화면·키보드·반응형 계약과 현재 기능 경계는
[정오표·오답노트 프론트엔드 계약](GRADING-WRONG-NOTE-WORKFLOW.md)을 참고합니다.

채점·권한·저장 API의 기술 계약은
[`backend/docs/domain/exam-grading.md`](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/exam-grading.md)를
참고합니다.

### 6-3. ⭐ 성적과 클리닉의 연결 (핵심!)

**이것이 시스템의 핵심 흐름입니다:**

```
시험 응시/채점 → 성적 계산 → 불합격 판정 → 클리닉 대상자 자동 지정
                                              ↓
                              교사 확인 → 클리닉 세션 배정 → 학생 예약
                                              ↓
                              학생 출석 → 재시험/과제 통과 → 다음 차시 진행
```

**자동 클리닉 대상자 지정 조건:**

성적이 저장되면 시스템이 자동으로 다음을 확인합니다:

| 조건 | 설명 | 예시 |
|------|------|------|
| **시험 불합격** | 시험 점수 < 합격점 | 40점 / 합격점 60점 → 클리닉 대상 |
| **OMR 신뢰도 낮음** | OMR 인식 시 2개 이상 문항이 확신도 부족 | 마킹이 불분명한 답안 |
| **반복 오답** | 같은 문항을 2회 이상 응시에서 연속 틀림 | 재시험에서도 같은 문제를 틀림 |
| **차시 미이수** | 영상 시청 부족(<90%), 시험 불합격, 과제 미제출 | 종합적으로 차시 완료 조건 불충족 |

**이 중 하나라도 해당하면 학생은 자동으로 "클리닉 대상자"가 됩니다.**

## 7. 클리닉 관리 (보충 학습)

### 7-1. 전체 흐름

```
① 시험/과제 채점 → 불합격 학생 자동 감지
     ↓
② 교사: 클리닉 → 오늘에서 "이번 주 미예약 학생" 확인
     ↓
③ 교사: 클리닉 세션 생성 (날짜, 시간, 장소, 정원)
     ↓
④ 학생 배정: 교사가 수동 배정 또는 학생이 직접 예약
     ↓
⑤ 클리닉 당일: 미등원 → 등원/지각 등원 → 하원 순서로 운영
     ↓
⑥ 재시험/과제 통과 또는 교사 수동 처리로 클리닉 요건 해소
```

### 7-2. 클리닉 대상자 확인

**클리닉 → 미통과**

- **클리닉 대상자** 테이블이 표시됩니다
- 각 대상자 정보:

| 항목 | 의미 |
|------|------|
| 학생 이름 | 클리닉이 필요한 학생 |
| 차시명 | 어떤 수업에서 미달됐는지 |
| 사유 | "점수 미달", "미응시", "미제출" 또는 "OMR 신뢰도" |
| 시험·과제 점수 | 실제 받은 점수. 미응시·미제출은 점수 대신 상태 표시 |
| 합격 기준점 | 넘어야 하는 점수 |
| 처리 상태 | 진행중 / 통과 / 면제 / 이월 |

- 학생별 보기는 학생 ID 기준으로 묶으므로 여러 강의를 수강해도 학생 수가 중복 집계되지 않습니다
- 점수 미달 항목에서는 재시험 점수를 입력하거나 통과·면제·이월 처리할 수 있습니다
- 과제의 통과 기준은 해당 과제의 개별 기준을 먼저 표시합니다. 퍼센트 기준은
  `%`, 원점수 기준은 `점`으로 구분하며 같은 과제를 시험 점수로 중복 표시하지
  않습니다
- **미응시·미제출**은 0점과 구분해 `판정 대기`로 보입니다. 시험 미응시는 유효한
  클리닉 링크가 있어도 일반 통과할 수 없고 **면제**만 허용합니다. 이전 수업 결석 등
  정당한 사유를 필수로 남기며, 면제는 점수 합격으로 바꾸지 않고 별도 이력으로
  보존되어 `해결 완료 포함`에서 다시 확인할 수 있습니다
- 문자·사진·종이처럼 사이트 밖으로 이미 제출한 **미제출 과제**는
  **제출 확인·완료**를 누르고 확인 사유를 2자 이상 남길 수 있습니다. 저장 성공 뒤
  서버 목록을 직접 다시 조회해 같은 미해결 항목이 빠졌는지 확인합니다. 그대로 남아
  있거나 재조회가 실패하면 창을 닫거나 성공으로 알리지 않으며, 이력에는 `수동 통과`와
  사유가 보존됩니다
- 예약 승인 또는 클리닉 대상이 로딩 중이면 인원 KPI는 `—`로 표시합니다. 조회가
  실패하면 0명·전원 통과로 표시하지 않고
  **확인 실패**와 **다시 시도**를 보여 줍니다. 재시도 후 실제 빈 결과를 받았을 때만
  `승인 대기 예약이 없습니다` 또는 `진행중 항목이 없습니다`를 표시합니다
- 세션 생성의 반·강의 목록이나 학생 배정의 대상자·전체 학생 목록을 불러오지
  못하면 빈 선택으로 저장하지 않습니다. 해당 목록의 **다시 시도**가 성공한 뒤에만
  클리닉 저장 또는 대상자 확정을 계속할 수 있습니다

### 7-3. 예약 일정과 클리닉 세션 생성

**클리닉 → 일정·배정**

1. 월요일부터 일요일까지 한 주의 세션·예약 인원·학생 명단을 한 화면에서 확인합니다. 상단의 7칸 **주간 날짜 선택**에는 날짜와 개설 시간대 수가 표시되며, 원하는 날짜를 누르면 아래 일정 보드의 해당 날짜 열로 바로 이동합니다. 모바일에서도 날짜 선택은 한 화면에 유지되고 일정 보드만 가로로 이동합니다
2. 각 날짜 맨 위의 **첫 시간대 만들기** 또는 **시간대 추가**를 클릭합니다. 이미 세션이 있는 날짜에도 계속 추가할 수 있어 토요일 13시·17시·19시처럼 여러 수업을 운영할 수 있습니다
3. 입력 항목:

| 항목 | 필수 | 설명 |
|------|------|------|
| 제목 | 선택 | 예: "수학 보충", "영어 재시험" |
| 시간 | ✅ | 시작 시간 (예: 14:00) |
| 시간(분) | ✅ | 소요 시간 (기본 60분) |
| 장소 | ✅ | 예: "보충학습실 A", "3층 교실" |
| 정원 | ✅ | 최대 참가 인원 |
| 대상 학년 | 선택 | 전체/1학년/2학년/3학년 |
| 대상 학교유형 | 선택 | 전체/고등/중등 |
| 대상 강의 | 선택 | 특정 강의 수강생만 |

4. **클리닉 만들기** 버튼을 누르면 아직 저장되지 않고 **클리닉 일정 최종 확인**이 열립니다. 연도·날짜·요일, 이름, 시작·종료 시간, 장소, 정원, 공개 대상 강의의 대표 이름과 즉시 배정 학생의 대표 이름·인원을 확인합니다
5. 잘못 입력한 항목이 있으면 **다시 확인**으로 돌아가 수정합니다. 내용이 맞을 때만 **확인하고 만들기**를 눌러 저장합니다
6. 성공 메시지와 주간 일정 카드를 확인합니다

기존 일정은 해당 카드 상단 정원 옆 톱니바퀴 **일정 수정**을 눌러 날짜·시간·장소·정원을 바꿉니다. **클리닉 일정 수정 확인**에서 일정뿐 아니라 이름·정원·공개 대상의 변경 전·후 값을 비교한 뒤 **확인하고 수정**해야 저장되며, **다시 확인**을 누르면 수정 폼으로 돌아갑니다. 일정이 과거에 종료된 강의를 대상으로 삼았더라도 수정 확인에서는 해당 강의명을 그대로 보여 주되 새 대상으로 다시 선택할 수는 없습니다. 생성·수정 요청부터 즉시 학생 배정과 목록 갱신이 끝날 때까지 중복 저장과 창 닫기가 잠깁니다. 예약자가 있는 일정을 바꾸면 운영 화면으로 이동해 변경 전·후 내용을 보여주며, 필요한 경우 **수정 알림 보내기**로 보호자에게 안내할 수 있습니다.

> 💡 미통과 대상자를 먼저 선택해도 정원은 선택 인원으로 줄어들지 않습니다. 예를 들어 3명을 배정하고 정원 10명으로 만들면 나머지 7명은 학생 앱에서 예약할 수 있습니다.

> 💡 같은 날짜의 세션은 시작 시간순으로 표시됩니다. 날짜 머리글의 **시간대 수**와 전체 예약/정원을 먼저 확인한 뒤 각 카드에서 학생을 배정하세요.

> 💡 반복 일정은 **이전 주 불러오기**로 같은 요일에 한꺼번에 만들거나, 세션 카드의 **복사**로 시간·장소·정원 설정을 불러와 새로 만들 수 있습니다. 학생 명단은 복사되지 않습니다. 다른 주를 보고 있을 때 상단 **클리닉 만들기**는 그 주의 월요일을 기본 날짜로 엽니다. 결석 확인 뒤 **새 클리닉 만들기**를 누르면 선택한 날짜의 생성 창이 바로 열립니다.

### 7-4. 학생 배정 방식

**방법 1: 교사가 수동 배정**
- 예약 일정의 세션 카드에서 **학생 추가** 클릭
- **미통과 대상자** 또는 **전체 학생** 명단에서 이름을 검색해 한 명 이상 선택
- 한 학생이 여러 강의를 수강하면 이름은 한 행에 한 번만 나오고, 학생이 설정한
  아바타 옆에 해당 강의 딱지가 모두 붙습니다. 선택 인원도 학생 기준으로 셉니다
- 여러 페이지에서 고른 학생의 이름은 선택 창을 닫았다 다시 열어도 확정 전까지
  유지되며, 최종 일정 확인에도 실제 이름으로 표시됩니다
- 두 탭은 `수강 ID`와 `학생 ID`가 달라 탭을 바꾸면 기존 선택이 초기화됩니다
- 세션에 배정하면 바로 **"예약됨(booked)"** 상태가 됩니다
- 학생 앱의 "내 일정"에 즉시 반영됩니다

**방법 2: 학생이 직접 예약**
- 학생이 앱에서 클리닉 → 예약하기에서 날짜표와 세션을 선택해 예약합니다
- **자동 승인 설정**에 따라:
  - 자동 승인 **켜짐**: 예약 즉시 확정 (booked)
  - 자동 승인 **꺼짐**: "대기(pending)" 상태 → 교사가 승인/거절 필요

### 7-5. 클리닉 요건 해소 규칙

| 상황 | 클리닉 요건 상태 |
|------|----------------|
| 학생 예약/교사 배정 | ❌ 미해소 유지 — 일정 연결만 생성 |
| 등원/지각/결석/하원 처리 | ❌ 미해소 유지 — 현장 운영 기록만 변경 |
| 자율학습 완료 | ❌ 미해소 유지 — `completed_at` 학습 완료 기록만 변경 |
| 재시험 통과 | ✅ 시험 대상 해소 |
| 과제 통과 | ✅ 과제 대상 해소 |
| 결과 카드의 교사 통과/교사 완료 | ✅ 원점수·제출 보존, 사유와 감사 이력 보존 |
| 클리닉 목록의 면제 | ✅ 점수 합격과 구분한 면제 사유·이력 보존 |
| 다음 차수 이월 | 현재 항목 종료 후 다음 차수 대상으로 생성 |

> ⚠️ **핵심**: 예약·등원·하원·자율학습 완료와 학습 요건 해소는 별도 상태입니다. `completed_at`은 자율학습 완료이고 하원 시각은 별도 `checked_out_at`입니다. 어떤 운영 버튼도 시험/과제 미통과를 자동 해소하지 않습니다.

> 💡 화면 높이가 낮거나 모바일인 경우 클리닉 만들기·과제 만들기 같은 긴 모달의
> 본문을 안에서 스크롤하세요. 브라우저 배율을 줄이지 않아도 하단 동작까지 접근할
> 수 있습니다.

### 7-6. 클리닉 홈 (당일 운영)

**클리닉 → 오늘**

- 오늘 예정된 클리닉 세션이 타임라인으로 표시됩니다
- 오늘 날짜와 세션 수, **예약 자동 승인** 상태를 같은 운영 카드에서 확인합니다
- 각 세션에서:
  - 예약 학생 목록 확인
  - **등원/지각 등원/재촉/결석/하원** 처리
  - 등원·하원 알림톡 수신자를 학생/학부모/둘 다 중 선택
  - 재촉은 1회 또는 사용자 간격 반복. 반복 종료는 같은 날 최대 22:00
  - 결석은 Enter로 확정하고 Esc로 취소하며, 이후 기존 일정 이동 또는 새 일정 생성
  - 메모 작성
- **대기 승인**: 학생이 신청한 예약 중 승인 대기 건이 있으면 상단에 표시됩니다

### 7-7. 클리닉 패스카드

**클리닉 → 패스카드**

- 합격 학생 패스카드의 배경 3색을 직접 지정하거나 랜덤으로 배치합니다
- **매일 자동으로 색상 바꾸기**를 켜면 날짜 기준 3색이 자동 적용됩니다
- **학생 화면에 적용**을 누르면 현재 학원 학생 패스카드에 반영됩니다
- 선생님 모바일 화면에서는 **메뉴 → 패스카드 색상**에서 같은 3색을 즉시 바꿀 수 있습니다
- 클리닉 대상 학생은 지정색 대신 검은색 경고 화면으로 표시됩니다

### 7-8. 클리닉 운영 콘솔

**클리닉 → 출석·진행**

- 처음 열면 **현장** 범위가 선택되어 16시·17시·18시 등 여러 시간대에서 지금
  등원해 있는 학생을 한 명단으로 보여줍니다. 시간대는 학생을 찾기 위한 별도 화면이
  아니라 `전체 시간 / 16:00 / 17:00 / 18:00` 보조 필터입니다. **오늘 전체**를
  선택하면 미등원·결석·승인 대기까지 당일 참가자를 함께 확인할 수 있습니다.
- 현장 학생은 해당 날짜에 `등원` 또는 `지각 등원` 처리되어 체크인 시각이 있고 아직
  하원하지 않은 경우만 포함됩니다. 자율학습 완료나 시험·과제 통과만으로 현장에서
  빠지지 않으며 **하원 처리** 뒤에만 현장 명단에서 제거됩니다. 조회 중·오류 중에는
  `현장 0명`으로 확정하지 않고 스켈레톤 또는 다시 시도를 표시합니다.
- 상단 **일정**을 누르면 월 캘린더와 세션 목록이 학생 큐 위에 겹쳐 열립니다. 목록
  폭이나 스크롤 위치를 밀지 않으며 Esc로 닫으면 **일정** 버튼으로 돌아갑니다.
  390px에서는 전체 높이 오버레이 안에서 이전/다음 날짜와 해당일 세션을 빠르게
  바꿉니다.
- 오른쪽은 현장 또는 선택 날짜의 학생 운영 큐입니다. 통합 범위에서는 각 학생 행에
  실제 클리닉 시간·장소가 표시됩니다. 학생 한 명을 고정 높이 한 줄로 표시하고
  `오늘 n / 미완료 n`과 최근순 시험·과제 항목을 같은 크기의 카드로 가로로 나열합니다.
  최신 항목이 왼쪽이며 학생마다 보이는 카드 수로 남은 처리량을 바로 비교합니다. 목록 안에는
  반복 점수 입력 폼을 두지 않습니다.
- 같은 학생이 여러 시간대에 등록돼도 `student_id` 기준 한 줄만 보이고, 이름이 같은
  다른 학생은 합치지 않습니다. 한 줄 안의 시간·장소 칩으로 exact 클리닉 일정을
  고릅니다. 여러 participant가 모호한 상태에서는 첫 일정을 임의로 사용하지 않으며
  출결·하원·오늘 할 일은 시간대를 직접 고른 뒤에만 실행됩니다.
- 시험·과제 항목을 누르면 화면 이동 없이 해당 학생의 **클리닉 작업대**가 열립니다.
  상단 항목 전환기로 다른 미완료 항목을 바꾸되, 아래에는 현재 항목 하나의 점수 입력,
  수동 통과·면제·다음 차수 이월만 표시합니다. Esc로 닫으면 누른 항목으로 돌아갑니다.
- 학생이 미제출 과제를 온라인으로 끝냈거나 문자 사진·현장에서 별도로 제출했다면
  출석/불참과 관계없이 해당 과제 카드의 **온라인·문자 제출 확인·완료**를 누릅니다.
  과제명과 강의·차시가 맞는지 확인하고 확인 경로를 2자 이상 남긴 뒤 완료를 확정합니다.
  제출 점수가 아직 없는 과제도 같은 확인 경로를 사용하며, 실제 점수가 저장된 항목만
  일반 점수 통과로 처리합니다.
  서버에서 해당 과제가 실제로 해소됐다는 재조회가 확인되어야 카드가 사라집니다.
  이 작업은 학생을 출석으로 바꾸거나 하원·세션 완료를 만들지 않습니다. 미응시 시험에는
  이 버튼과 일반 수동 통과를 제공하지 않으며 사유를 기록한 면제만 허용합니다. 아직
  `clinic_link_id`가 없는 미응시 시험도 차시·수강·시험이 모두 확인되면 목록에서 숨기지
  않고 면제할 수 있지만, 미해결·미응시(`NOT_SUBMITTED`) 상태이고 양수인 차시·수강·시험·
  원본 식별자가 있으며 시험과 원본 식별자가 같을 때만 허용합니다. 이 대상은 오늘 할 일·
  재시험·이월·일반 통과에는 사용하지 않습니다. 이 식별자 계약을 만족하지 못한 링크 없는
  미응시 항목은 처리 목록과 KPI 집계에서도 제외합니다.
- **오늘은 이 항목 처리**는 조교가 그날 확인할 범위를 고르는 기능입니다. 선택 결과는
  참가자 단위로 서버에 저장되어 새로고침 뒤에도 유지됩니다. 저장이 거부되면 일부만
  바꾸지 않고 기존 범위를 유지합니다. 저장 성공 뒤 참가자 목록을 다시 읽고 같은
  `clinic_link_id` 항목과 포커스를 유지합니다.
  - 참가자별 `미등원 → 등원/지각 등원 → 하원` 상태 레일. 하원은 등원한 학생에게만 활성화
  - 결석으로 먼저 처리한 학생도 등원 또는 지각 등원으로 즉시 정정 가능
  - 등원·하원은 클리닉 날짜·시간·장소와 실제 처리 시각을 포함한 알림톡을 선택한 수신자에게 요청. exact 승인 템플릿이 없으면 다른 문자나 템플릿으로 대체하지 않음. 상태 저장과 알림톡 요청 결과는 따로 표시하며, 상태 저장 실패와 알림톡 요청 실패가 동시에 생겨도 둘 다 같은 피드백에 건수로 표시하고 성공 팝업을 띄우지 않음
  - 재촉은 1회/반복과 간격·종료 시각을 선택하며 22:00 이후와 날짜를 넘는 예약은 거부
  - 결석은 키보드 Enter/Esc 확인 뒤 1회 알림톡을 요청하고, 기존 일정 이동 또는 새 일정 생성으로 연결
  - 미통과 항목(어떤 시험·과제에서 기준을 통과하지 못했는지) 표시
  - 문자·사진·종이로 제출한 미제출 과제는 **제출 확인·완료**와 2자 이상 사유로
    완료하고, 시험 미응시는 일반 통과 대신 면제만 사용
  - 한 학생이 여러 활성 강의를 수강하면 예약에 연결된 한 강의만 고르지 않고,
    모든 강의의 아직 해결되지 않은 클리닉 할 일을 최근 생성 순으로 전부 표시.
    원본 시험·과제명, 단원/범위, 차시는 학생 행의 한 줄 레일과 작업대에서 확인
  - 하원(`checked_out_at`), 세션 처리 완료(`completed_at`), 시험·과제 해소,
    오늘 할 범위는 서로 다른 상태이며 어느 버튼도 다른 상태를 대신 변경하지 않음
  - 학생 이름 클릭 → 학생 상세 오버레이
- 참가자 또는 시험·과제 대상 조회 중에는 0명·전원 처리·자율 학습으로 확정 표시하지
  않고 스켈레톤이나 `—`를 보여줍니다. 대상 조회 오류는 학생 사유로 가짜 항목을 만들지
  않고 오류와 **다시 시도**를 표시합니다.
- 참가자 pagination 객체는 현장/오늘 전체 모두 `next`가 필수이며 `next: null`에서만
  끝납니다. `next` 누락·반복 링크·중복 참가자·취소된 요청은 일부 학생을 정상 명단처럼
  표시하지 않고 전체 조회 오류로 처리합니다.
- 대상 조회가 성공했지만 진행중 항목이 0건이면 예약 당시의 과거 클리닉 사유만으로
  가짜 미통과 항목이나 완료 버튼을 다시 만들지 않습니다.
- 통합 현장 범위에서는 일정 수정·삭제, 학생 추가, 전체 출석, 변경 알림처럼 한
  세션에만 안전한 동작을 숨깁니다. 해당 동작은 날짜/시간대를 좁혀 단일 세션
  문맥에서만 사용합니다.
- 모바일의 범위·시간대 레일과 상단 클리닉 탭은 한 줄 가로 스크롤이며, 작업대는 전체 높이로 열리고
  문서 가로 넘침 없이 항목 레일만 내부 스크롤합니다. 모션 줄이기 설정에서는 전환
  애니메이션을 사용하지 않습니다.

## 8. 영상 관리

### 8-1. 영상 업로드

**사이드바 → 영상**

1. 왼쪽 트리에서 강의 → 차시를 선택
2. **영상 추가** 클릭
3. 업로드 방식을 선택합니다
   - **파일 업로드**: MP4, MOV 등 파일을 끌어놓거나 파일 탐색기에서 여러 개를 한 번에 선택합니다
   - **YouTube 링크**: 공개 또는 일부공개 YouTube 주소를 붙여넣습니다
4. 선택한 영상은 파일명에서 확장자를 뺀 값이 제목으로 미리 입력됩니다. 각 영상 제목은 업로드 전에 따로 수정할 수 있습니다
5. 업로드 목록의 위→아래가 학생에게 보일 재생 순서입니다. 끌기 또는 위·아래 버튼으로 순서를 바꾸면 그 순서로 저장되며, 인코딩 완료 순서 때문에 바뀌지 않습니다
6. 파일 업로드는 업로드 진행률이 표시되고, 완료 후 자동으로 인코딩이 시작됩니다. 초기화에 실패한 파일은 제목과 순서를 유지한 채 목록에 남아 다시 시도할 수 있습니다
7. 이미 등록한 영상이 2개 이상이면 영상 목록 상단의 **재생 순서 바꾸기**에서 다시 배치할 수 있습니다
8. YouTube 링크 영상은 인코딩 없이 바로 시청 가능 상태로 추가됩니다
9. 워터마크와 건너뛰기는 각각 `허용` 또는 `금지`로 현재 상태가 표시됩니다. 라벨이나 상태 버튼 어디를 눌러도 값이 즉시 전환되며, 저장되는 영상 정책에 반영됩니다

### 8-2. 영상 처리 상태

| 상태 | 의미 | 학생 시청 |
|------|------|----------|
| 대기 중 (PENDING) | 업로드 직후 | ❌ |
| 처리 중 (PROCESSING) | 인코딩 진행 중 | ❌ |
| 완료 (READY) | 인코딩 완료 | ✅ 시청 가능 |
| 실패 (FAILED) | 인코딩 오류 | ❌ 재시도 필요 |

- 실패 시 **재시도** 버튼으로 다시 시도할 수 있습니다
- 실시간 진행률 저장소가 재시작되거나 일시적으로 연결되지 않아도 작업박스는 같은 학원의 영상 상세 상태를 제한된 간격으로 다시 확인합니다. 완료·실패가 확인되면 자동으로 종결하고, 아직 처리 중이면 상세 상태를 확인 중이라는 안내를 표시합니다. 화면 이동, 학원 전환, 작업 삭제 뒤 도착한 이전 조회 결과는 현재 작업에 반영하지 않습니다
- YouTube 링크 영상은 실패 재시도/인코딩 대상이 아니며, 학생 목록에서 **YouTube 링크**로 표시됩니다
- 30분 이하 영상: 빠른 처리 (보통 수 분)
- 30분 초과 영상: 별도 처리 (최대 수 시간)

### 8-3. 영상 상세

영상 카드를 클릭하면:
- 조회수, 좋아요 수, 댓글 수
- 학생별 시청 현황 (누가 얼마나 봤는지)
- 영상 공개/비공개 설정
- 시청 제한: 자유 시청 / 1회 제한 / 차단
- 워터마크 표시 여부
- 삭제 (확인 팝업 → 6개월 보관 후 영구 삭제)

## 9. 커뮤니티

### 9-1. 공지사항

**커뮤니티 → 공지사항**

**공지 작성:**
1. **+ 추가** 버튼 클릭
2. 제목 입력
3. 내용 작성 (리치 텍스트 에디터: 굵게, 이탤릭, 링크, 이미지 삽입 가능)
4. **등록** 클릭

- 공지 범위: 전체 공지 / 특정 강의 공지 / 특정 차시 공지
- 학생 앱의 공지사항 탭에 즉시 반영됩니다
- 좁은 화면에서는 범위 트리, 글 목록, 상세/작성 영역이 위에서 아래로
  이어지므로 가로 스크롤 없이 각 영역을 순서대로 확인할 수 있습니다.
- 데스크톱에서는 세 영역을 화면 높이 안에 유지하고, 공지 목록이 길면
  가운데 목록 안에서 스크롤하므로 빈 상세 영역이 목록 길이만큼 늘어나지 않습니다.

### 9-2. QnA 답변

**커뮤니티 → QnA**

1. 왼쪽에 학생 질문 목록이 표시됩니다
   - 미답변 질문 수는 왼쪽 사이드바의 **커뮤니티** 배지와 QnA 목록에 함께 표시됩니다
   - 첫 답변을 등록하면 해당 질문이 답변 완료로 바뀌고 미답변 수가 즉시 줄어듭니다
   - 삭제된 학생의 질문은 "삭제된 학생" 표시
2. 질문을 클릭하면 데스크톱 큰 화면 왼쪽에 문제 사진, 오른쪽에 답변 작성 영역이
   열립니다. 사진은 좌우 90도 회전, 확대·축소, 원본 열기를 지원합니다.
3. 모바일에서는 **문제 보기 / 답변 작성** 탭으로 같은 작업을 전환합니다.
4. 오른쪽 입력란에 답변을 작성합니다
5. **답변 등록** 클릭 (또는 Ctrl+Enter)
6. 자동발송 설정이 켜져 있으면 학생에게 알림톡이 발송됩니다

### 9-3. 상담

**커뮤니티 → 상담**

- QnA와 같은 형태이지만 상담 요청 전용입니다
- 학생/학부모의 수업 시간 변경, 상담 요청 등을 처리합니다

### 9-4. 게시판 / 자료실

- **게시판**: 자유 게시판 관리 (글 작성, 수정, 삭제, 댓글)
- **자료실**: 학습 자료 업로드 (PDF, 이미지, 문서). 학생이 다운로드 가능
- 자료실에서 **+ 자료 등록 → + 파일 추가**를 누르면 운영체제의 파일 선택 창이
  바로 열립니다. 파일 입력은 숨은 버튼을 간접 실행하지 않고 브라우저의 네이티브
  선택 영역을 사용하며, PDF·HWP/HWPX·DOCX·PPTX·이미지 등 안전한 원본을
  파일당 최대 50MB, 게시물당 최대 10개까지 첨부할 수 있습니다.
- 선택한 파일명과 크기는 등록 전에 목록에 표시됩니다. 저장이 실패하면 화면의
  오류 문구를 확인한 뒤 같은 작성 화면에서 파일을 다시 선택할 수 있습니다.
- 등록 후에는 자료 상세의 첨부파일 목록에서 다운로드할 수 있고, 새로고침 뒤에도
  파일명·크기와 다운로드 동작이 유지됩니다.

## 10. 메시지 관리

### 10-1. 직접 발송

**메시지 → 알림톡 보내기**를 누르면 학생 선택 화면으로 이동합니다. 상태 확인 중·조회 오류·운영 중지 때는 진입을 막고, 오류는 **다시 확인**, 운영 중지는 **설정 보기**를 제공합니다. 학생 목록/수강생 목록에서 대상을 선택한 뒤 **알림톡 보내기**를 누르면 **문구 저장**에 보관한 공지 문구를 불러올 수 있습니다.

| 발송 방식 | 설명 |
|----------|------|
| 알림톡 | 카카오톡 알림톡 (사전 승인된 템플릿만 가능) |

문자/SMS 실발송 경로는 없습니다. 과거 기록의 `message_mode=sms`는 발송 내역에서
**문자 발송 차단(레거시)**으로 표시되며 다시 보내기나 SMS 전환 기능을 제공하지 않습니다.

발송 버튼을 누르면 마지막 확인 화면에서 카카오톡과 같은 형태로 최종 문구를 확인할 수 있습니다. 학원명·학생명·링크·빈 항목은 실제 발송에 쓰이는 값 그대로 표시됩니다. 여러 학생을 선택한 경우 **전체 학생 열기**를 누른 뒤 학생 이름을 선택하면, 발송 대상은 유지한 채 해당 학생에게 적용될 이름·성적 등으로 미리보기가 바뀝니다. 전화번호가 없는 대상은 발송에서 제외되며 마지막 확인 화면에 표시됩니다.

시험·성적 결과 없이 홈페이지 주소, 영상 수강, 장소, 일정 같은 단체 공지만 보낼
때는 발송 유형에서 **수업·운영 공지**를 고릅니다. 화면에는 자유롭게 작성한
선생님 메모를 보여 주되 실제 카카오는 승인된 출석/수업 안내 봉투를 유지합니다.
390px 모바일에서도 발송·문구 선택·미리보기 모달은 현재 화면 상단에서 바로
열리고, 본문만 스크롤해 닫기와 마지막 확인 버튼에 계속 접근할 수 있습니다.

### 10-2. 템플릿 관리

**메시지 → 템플릿**

- 자주 사용하는 자유 본문을 문구로 저장·수정합니다
- 저장한 내 문구는 저장 당시 카테고리와 무관하게 모든 수동 공지 유형에서 다시
  불러올 수 있습니다. 현재 발송 유형과 같은 문구, 일반 문구 순으로 먼저 보입니다
- 문구를 다시 복제해도 이름의 `복사 -` 접두어는 한 번만 붙으며, API 이름
  길이를 넘지 않도록 자동으로 정리됩니다
- 변수 사용 가능: `#{학생이름}`, `#{강의명}`, `#{시험명}` 등
- 시스템 기본 문구와 실제 발송에 쓰는 승인 봉투는 읽기 전용입니다
- 학원별 PFID/API key 입력이나 신규 템플릿 검수 신청은 하지 않습니다. 공용
  승인 봉투가 없으면 다른 템플릿이나 문자로 대체하지 않고 발송이 실패합니다

### 10-3. 자동 발송

**메시지 → 자동발송**

화면 상단의 **알림톡 전체 사용**은 수동·자동·계정 알림을 포함한 학원 전체
상태입니다. 대표·관리자가 직접 끄고 다시 켤 수 있으며 변경은 감사 기록에
남습니다. 트리거별 토글은 그 아래에서 별도로 제어합니다. 장애 확산 방지용 긴급
운영 보호가 있는 경우 고객 설정과 다른 상태로 명시되며 화면 토글로 덮어쓰지
않습니다.

이벤트 발생 시 자동으로 메시지를 보낼 수 있습니다:

| 이벤트 | 수신 대상 | 예시 |
|--------|----------|------|
| 가입 안내 | 학생 + 학부모 | 아이디/비밀번호 안내 |
| 수업 시작 전 | 학생 + 학부모 | "오늘 수업이 시작됩니다" |
| 입실 완료 | 학부모 | "학생이 입실했습니다" |
| 결석 발생 | 학부모 | "결석이 발생했습니다" |
| 시험 예정 | 학생 | "시험이 예정되어 있습니다" |
| 성적 공개 | 학생 + 학부모 | "성적이 공개되었습니다" |
| 과제 등록 | 학생 | "새 과제가 등록되었습니다" |
| 클리닉 예약 | 학생 | "예약이 완료되었습니다" |
| 퇴원 처리 | 학생 + 학부모 | "퇴원 처리가 완료되었습니다" |

각 이벤트별로 **켜기/끄기**, 사용할 **템플릿**, **발송 시점**(즉시 / N분 전)을 설정할 수 있습니다.
관리자 화면과 교사용 모바일 메시지 설정에서 `N분 전` 값을 비우고 저장하면
발송 시점이 `null`로 초기화되며, 화면을 다시 열어도 빈 값으로 유지됩니다.

### 10-4. 발송 기록

**메시지 → 로그**

- 모든 발송 이력이 기록됩니다
- 성공/실패 상태, 수신자, 발송 시간 확인
- 실패한 메시지의 원인 확인 가능

## 11. 직원 관리

### 11-1. 직원 상세 팝업

**직원관리 → 홈 → 직원 이름** 또는 **직원관리 → 운영 화면 → 선택 직원 이름**

- 직원 이름을 누르면 현재 목록이나 근태·비용·월 마감 등 운영 화면 위에 직원 상세 팝업이 열립니다. 목록의 검색·선택·스크롤, 운영 탭·직원·연월 조건은 팝업 뒤에 그대로 유지됩니다.
- 닫기 버튼, 바깥 영역 클릭, `Esc`, 브라우저 뒤로가기는 모두 팝업을 닫고 같은 직원 목록 위치로 돌아갑니다. 상세 URL을 직접 연 경우에도 직원 홈을 배경으로 표시하고 닫으면 직원 홈으로 이동합니다.
- 상세에서는 기본 정보와 이번 달 요약, 시급·근무유형, 근무기록, 비용, 급여 히스토리, 리포트를 확인합니다. `근무기록` 탭에서는 이번 달 기록을 추가하고 잘못 입력한 날짜·유형·출퇴근 시각·휴게시간·메모를 수정하거나 삭제할 수 있습니다. `비용` 탭에서는 대기 중인 선결제 환급을 추가·수정·삭제하고 승인·반려하며 상태별로 볼 수 있습니다. 두 탭 모두 월 마감 확인 중·실패·마감 완료 상태에서는 변경을 막습니다. 헤더는 직위·계정 유형·로그인 여부, 재직 상태, 정보 수정·퇴사 작업을 분리해 보여 줍니다. 탭은 선택 항목을 배경·윤곽과 `aria-selected`로 함께 구분하고 좌우 방향키와 `Home`·`End`로 이동할 수 있습니다.
- 헤더는 고정되고 본문만 스크롤됩니다. 좁은 화면에서는 주요 업무 탭이 먼저, 기본 정보와 이번 달 요약이 뒤에 한 열로 이어지며 탭은 가로로 스크롤할 수 있습니다.
- 직원·급여 관리 권한이 있는 사용자만 진입할 수 있습니다. 대표·admin 계정은 원래
  가진 직원관리 권한을 끌 수 없고 직원 화면에서 퇴사·삭제하지 않습니다. 일반
  강사·직원 계정에만 직원관리 권한을 위임하거나 회수할 수 있습니다. 팝업을 열고
  닫는 것만으로는 데이터가 변경되지 않습니다.
- 직원 상세·월 요약·월 마감 상태는 백엔드 직원 API의 응답을 그대로 사용합니다. 불러오는 동안 진행 상태를 표시하고 조회 실패 시 팝업 안에서 다시 시도할 수 있습니다.
- 집중 검증: `pnpm exec playwright test e2e/admin/staff-operations-contract.mock.spec.ts --project=chromium`

### 11-2. 직원 추가

**직원관리 → + 직원 추가**

- 로그인 아이디, 초기 비밀번호, 이름, 전화번호를 입력한 뒤 직위(실장·강사·조교·직원),
  계정 유형(강사 계정·일반 직원 계정), 직원관리 권한을 각각 선택합니다. 직위는
  화면 표시용이며 계정 유형이나 권한을 자동으로 바꾸지 않습니다.
- 초기 비밀번호는 4자 이상이며 직원은 설정된 비밀번호로 즉시 로그인해 계속 사용할 수 있습니다.
- 직원 선택 도구에서는 명부·정산 엑셀, 시급 태그 일괄 추가, 비밀번호 설정, 퇴사 처리를 수행합니다. 퇴사는 계정 접근만 중지하고 기존 근무·비용·급여 이력을 보존합니다.
- 명부·정산 엑셀은 선택 전에도 사용할 수 있습니다. 시급 태그 추가,
  비밀번호 변경, 퇴사 처리는 직원을 선택한 뒤에만 나타나므로 일반 조회와
  선택 작업이 섞이지 않습니다.
- 390px 직원 명부는 선택과 이름에 폭을 집중하고 직위·계정·연락처·재직·급여유형·
  직원관리 권한을 이름 아래 요약합니다. 데스크톱용 넓은 열을 잘라 보여
  주거나 페이지 전체를 가로 스크롤하지 않습니다.

### 11-3. 비용/경비

**직원관리 → 급여 → 비용/경비 → 직원·연월 선택**

- 직원 선결제 환급은 직원이 개인 비용으로 먼저 결제한 환급 대상입니다. 개인 프로필의 `지출`과는 별도 데이터이며, 직원 환급은 `/staffs/expense-records/`, 개인 지출은 `/core/profile/expenses/`가 소유합니다.
- 월 화면 상단에서 전체·대기·승인·반려 건수와 금액을 비교하고 상태 버튼으로 목록을 좁힙니다. 화면 합계는 API가 반환한 상태를 그대로 묶으며 임의로 승인 상태를 추론하지 않습니다.
- 새 환급은 항상 대기로 등록됩니다. 대기 건은 날짜·항목·1원 이상의 금액·메모를 수정하거나 삭제할 수 있고, 관리자만 승인·반려할 수 있습니다.
- 승인·반려가 끝난 환급은 승인자와 처리 시각을 표시하고, 이력 보존을 위해 수정·삭제 조작부를 제공하지 않습니다. 정정은 새 대기 건으로 등록합니다.
- 월마감이 끝났거나 마감 상태 조회가 진행 중·실패 상태이면 추가·수정·삭제·승인·반려를 모두 막습니다.
- 직원·개인 지출 입력은 공용 모달을 사용합니다. 일반 입력창의 `Enter`는 저장, 여러 줄 메모의 `Enter`는 줄바꿈이며 한글 조합 중에는 저장하지 않습니다. 저장 중에는 `Esc`, 배경 클릭, 닫기 버튼으로 이탈할 수 없습니다. 모달을 닫으면 키보드 포커스가 모달을 연 버튼으로 돌아갑니다.
- 삭제·승인·반려·월마감 확인창은 포커스를 내부에 유지하고 닫힌 뒤 원래 조작 위치로 돌려보냅니다.
- 집중 검증: `pnpm exec playwright test e2e/admin/staff-operations-contract.mock.spec.ts --project=chromium`

### 11-4. 근무 시간

**로그인 직후 선택창과 상단 헤더의 시계 영역:**
- 로그인만 하면 근무시간이나 조교비가 계산되지 않습니다.
- 조교는 로그인 직후 배정된 **클리닉 조교**, **현장 조교** 등 근무유형으로
  출근하거나 **출근하지 않고 로그인**을 선택합니다.
- **출근하지 않고 로그인**: 매뉴얼 확인 등 비근무 이용. 시간·조교비 미계산
- **출근**: 선택한 근무유형과 시급으로 즉시 근무 시작
- **휴식**: 휴식 시간 시작/종료 (근무 시간에서 제외)
- **퇴근**: 근무 종료 후 근무시간·공제 전 근무액 계산
- PC 프로필의 **근무 기록**, 모바일의 **근무 기록 / 지출**에서 기간별 유형,
  출퇴근, 휴게, 적용 시급, 공제 전 금액을 확인합니다.
- 모바일은 상단 타이머 버튼에서 언제든 현재 유형·경과시간을 확인하고
  휴식·복귀·퇴근할 수 있습니다.
- 실시간 경과 시간이 표시됩니다.
- 현재 근무 중인 직원 목록도 확인 가능

### 11-5. 급여

**직원관리 → 급여**

- 직원을 선택하지 않은 첫 화면은 해당 월의 대상 직원, 총 근무시간, 근무기록 금액,
  승인 선결제 환급, 공제 전 합계, 마감 인원과 확인 필요 인원을 한 급여판에 표시합니다.
- 직원별 행에서 직위·계정, 근무시간, 근무기록 금액, 승인·대기 환급, 공제 전 합계,
  정산 상태를 비교하고 이름을 눌러 그 직원의 월 근태로 이동합니다.
- 진행 중 근무, 계산 미완료 기록, 대기 환급, 시급태그 미배정, 월급 수동 확인은
  `확인 필요` 사유로 표시합니다. 마감과 스냅샷이 불일치하면 `대사 필요`로 표시하며
  자동으로 정상 마감으로 추정하지 않습니다.
- 월별 근무기록 금액은 `적용 시급 × 근무 시간 + 관리자 조정액`, 정산 합계(공제 전)는
  여기에 승인 선결제 환급을 더한 값입니다. 세금·보험을 추정한 실지급액이 아닙니다.
- 직원별 월마감은 append-only 급여 스냅샷을 저장하고 정산 엑셀/PDF 이력을 보존합니다.

## 12. 저장소

**사이드바 → 저장소**

| 탭 | 설명 |
|------|------|
| 내 저장소 | 교사 개인 파일 관리 (폴더 구조) |
| 학생 인벤토리 | 학생별 제출 파일/공유 자료 확인 |

**파일 작업:**
- 업로드: 드래그&드롭 또는 파일 선택
- 폴더: 생성, 이름 변경, 이동
- 파일: 다운로드, 이름 변경, 이동, 삭제
- 파일이나 폴더 하나를 선택한 뒤 **이동**을 누르면 최상위 폴더 또는 다른
  폴더를 목적지로 지정할 수 있습니다. PC 버전의 기존 드래그 이동도 그대로
  사용할 수 있으며, 모바일 버전과 키보드에서는 이 버튼을 사용합니다.
- 현재 위치, 선택한 폴더 자신과 그 하위 폴더는 목적지로 선택할 수 없습니다.
  여러 항목을 선택했을 때는 이동 순서를 추정하지 않으므로 한 항목씩 이동합니다.
- 목적지에 같은 이름이 있으면 덮어쓰기 또는 이름 변경을 직접 선택합니다. 이동에
  실패하면 화면의 원래 위치를 유지하며 같은 목적지를 다시 선택해 재시도할 수 있습니다.
- 내 저장소와 학생 인벤토리는 로그인한 학원의 대표·관리자·선생님·직원만 사용할
  수 있고, 학생 인벤토리 이동은 현재 선택한 학생 범위 안에서만 처리됩니다.
- 용량 표시: 사용 중인 저장 공간 확인

## 13. 도구

### PPT 생성기

**사이드바 → 도구 → PPT 생성기**

1. **이미지 모드**: 이미지 파일(최대 50개)을 업로드 → 각 이미지가 슬라이드가 됩니다
2. **PDF 모드**: PDF 파일 업로드 → 각 페이지가 슬라이드가 됩니다
3. 설정:
   - 비율: 16:9 / 4:3
   - 배경색: 검정 / 흰색 / 회색
   - 맞춤: 포함 / 채우기 / 늘리기
   - 반전, 흑백, 밝기/대비 조절
4. 이미지 슬라이드 순서:
   - PC 버전: 슬라이드를 드래그하여 직접 정렬합니다
   - 모바일 버전: 각 슬라이드의 **이전/다음** 버튼으로 직접 정렬합니다
   - 직접 바꾼 화면 순서와 슬라이드별 반전 설정이 생성 결과에 그대로 적용됩니다
5. **생성** 버튼 → 백그라운드 처리 → 자동 다운로드

### 클리닉 대상자 출력 경로

도구의 별도 `클리닉 대상자` 붙여넣기 페이지는 지원하지 않습니다. 외부 화면의
텍스트를 다시 해석하는 방식은 서버 판정·출결과 달라질 수 있어 제거했으며,
**차시 → 성적 → 성적 도구 → 클리닉 대상**만 공식 출력 경로입니다. 기존
`/workspace/tools/clinic` 주소는 지원 중인 도구 화면으로 이동합니다. 이 도구는
브라우저 입력만 사용하고 서버에 저장한 데이터가 없었으므로 별도 데이터 이전이나
삭제 대상은 없습니다.

### 타이머

**사이드바 → 도구 → 타이머**

타이머와 스톱워치를 전환하고 프로젝터·전체 화면으로 사용할 수 있습니다.
시간 숫자는 폭이 흔들리지 않는 기기 내장 고정폭 글꼴로 표시합니다. 배포 직후
화면 자산이 바뀐 경우에는 새 버전을 자동으로 다시 불러오며, 반복 실패하면
새로고침 안내를 표시합니다.

### 14-4. 구독/결제
- 모든 기능이 포함된 단일 요금제와 월 결제 금액 확인
- 일반 신규 가입가는 공급가 180,000원, 부가가치세 18,000원, 총 198,000원
- 2026년 8월 가입 특별가는 공급가 145,000원, 부가가치세 14,000원,
  총 159,000원이며 가입 후에도 동일 가격 보장
- 구독 상태와 남은 일수 확인
- 현재 납부 수단은 계좌이체입니다. 학원 소유자가 **계좌이체 선택하기**로
  청구서를 준비한 뒤 화면에 표시된 운영 계좌와 납부 금액을 확인합니다.
- 이체를 마치면 입금자명과 이체 시각을 제출합니다. 입금 신고만으로 납부가
  완료되지는 않으며, 운영팀이 실제 통장 내역과 금액을 확인한 뒤 수납 처리합니다.
- 카드 등록과 카드 결제 화면은 카드 결제 계약을 시작할 때까지 표시하지 않습니다.
  기존 카드 데이터와 서버 호환 경로는 삭제하지 않습니다.
- 구독 관련 문의

### 14-5. 홈페이지 꾸미기

- **설정 → 홈페이지 → 홈페이지 모듈**에서 실제 공개 페이지에 보이는 모듈과
  아직 사용하지 않는 모듈 라이브러리를 나누어 확인합니다.
- **현재 보이는 모듈**은 위에서 아래 순서가 공개 홈페이지 표시 순서입니다.
  위·아래 버튼으로 순서를 바꾸고 카드를 눌러 내용을 편집합니다.
- 꺼진 모듈은 **모듈 라이브러리**에서 다시 켤 수 있습니다. 켠 모듈은 현재 보이는
  목록으로 이동하고, 끈 모듈은 라이브러리로 돌아가므로 노출 상태를 바로 구분할 수
  있습니다.
- 변경 중에는 **미리보기**로 공개 전 화면을 확인하고, 저장 후 **게시하기**를 눌러
  공개합니다.

## 15. 전체 업무 흐름 요약

### 새 학기 세팅
```
학생 등록(엑셀) → 강의 생성 → 수강생 배정(계정 안내 알림톡 1회) → 차시 추가 → 영상/자료 업로드
```

### 매 수업
```
출결 입력 → 시험/과제 채점 → 성적 저장
                ↓
     불합격 학생 자동 감지 (클리닉 대상)
                ↓
     클리닉 세션 생성 → 학생 배정/예약 → 당일 출석 확인
```

### 시험 운영
```
시험 생성 → 문항 입력 → 정답지 설정 → 학생 공지(알림톡)
    ↓
학생 응시 → 자동 채점 (객관식·수학 숫자 단답) + 수동 채점 (그 외 서술형)
    ↓
합격/불합격 판정 → 불합격 시 클리닉 대상 자동 등록
    ↓
재시험 허용된 경우 → 학생 재응시 가능
```

### 커뮤니티 관리
```
학생 질문 → 교사 답변 → 학생 확인 (알림톡 자동 발송)
공지 작성 → 학생 앱에 즉시 반영
자료 업로드 → 학생 다운로드 가능
```
