# 학생 공지·알림 이어보기

학생·학부모는 `/student/notices`에서 공지를 읽고, `/student/notifications`에서
최근 7일의 예약 승인·질문 답변·상담 답변·성적 소식을 확인한다.
역할·선택 자녀·tenant의 조회 범위는 기존 인증 API와 공용 query cache 초기화가 소유한다.
공지 작성·공개 권한은 [커뮤니티 첨부 계약](COMMUNITY-BOARD-ATTACHMENTS.md),
클리닉 승인 정책은 [승인 흐름](APPROVAL-WORKFLOWS.md)을 따른다.

## 공지 목록과 복귀

- `tab=lecture|session`, `lecture=<id>`를 주소에 유지한다. 상세 링크도 같은 범위를
  전달하며, 상세의 뒤로 가기·목록 링크·새로고침 후 복귀가 같은 목록을 연다.
- 종류를 바꾸면 다른 종류에 적용되지 않는 강의 범위는 지운다. 브라우저 뒤로/앞으로
  이동도 현재 주소의 선택 상태를 표시한다. 상세 직접 링크의 기본 복귀는 전체 공지다.
- 조회 중에는 로딩, 실패 시에는 재시도를 표시한다. 상세 조회 실패 중에도 목록으로
  나갈 수 있다. 필터는 `aria-pressed`와 44px 터치 영역으로 선택 상태를 전달한다.

## 알림 조회·읽음·복구

- 상단 배지와 목록은 같은 진행 중 요청 및 30초의 원본 조회 캐시를 재사용한다.
  배지는 기존 60초 갱신 주기를 유지한다. 질문·상담의 알림용 최근 50건 캐시는
  커뮤니티 전체 목록과 구분하되 상위 키의 갱신 요청을 함께 받는다.
- 프로필 또는 알림 소스 조회 실패를 0건으로 표시하지 않는다. 재시도는 프로필,
  예약, 질문, 상담, 성적과 집계를 다시 확인한다.
- 필수 조회가 모두 성공해 목록을 보여준 뒤에만 현재 항목을 읽음 처리한다.
  읽음 표시는 기존 tenant·학생/선택 자녀별 브라우저 저장소에 남는다. 서버의 예약,
  답변, 성적 데이터에는 쓰지 않는다. 읽음 후 집계 갱신은 신선한 원본 캐시를 사용한다.
- 목록의 합계는 실제 표시한 항목 수다. 읽은 알림도 최근 7일 동안 다시 볼 수 있다.
  긴 제목은 두 줄까지 표시하며 키보드 포커스와 터치 피드백을 제공한다.
  짧은 이동 효과는 reduced-motion에서 끈다.

## 검증

`e2e/student/student-content-resilience.mock.spec.ts`의 ‘알림·공지 이어보기’는
390/1366px에서 공지 범위→상세→reload→목록 및 브라우저 복귀, 상담 조회 실패→
재시도→읽음 저장→reload, 중복 조회 수와 가로 넘침을 확인한다.
동일 산출물 격리 development의 공지/QnA·클리닉·학생/학부모 평가 실사용 검증은
실제 서버 저장 후 소비 화면을 확인하며, 운영에서는 조회만 수행한다.

기존 링크·API·읽음 저장 형식은 호환되며 마이그레이션이나 기존 데이터 삭제는 없다.
