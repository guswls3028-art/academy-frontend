# 성적표 합산 구성

차시 성적 탭의 **합산 설정** 또는 시험/과제 총점 열 제목을 눌러 구성 모달을
연다. 시험과 점수형 과제 목록에서 평가 또는 총점 행을 끌어 옮긴다. 총점 위
항목을 합산하고 아래 항목은 별도로 표시한다. 키보드·390px에서는 각 행의
위/아래 이동 버튼으로 같은 작업을 할 수 있다. 저장 전 변경은 화면 초안이다.
이동 버튼은 44px 터치 영역을 제공하며 긴 평가명은 줄바꿈한다.

메인 성적표에서 평가 열을 이동할 때도 실제 표시된 총점 앞/뒤 경계를 기준으로
합산 대상이 함께 바뀐다. 통과형 과제는 이동해도 총점 뒤에 남고, 제외 영역 안의
순서는 바꿀 수 있다. 총점 자체의 위치는 합산 설정 모달에서 옮긴다.
합산 설정을 다시 저장해도 제외 영역에서 정한 통과형 과제의 순서를 유지한다.

저장 후 기존 성적표의 열 순서와 합산 대상 수가 함께 갱신되고 reload에도
유지된다. 통과형 과제는 합산 목록에 넣지 않는다. 저장 중 중복 실행/닫기를
막고 오류 시 초안을 보존한다. 동시 수정 409에서는 **최신 설정으로 다시 시작**
버튼으로 현재 서버 설정을 읽어 다시 구성한다.

시험 총점과 과제 총점은 서버의 exam_total/homework_total을 표시한다.
미입력·채점 중 점수가 있으면 집계 중 및 입력 개수를 표시한다. 실제 0점과
미입력은 다르며 합산 대상 없음도 별도로 표시한다. 학부모·학생 성적 홈의
접을 수 있는 **차시별 총점**은 같은 서버 값이다. 성적 안내의 시험/과제 총점
블록과 익명 분포 PDF 역시 같은 선택 기준을 따른다.
개인 성적표 미리보기와 다운로드 PDF의 **현재 차시 요약**에도 같은 서버의
시험·과제 총점을 표시한다. 합산 없음·실제 0점·집계 중과 입력 개수를 구분하며
화면에서 별도로 합계를 재계산하지 않는다.
서버가 `is_provisional`로 표시한 미확정 시험은 개인 성적표에 **채점 확인 중**으로
표시하며, 점수·시험 평균·현재 문항별 득점에 확정 결과처럼 넣지 않는다.
성적 안내도 미확정(`is_provisional`) 시험의 점수·평균·합격 판정을 확정하지
않고 **채점 확인 중**으로 표시한다. 발송 준비의 최초·최종 성적 재조회에서
미확정을 확인하면 완료를 기다리도록 안내하며, 채점 완료 후 같은 발송 버튼으로
다시 진행할 수 있다. 조회 실패나 서술형 미입력도 기존 별도 안내를 유지한다.
이 검증은 발송 준비와 표시를 다루며 실제 외부 메시지를 발송하지 않는다.
서술형 입력 대기와 OMR 검토 안내는 각각의 상태를 유지한다.

과제 생성의 **점수형**은 만점과 커트라인을 지정하고 **통과형 (O/X)**은
통과/미통과만 입력한다. API의 SCORE/COMPLETION과 기존 기록은 유지한다.
통과형은 메시지·성적 카드에 O/X로 표현하며 점수 평균에서도 제외한다.
개인 성적표에서도 통과형은 `통과 (O)`·`미통과 (X)`로 표시하고, 미입력·미제출·
미배정을 구분한다. 과제 평균은 점수형의 현재 만점을 기준으로 계산한다.
통과형의 내부 저장 값인 0/1을 점수나 평균에 포함하지 않는다.
교사용 전체 성적표 미리보기는 기본 **화면에 맞추기**로 전체 가로 폭을 보여준다.
모바일에서 작은 글씨를 확인할 때 **100%**를 선택해 좌우로 이동할 수 있으며,
화면 크기를 바꿔도 맞춤 배율은 다시 계산한다. 미리보기 배율은 PDF의 A4 크기와
페이지 수를 바꾸지 않는다.
수동 교사 완료 판정·출결 메모·학부모 코멘트와 독립된 기능이다.

데이터·권한·계산의 정본은 [backend assessment-totals.md](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/assessment-totals.md)다.
검증은 순서 이동·부분 합산·빈 합산·통과형 제외·동시 수정·실패 복구와
새로고침, 학생/학부모 후속 표시를 desktop/390px에서 확인한다.
`individual-score-report.spec.ts`는 혼합 과제의 desktop/390px 미리보기와 실제
PDF 다운로드·페이지 경계를 검증한다. 격리 `student-parent-homework-realuse.spec.ts`는
저장·잠금·reload 후 개인 성적표의 O/X·점수형 평균·서버 총점 반영을 확인한다.

교사용 **성적표 출력**의 전체 학생 PDF도 서버 시험·과제 총점을 그대로 표시한다.
선택 평가 → 총점 → 제외 평가 순서를 유지하며 0점·합산 없음·집계 중과 입력 개수를
구분한다. 합불형은 O/X와 미입력·미제출·미배정을 표시하고 숫자 평균 대신
통과/입력 인원을 제공한다. 미확정 시험은 점수·P/F·평균·최종 통과 집계에서
확정 성적으로 표시하지 않는다. 총점 footer는 부분합계의 평균을 만들지 않고
완료 인원을 표시한다. A4 가로 12명씩 페이지를 나누며 desktop/390px 미리보기,
혼합 과제와 실제 PDF 다운로드, 25명 3페이지 경계 회귀로 검증한다.
