# 다원수학 데모

## 학생·학부모 홈과 직접 메뉴 (11월 23일)

첫 방문에 학생이 선택한 영상·자료·공지 상세는 학생 체험 로그인 후 같은 항목에서 열린다. 로그인 전 선택한 메뉴 또는 홈 날짜는 상세에서 목록으로 돌아갈 때도 유지한다. 재생 검수는 성적표 등 다른 화면에 먼저 로그인하지 않은 새 브라우저에서 시작한다.

내신 모의시험 성적표는 응시한 최근 8회까지 내 원점수와 응시생 평균(왼쪽 점수축), 내 백분위(오른쪽 백분율축)를 그린다. 전체 회차 표에는 최고점과 미응시·채점 대기도 남는다. 점수가 0인 응시는 그래프와 평균에 포함한다. 시험 범위 아래에는 선생님이 학생에게 공개한 시험 설명이 있을 때만 테스트 특성을 표시한다.

휴대폰 성적표에서 열 제목과 회차별 점수·단위는 한 줄로 표시한다. 전체 이력 표가 좁은 화면을 넘으면 표 안에서 가로로 이동한다.

학생 홈은 한 줄 공지와 세로 메뉴 사이에 월간 달력을 펼친다. 달을 이동하거나 날짜를 누르면 현재 주소에 선택일이 남는다. 같은 화면에 그날 출결, 영상·자료, 테스트, 과제를 차시 이름 및 실제 값과 함께 표시한다. 출결 미입력과 수업 없음, 결과 대기와 실제 0점을 구분한다. 자료가 없으면 빈 상태, 조회 실패는 오류와 재시도를 표시한다. 시험 성적표, 영상 재생, 과제 안내에서 돌아오면 선택일로 복귀한다.

두 역할의 홈 목록은 공지 중복 행, 분류 제목, 왼쪽 아이콘을 제거하고 기존 순서와 오른쪽 이동 표시를 유지한다. 공지는 상단 배너와 전체 메뉴에서 연다. 예전 주간 링크는 같은 날짜의 월간 보기를 연다. 수업 진도는 수강 강좌별 등록 회차와 차시명을 텍스트로 표시하며, 실제 샘플 수령 전까지 등록된 기록만 사용한다. 클리닉 안내는 임단규 선생님의 정규·상시 안내와 예약 내역을 구분하고 학생은 기존 예약 화면을 연다. 정규 시간은 확인 전까지 미정이다. 지도 단축 주소는 제공된 원본에 생략되어 장소명만 표시한다. 학생과 학부모는 영상 메뉴 첫 항목에서 지정된 YouTube 수업 영상을 새 창으로 연다. 기존 영상·자료와 시청 이력은 보존한다. 교직원은 차시 출결에서 출석·지각·동영상·결석을 기록한다. 학생은 기존 QR 출석을 사용할 수 있고 학생·학부모의 출결 현황은 조회 전용이다. 기존 저장 값과 기록 ID는 그대로 읽는다.

학생의 공지는 바로 본문, 출결은 요일별 수업 상태, 영상·자료는 강좌별 차시 목록, 테스트는 시험 목록으로 열린다. 공지·자료의 첨부와 영상은 기존 학생 권한을 확인하는 상세에서 열고 채점된 시험은 성적표로 간다. 네 메뉴의 종전 일자 링크는 계속 열 수 있고 과제의 날짜 선택과 학부모의 자녀별 달력·상담·성적표 경로는 유지한다. 서버는 지정된 다원 예시 학생의 실제 배정 기록을 조회한다. 검증에는 여러 수업이 있는 날, 과제 달력, 실제 재생과 결과지, 자료만 있는 차시, 뒤로가기, 일부 자료의 조회 실패와 390px·PC 화면을 포함한다.


선생님·학생·학부모·관리자가 같은 다원수학 디자인을 사용한다. 선생앱과 관리자앱은 각각 로그인 화면이 열리며, 사용자가 데모 로그인 버튼을 누르면 격리된 예시 학원의 해당 역할로 들어간다. 선생앱은 차시 운영, 출결, 시험·과제 및 영상과 클리닉·상담 등을 맡는다. 관리자는 반별 운영 현황과 직원 직위, 시험 채점 현황을 확인한다. 실제 운영 학원 계정은 기존 로그인으로 접근한다.

## 헤더의 홈 이동

역할을 선택한 로그인 화면에서 로고로 홈에 갔다가 브라우저 뒤로 가기를 누르면 같은 역할의 로그인 버튼으로 돌아온다. 새 탭이나 새로고침으로 역할별 로그인 주소를 다시 열어도 동일하다.

상단의 다원수학 로고와 이름은 하나의 홈 링크다. 학생과 학부모는 각자의 학습 홈으로, 로그인한 교직원은 업무 대시보드로 돌아간다. 로그인 전에는 공개 데모 홈으로 돌아가며 학부모 상담 입구에서는 학부모 홈을 연다. 시험·영상·상담 상세와 내 정보에서도 같은 규칙을 적용한다. 집 모양 홈 아이콘은 하단 탐색에 유지하고 햄버거 메뉴와 상세 화면의 뒤로가기는 각자의 동작을 유지한다.

이 변경은 탐색 링크와 표시만 다룬다. 로그인·역할 전환은 기존 인증 절차를 사용한다. 모바일과 PC에서 로고를 누르거나 키보드로 열었을 때 목적지와 현재 역할이 일치하는지, 날짜별 내역과 상세의 복귀 버튼이 작동하는지 확인한다.

## 반 편성과 수업

- 강의 메뉴는 반 목록에서 시작한다. 학생 메뉴의 반 편성에서도 같은 목록을 쓴다. 전체 강의 목록과 지난강의에서 종전 강의를 열 수 있다.
- 반 만들기 창에서 연합반의 1%, HYPER, SKY 또는 학교반의 학교를 선택한다. 저장하면 반 인원 배정 창이 열린다. 등록된 학생을 직접 검색하거나 기존 수강등록용 Excel 서식으로 대조한다. 동명이인·미매칭 행은 확인할 수 있다. 파일은 계정 정보를 수정하지 않는다.
- 반을 열면 들어온 메뉴에 따라 ‘강의 목록’ 또는 ‘반 명단’ 한 곳이 열린다. 강의 목록에서 수업을 개설하고 반 명단에서 학생을 배정한다. 두 메뉴 사이를 이동해도 선택한 반이 유지되며 각 주소를 다시 열 수 있다. 선택한 반 안에서는 상위 영역의 탭을 접고 ‘강의 목록’과 ‘반 명단’만 표시한다. 상위 메뉴는 반 목록으로 돌아가거나 왼쪽 업무 메뉴에서 연다. 새 반 저장 직후에는 반 명단의 배정 창으로 이동한다.
- 반 명단에서 제외는 전용 창에서 확인한 학생에 적용한다. 이미 개설한 수업의 등록·출결 기록은 보존된다.
- 반 상세의 수업 개설은 기존 강의 설정 창을 사용한다. 연합반 방학 수업은 반 전체, 연합반 내신 수업은 선택한 학교, 학교반은 해당 학교를 대상으로 저장한다. 현재 대상 인원은 이때 수강 등록된다. 개설된 수업의 수강생 등록 창은 이후 합류한 대상 학생만 표시한다.
- 수업 운영은 기존 강의 화면에서 차시, 출결, 시험, 과제, 영상에 접근한다. 반과 연결되기 전에 생긴 강의는 종전 수강 등록 방식을 사용한다.
- 선생님 대시보드에서 날짜를 선택하면 그날의 등록 차시가 표시된다. 수업 행을 누르면 해당 수업일의 출결 화면으로 이동한다. 반별 강의와 반 편성, 수업 출석 QR도 여기에서 열 수 있다.
- 강의 개설 후 등록된 수강생 수와 **수업 운영 열기**를 보여 준다. 강의 상세에서 **첫 차시 추가**로 들어가 날짜와 시간을 확인해 저장하면 방금 만든 차시의 출결이 열린다. 다원 반과 연결된 공통 정규 차시에는 현재 강의의 활성 수강생이 자동 배정된다. 보강 및 하위 반별 차시는 출결에서 대상 학생을 선택한다. 강의·차시 상단의 반 이름으로 원래 반에 돌아간다.
- 설문·성적취합 만들기는 각각 같은 기존 작성 폼을 모달에서 연다. 초안 저장 후 대상과 질문을 검토하고 응답을 시작한다.

## 선생님과 원장의 일일 업무

휴대전화의 반 명단과 원장 운영 표는 옆으로 밀어 나머지 열을 읽는다. 기본 너비에서는 학생 이름 또는 반·담당 강사가 왼쪽에 고정된다. 360px 미만이나 이름 열의 너비를 조정한 경우에는 표 전체를 이동할 수 있다. 열 제목을 누르면 정렬되고, 제목 오른쪽 구분선에서 너비를 바꿀 수 있다. 선생님 명단의 인원수와 검색창, 원장 홈의 반 개수와 전체 경보는 공간이 충분하면 각각 한 줄에 표시한다.

작은 화면에서 출결 명단은 학생 이름과 상태를 먼저 보여 준다. 이름·전화번호 검색은 표 위에 두고 정렬·필터·등록은 출결 옵션에서 연다. 원장 비교표의 첫 열에는 반 이름과 담당 강사를 함께 표시한다.

선생님 홈은 담당 반 전체의 선택일 수업을 시간순으로 보여 준다. 분반 수업은 해당 수업일로 바로 연결한다. 반을 열면 강의 목록, 반 명단, 출결, 시험 결과를 같은 메뉴에서 전환한다. 강의 선택은 탭을 바꾸거나 새로고침해도 유지한다. 차시 출결 명단에서는 학생마다 한 행에서 상태를 고르고 연락처·메모는 상세에서 확인한다. 퇴원은 기존 확인 절차를 거친다.

원장 홈은 전체 반에서 담당 강사와 선택일의 미입력 출결을 비교한다. 숫자를 누르면 해당 반의 차시와 수강생별 상태가 열린다. 아직 출결 행이 없는 학생과 미입력 상태를 합산하며 조회 실패, 수업 없는 날, 입력 완료를 구분한다. 날짜별 전체 차시 출결과 학습 경보는 같은 홈에서 연다.

## 학생·학부모 홈과 일자별 기록

흰색 바탕, 주황색 학생 정보 영역, 세로형 메뉴를 공통으로 사용한다. 학부모 화면의 하단은 홈·영상·알림·상담하기이고 학생은 질문하기를 사용한다. 학생의 학교 성적과 QR 출석은 학생 화면에서 진입한다.

학부모 홈의 기록 메뉴와 학생 홈의 과제 등 날짜별 메뉴를 누르면 해당 항목의 월간 달력이 열린다. 학생의 공지·출결·영상·테스트는 위의 학생 홈 규칙을 따른다. 날짜 링크는 같은 메뉴의 일자별 기록 페이지를 열고, 뒤로 가기는 원래 월과 선택일를 복원한다. 셀 크기는 오늘과 기록 표시 유무에 관계없이 일정하다. 예를 들어 영상 날짜에는 공개 영상 목록, 출결 날짜에는 출결만 노출한다. 하단 영상 탭은 홈 영상 메뉴와 같은 화면을 연다. 영상 목록과 시청 통계에서 1분 미만인 길이는 초로 표기한다. 기존 독립 일정 주소는 학습 홈으로 안내한다.

학생·학부모 달력은 기간 제목 양옆에서 이전 달·다음 달로 이동하고 오늘로 돌아갈 수 있다. 날짜 칸의 크기는 같고 오늘은 글자, 해당 메뉴에 기록이 있는 날은 점으로 표시한다. 학생의 한 줄 공지는 해당 본문, 학부모의 한 줄 공지는 그 공지가 있는 달을 연다. 기록이 없는 기간이나 일자에서는 같은 메뉴에 날짜가 확인된 기록이 있을 때만 가장 가까운 날짜로 이동할 수 있다. 일자 상세에서 달력으로 돌아가면 들어왔던 기간과 방금 확인한 날짜를 식별할 수 있다.

출결 달력은 출결 상태를 입력한 날과 입력을 기다리는 날을 구분한다. 날짜를 열면 각 차시의 상태를 확인할 수 있다. 학생·학부모는 과제 현황에서 날짜를 고르면 과제가 한 건일 때는 내용, 제출기한, 제출 방법이 바로 보인다. 여러 건일 때는 원하는 과제 행을 펼치며 새로고침으로 선택을 복원한다. 선생님은 기존 과제 운영 설정에서 이 세 항목을 저장한다. 기한이 비어 있으면 ‘기한 없음’, 안내가 비어 있으면 미등록으로 표시한다.

날짜별 학생 질문에서 ‘질문 보기’를 누르면 해당 본문·사진·예시 답변을 열고 원래 날짜로 돌아간다. 상세의 돌아가기 링크는 첫 화면 응답부터 원래 날짜·달력·목록 중 올바른 위치를 가리켜 로딩 중에도 사용할 수 있다. 같은 브라우저의 질문 저장소를 직접 읽으며, 이 저장소를 읽을 수 없으면 오류와 다시 시도를 표시한다. 다른 학습 기록은 기존 데모 조회 API의 역할별 표시 범위를 따른다. 달력·상세 변경 검수에는 학생과 학부모 각각에서 월 이동, 빈 기간·날짜, 상세 복귀와 새로고침, 390px 및 PC 정렬을 포함한다.

선생앱 대시보드에서 출석 QR을 열어 SVG로 내려받거나 인쇄한다. 학생은 카메라나 QR 링크에서 출석을 등록한다. 클리닉 안내에서 장소·운영시간과 내 예약을 확인한다. 예약과 학부모 상담 답변은 기존 화면에서 처리한다. 데모 학생 질문은 이전과 같이 같은 브라우저 안에 보존하며 새 질문에는 등록 날짜를 기록한다.

## 학부모 상담

학부모 홈의 하단 **상담하기**는 예시 학부모 인증을 거쳐 상담 신청서를 바로 연다. 홈 목록에서 상담하기를 선택하면 월간 달력이 열리고, 날짜를 고른 뒤 새 상담을 신청하거나 그날 신청한 상담의 내역과 답변을 열 수 있다. 상담 신청과 신청 내역을 탭으로 전환하며 내역과 상세에는 새로고침·브라우저 뒤로가기로 복원되는 주소가 있다. 신청이 저장되면 방금 등록한 글과 답변 상태를 연다. 상담 자체는 기존 자녀 범위의 인증된 커뮤니티 API로 저장·조회한다. 날짜 필터는 신청 시각을 서울 날짜로 해석한다. 공유 체험 계정의 신청과 답변에는 기존의 예시 문구만 사용한다.

학부모가 메뉴를 누른 탭에서만 해당 상담 진입을 이어간다. 직접 연 진입 주소에는 학부모 체험 버튼을 표시한다. 인증이나 내역 조회가 실패하면 다시 시도할 수 있고, 신청을 열기만 해서는 글을 생성하지 않는다. 학부모 폼·내역 전환과 날짜 복귀는 휴대폰·PC에서, 실제 신청과 교직원 답변 반영은 격리된 예시 학원에서 검증한다.

## 시험 성적 비교 기준

반에 연결된 강의는 기본 상위 30% 평균과 비교한다. 시험 결과의 비교 기준에서 담당 선생님이나 운영 관리자가 1~100%로 변경한다. 설정은 수업에 저장되며 채점이 확정된 참가자만 집계한다. 유효한 0점은 포함하고 미응시·미채점은 제외한다. 학생에게는 본인의 만점 대비 성취율을 비교 집단 평균으로 나눈 값과 원점수를 함께 표시한다. 학교별 내신은 선택한 학교의 수강생 집단을 사용한다.

## 반별 강의와 배포 후 재진입

강의에서 반을 선택하면 강의 목록이 먼저 열린다. 행에서 강의 이름, 수강생 수, 대상 학교와 기간을 확인하고 강의 운영으로 이동한다. 현재·예정과 지난 강의를 전환해 같은 반의 기록을 조회한다. 연합반 방학은 전체 명단을, 내신은 선택한 학교의 학생을 개설 시 자동 등록한다. 다른 학교의 중간고사를 개설해도 먼저 개설한 학교의 중간고사는 유지된다. 해당 학교의 기말이 시작되면 그 학교의 중간만 지난 강의로 이동한다. 이후 합류자는 수강 등록에서 추가한다.

반 인원 배정 창은 학생 검색과 엑셀 대조 결과를 선택 명단에 모아 저장한다. 강의 이력과 당시 수강생은 반 명단 제외 후에도 조회한다. 공개 데모의 HTML과 버전 응답은 매번 확인하고 해시가 붙은 정적 파일을 재사용한다. 기존 탭은 새 배포를 감지하면 작성 중인 입력, 열린 대화상자 및 재생을 보호하며 안전한 시점에 같은 주소를 다시 연다. 닫힌 학습 메뉴는 갱신을 막지 않으며, 학부모 상담 화면 안에서 메뉴를 열어둔 동안에도 갱신을 기다린다.

### 학교 성적 입력과 교직원 조회

학생은 `/student/submit/school-report`에서 학년도·학기·중간/기말을 선택해
자신의 과목별 점수를 저장하고 다시 열어 수정한다. 데스크톱의 **학생 → 설문·성적 취합 →
학교별 제출 성적**에서 같은 회차의 학교·학년별 과목 평균을 확인할 수 있다.
학교와 학년을 고르면 제출 학생을 선택해 개인 성적표로 들어간다. ‘학교·학년 미확인’도
별도로 열 수 있다. 기존 브라우저 체험 점수는 그대로 보존한다.

다원 학생 개인 성적표의 상세 PDF는 현재 차시에 문항별 점수가 확정된 시험마다
문항 번호 순으로 전체 득점을 싣는다. 한 표가 16문항을 넘으면 다음 A4 쪽에
이어지고, 시험명과 해당 범위를 표시한다. 미리보기와 일괄 다운로드도 같은 쪽 수를 사용한다.

공개 데모 진입점은 [Worker](../deploy/dawon/demo-worker.mjs)와
[전용 원본 라우팅](../deploy/dawon/origin.Caddyfile)이 담당한다. Worker는 배포 시
기존 학생 앱 모듈 `baseline-worker.mjs`(파일 SHA-256
`db4bfab9d90a9302d2d3e5d10c9adc5e01b79e496475c1730f27b308a83166e8`)과 함께 구성한다.
원본 인증값은 배포 환경의 바인딩에서 읽는다. 최신 브라우저용 시작 스크립트는
동일 출처의 기능 검사 모듈을 사용하고, 구형 브라우저는 기존 호환 번들을 사용한다.

공개 데모에서는 [역할 전환 헤더](../deploy/dawon/dawon-demo-header.mjs)가 선생님용·관리자·학생·학부모를 이 순서로 표시한다. 선생님용과 관리자 진입은 사용자의 로그인 버튼 클릭으로 시작한다. 학원용의 관리자 모드 데모도 이 관리자 진입을 사용한다. 화면을 바꾸기 전에 작성 중인 양식의 전환을 확인하며 취소 시 입력값을 유지한다. QR 인쇄에서는 공용 헤더를 숨긴다.

[일자별 학습 화면](../deploy/dawon/dawon-learner-sessions.mjs)은 홈과 하단 영상의 링크, 항목별 월간·일자 주소를 정의한다. 데이터는 같은 출처의 데모 API가 반환하며, 응답 실패 시 사용자가 다시 시도할 수 있다. 영상이 있는 날짜에서 체험 학생으로 로그인하면 실제 플레이어를 이용할 수 있다. 보호자에게는 영상 목록과 자녀의 기록을 보여 준다. 공개 데모의 학교 성적에서는 기록일과 학기만 표시하며 점수 입력과 조회는 실제 학생 인증을 사용한다.

데모 화면의 마감은 달력의 날짜 글꼴과 보조 글자 대비, 44px 기간 조작, 일자별 상세 목록의 들여쓰기와 행 간격, 교직원 모달의 제목과 닫기·최소화 영역, 스크롤 본문과 푸터 버튼을 PC와 모바일에서 점검한다. 승인된 홈 배너와 업무 메뉴의 순서를 기준으로 유지한다.

배포 검증은 PC와 390px에서 첨부 예시의 홈 배치, 월간 날짜 셀과 달 이동, 선택 항목의 일자별 기록, 학부모의 학교 성적 숨김, 영상 양쪽 진입, 로그인 버튼을 누르기 전 세션 발급이 없는 상태를 확인한다. 관리자 화면에서 실제 반·직원·시험 데이터를 읽고, 예시 직원에 변경한 직위가 새로고침 후에 남는지 확인한다. 읽기 범위는 백엔드의 다원 예시 수업 문서를 참조한다.

## 교직원 업무 동선

PC는 왼쪽 업무 메뉴를 유지하고, 1023px 이하에서는 상단의 메뉴 버튼으로 같은 왼쪽 서랍을 연다. 수업 운영, 평가, 학생 지원에서 목적지를 선택하면 서랍이 닫힌다. 데모의 역할 전환은 별도의 최상단 헤더에서 한다.

선생님 반 운영 화면은 로그인한 선생님의 강의 담당 기록으로 연결된 반과 그 반의 오늘 수업을 보여 준다. 해당 날짜에 수업이 없으면 가장 최근 차시를 열 수 있다. 반 수업 관리에서 해당 반의 강의와 명단을 열고 차시 출결·시험·과제·자료로 이동한다. 여러 담당 반이 있으면 반을 선택할 수 있다. 연결된 반이 없거나 조회에 실패하면 빈 상태와 재시도를 구분한다. 반에 포함된 현행 강의만 대시보드의 QR 후보가 된다. 담당 반 조회는 기존 학원 업무 권한 내 개인화된 조회다.

관리자 반 운영 화면은 반을 선택한 뒤 해당 강의를 펼쳐 차시, 시험 결과, 과제 중 한 항목을 본다. 선택한 반·강의·항목은 주소에 보관하며 직원 관리나 시험 결과를 다녀와도 같은 곳으로 돌아온다. 전체 시험 결과는 채점 대기와 결과 있음으로 필터링한다. 점수와 제출 수는 해당 강의에 등록된 기록으로 계산한다. 직원 수정과 시험별 전체 집계는 별도 메뉴에서 확인한다.

관리자 데모는 반·직원·시험 조회에 필요한 데이터만 요청한다. 수강생 명단에서 쓰는 클리닉 대상 강조는 해당 명단을 제공하는 선생님 화면에서 조회한다.

학생·학부모 홈은 주황색 학생 정보와 기존 항목 순서를 유지한다. 햄버거 메뉴는 학원 생활, 수업 기록, 신청·문의 순으로 묶으며 학생에게는 마지막 묶음에 학교 성적 제출도 표시한다. 학습 메뉴는 닫기 버튼·바깥 터치·Escape로 닫고 키보드 초점을 열기 버튼으로 되돌린다. 수업 도구의 메뉴·하단 탭도 같은 역할별 항목을 사용한다. 하단 탭은 현재 위치를 색과 표시선으로 구분한다. 공지 미리보기와 알림 기록은 등록 날짜를 표시한다. 최신 공지가 없으면 햄버거 메뉴의 공지사항로 확인할 수 있고, 조회에 실패하면 홈에서 다시 시도할 수 있다. 학생 질문 작성에서 사진 선택·촬영은 선택 항목에 두고 작성과 내역을 전환한다. 질문은 기존 브라우저 체험 저장 방식을 따른다. 날짜 상세의 뒤로 가기는 진입한 월간 달력의 원래 기간을 복원하며 알림에서 열었다면 해당 역할의 알림으로 돌아간다. 조회에 실패해도 복귀 링크를 사용할 수 있다.

선생님 대시보드의 담당 반과 수업 날짜는 주소에 보관한다. 빈 날짜와 잘못된 날짜는 오늘을 표시한다. 이 화면의 선택은 기존 담당 반 조회 권한 안에서만 적용된다.

## 데모 후보 설치와 복구

전용 데모 호스트에서 새 API 후보를 시작하기 전에 `deploy/dawon/check-candidate-capacity.sh`로 실행 중인 버전과 가용 메모리를 확인한다. 현재 공개 버전과 롤백 버전을 대조해 쓰지 않는 후보의 API 프로세스를 중지한 뒤 설치한다. DB와 기존 정적 파일은 보존한다. 승격 후에는 새 공개 버전과 직전 롤백 버전만 실행 상태로 둔다. 중단된 설치는 공개 라우팅과 패키지 SHA를 확인하고 격리한 뒤 같은 패키지로 새 설치 영수증을 얻어 브라우저 검증을 다시 거친다.

데모의 엑셀 일괄 등록은 전용 에뮬레이터의 버킷과 작업 큐를 쓴다. 호스트 재기동 시 `dawon-review-excel-bootstrap.service`가 두 리소스를 준비하고 읽어 확인한다. 기존 버킷과 대기열은 재사용한다. 복구 후 두 학생이 엑셀 미리보기, 최종 등록, 새로고침한 명단까지 이어지는지 확인한다.

## 다원 체험 직원·근태

관리자는 직원 관리에서 분원장·강사·조교별 명단을 확인하고 이름 또는 직위로 검색한다. 직원을 선택하면 직위, 월 근태 기록과 월 급여를 본다. 직원과 조회 월은 주소에 보존된다. 강사·조교 직위 저장은 표시 직위만 바꾼다. 미퇴근 기록에는 금액을 확정하지 않으며 마감 스냅샷이 있는 월은 확정 금액을 표시한다. 승인 경비는 월 근무 수당과 구분한다.

선생님 홈의 내 출퇴근은 본인의 출근·퇴근을 기록한다. 처리 후 표시된 근무 상태는 새로고침과 관리자 월별 기록에 반영된다. 이미 출근했거나 월이 마감되면 오류와 실제 상태를 확인할 수 있다. 합성 직원·근무 데이터의 격리와 생성 절차는 백엔드 직원 운영 문서의 다원 체험 항목에 기록한다.

## 선생님·관리자 업무 프레임과 반 명단

두 역할의 학생 메뉴는 먼저 학생 명단 표를 연다. 선생님은 담당 반에 속한 학생을, 관리자는 미편성 학생을 포함한 학원 전체 학생을 본다. 여러 반에 속한 학생도 한 행으로 센다. 반 유형에서 연합반을 고르면 1%·HYPER·SKY 과정 및 실제 반으로, 내신반을 고르면 실제 반으로 좁힌다. 상위 조건을 바꾸면 이전 하위 선택을 비우며 학년과 이름·학교·전화번호 검색은 함께 적용한다. 입력한 글자는 즉시 보이고 한글 조합이 끝나거나 입력을 잠깐 멈추면 첫 페이지부터 조회한다. 휴대전화에서는 검색창이 한 줄을 사용하고 학생 상세에서 목록으로 돌아오면 조회 조건을 복원한다. 선생님의 조회 가능 범위는 서버가 명단·인원수·학생 상세·소속 반·수강 강의에 동일하게 적용한다. 조회 실패 시 해당 요청을 다시 시도할 수 있다.

맨 위의 네 역할 전환 바 아래에서 학원플러스 공용 헤더가 기능 검색, 작업박스, 알림, 도움말과 프로필을 제공한다. PC의 메뉴 버튼은 왼쪽 탐색을 접고 펼치며 휴대전화에서는 같은 메뉴를 서랍으로 연다. 기능 검색과 도움말의 목적지는 로그인 역할의 메뉴를 따른다. 설정의 프로필은 체험 계정을 조회하며 화면 설정은 기존 테마 저장 방식을 쓴다.

선생님의 반별 강의와 반 편성은 공통 목록 도구막대와 표를 쓴다. 반 이름·학교·과정으로 반을 찾고, 선택한 반에서 강의 목록과 학생 명단을 오간다. 강의는 현재·예정과 지난 강의를 구분한다. 반 명단에서 학생 이름·학교·전화번호로 검색하고 이름을 누르면 학생 상세를 연다. 명단 배정·제외는 기존 모달로 저장하며 조회·저장 실패는 해당 작업에서 다시 시도한다. 반 편성 및 강의 개설의 데이터 경계는 백엔드 반 편성 정책을 따른다.
휴대전화의 반 학생 명단은 학생 한 명을 한 줄로 표시한다. 이름 링크가 터치 영역을 제공하고, 명단 안에서 검색하거나 아래로 스크롤해 학생을 찾는다.

다원 데모의 기본 학생·학부모 계정은 김학생 2와 보호자 2, 담당 교사는 김선생 1, 관리자 계정은 김원장 1로 표시한다. 학생·학부모 홈과 기존 프로필의 예시 인물도 같은 번호를 쓴다. 명단·출결·성적의 이름과 실제 반 구분은 전용 데모 API에서 조회한다.

## 원장 PC 업무 화면과 성적 조회

원장 메뉴의 강의 관리는 강의, 반 편성은 반, 학생 명단은 미편성 학생을 포함한 학생을 한 행으로 표시한다. 강의 상세에서 차시·실제 수강 명단·시험·과제를 열고 해당 강의의 수강생을 등록한다. 반의 명단 배정은 강의 등록과 별개다. 기존 반·강의 상세 주소도 계속 지원한다. 학생 선택 창은 이름·학교·전화번호 및 학년으로 현재 작업에 해당하는 후보를 조회한다. 검색이나 페이지 변경 후에도 선택을 유지하며 최대 200명까지 중복 없이 저장한다. 엑셀 등록과 저장 실패 후 재시도도 같은 검증을 거친다.

직원 검색·직위, 학생 명단의 검색·필터, 시험 조회 조건은 해당 상세에서 복귀할 때 유지한다. 강의는 저장된 색과 두 글자 약칭을 학원플러스 강의 딱지로 표시하고 직원 역할과 학생 이름에는 공통 아바타를 사용한다. 직원과 학생은 PC에서 목록 옆에 상세를 표시한다. 원장 프로필은 학원플러스 프로필의 조회 모드이며 화면 설정은 기존 테마 컴포넌트를 사용한다. 지점별 역할·조직 범위는 다원 검토 API의 원장 권한을 따른다.

시험 목록에서 반·채점 상태·시험명을 조회한다. 시험을 선택하면 해당 강의의 확정 최초 응시를 기준으로 학교·학년·상태·득점률 조건을 함께 적용한다. 명단, 대상/채점/미응시/대기 인원, 원점수 평균·최고·최저, 득점률 분포, 문항별 정답률은 같은 선택 범위를 쓴다. 0점은 집계하며 미응시·미채점은 평균에 포함하지 않는다. 문항별 분모는 해당 문항에 채점이 있는 학생 수다. 학교 중간·기말 제출은 학원 시험과 별도 화면에서 회차·학교·학년별 과목 평균과 개인 성적표로 확인한다. 원본 성적표·실명은 배포물에 포함하지 않는다.

학생은 공개된 본인 시험 결과에서 시험 유형별 원점수와 만점, 반 평균·최고점, 공개된 백분위, 문항별 주제·정오·정답률, 회차별 응시 횟수·같은 만점별 누적 원점수 평균과 과제 기록을 본다. 백분위는 확정 채점 집단에서 본인 이하 점수의 비율(동점 포함)이다. 비교 수치는 같은 강의의 확정 응시를 기준으로 하고 개인별 응답은 본인 것만 제공한다. 본인의 학교 성적은 제출한 기간별로 다시 열 수 있다. 학부모에게 학교 성적은 표시하지 않는다. 명단과 문항 집계 계약은 scripts/test-dawon-admin-roster.mjs 및 scripts/test-dawon-admin-exam-cohort.mjs에서 검증한다.

### 원장 업무와 월말 대조

원장의 반 운영·출결, 강의·시험, 학생 성적, 상담·클리닉, 직원·월 정산 화면은 검색 중 주소나 조회 조건이 갱신되어도 입력하던 글자와 커서 위치를 유지한다. 한글 조합이 끝난 값으로 검색하며, 조건을 초기화하거나 뒤로 가면 해당 목록의 검색어를 복원한다.

반 운영 현황은 선택 날짜의 미입력 출결 건수, 학습 경보 건수, 반 이름 순서로 연다. ‘출결 미입력 N개 반’은 검색 범위에서 미입력 또는 기록이 없는 수강생이 있는 반만 남긴다. 헤더로 재정렬하거나 업무 우선순으로 돌아갈 수 있다. 교사는 PC 차시 출결에서 현장·지각·결석을 행에서 바로 저장한다. 기타 상태와 좁은 화면은 선택 상자를 쓴다. 출결 저장 권한과 원장 집계에는 기존 계약이 적용된다.

학생별 성적은 원장에게 허용된 수강 범위에서 학생마다 한 행을 표시한다. 최근 시험, 응시 상태, 원점수·만점·득점률과 비교 가능한 직전 회차 대비 변화(%p)를 조회한다. 비교 자료가 없으면 ‘비교 전’으로 표시한다. 이름·반·최근 응시 상태·상승/하락을 함께 조회한다. 학생의 강의별 기록에서 돌아오면 조건을 복원한다. 조회 결과 엑셀에는 조건과 정렬, 전체 결과를 담는다. 시험 상세에서는 요약 옆의 링크로 학생별 결과·문항 분석을 바로 연다.

원장의 반 배정·수강 등록에서 검색하면 기존 반 배정, 수강 중, 이전 수강 이력, 반 배정 필요 여부가 표시된다. 직접 선택 및 페이지 전체 선택에는 등록 가능 학생만 포함한다. 엑셀 대조와 서버의 중복 검증은 기존 규칙을 유지한다.

월 정산은 원장에게 조회 권한이 있는 직원의 근무 시간·근무 수당·승인 경비·지급액과 확정·예상·미확정 상태를 표시한다. 이름·직위 검색 후에도 체크 선택을 유지하며 월을 바꾸면 초기화한다. 직원 이름을 열어 개별 근무 내역을 대조한다. 엑셀은 선택 직원 또는 선택이 없을 때의 조회 결과를 담고 미확정 금액은 빈값이다. 조회·내려받기 실패 시 같은 조건에서 재시도한다. 이 조회·내려받기는 성적·급여 자료를 수정하지 않는다.

### 관리자 강의 운영과 직원 업무

휴대폰의 학생 명단은 이름 열을 고정하고 표 안에서 가로로 이동한다. 학교와 학년을 읽을 수 있는 폭을 확보하고 학부모·학생 연락처는 오른쪽에 표시한다. 이름을 눌러 여는 상세에서도 두 연락처를 확인할 수 있다.

관리자는 강의 관리에서 반과 강의를 골라 학원플러스 공용 차시 표를 연다. 차시 이름을 누르면 출결이 먼저 열리고, 같은 차시에서 성적·시험·과제·공지·영상으로 이동한다. 차시 추가는 기존 생성 모달을 쓴다. 반별 출결 현황에서도 해당 차시의 입력 화면을 열 수 있다. 강의 요약의 시험 결과와 과제 제출 현황은 개별 차시 운영과 함께 제공한다. 체험 영상 등록에는 공용 영상 등록 창의 YouTube 링크 방식을 사용한다.

학생 명단에는 학부모와 학생 전화가 별도 열로 표시된다. 학생·직원 이름을 누르면 공용 상세 오버레이가 열린다. 닫으면 원래 명단의 조건과 페이지로 복귀한다. 학생 상세에서 선생님과 관리자는 선택한 강의의 채점된 시험, 회차별 점수와 득점률 추이를 보고, 동일 계열 비교가 가능할 때만 이전 시험과의 차이를 본다. 원장은 학생 학습 기록에서 과제·상담·클리닉으로 이어간다. 직원은 상세에서 월 근태·급여를 확인한다. 클리닉의 반별 신청과 권한은 [클리닉 화면](../src/app_admin/domains/clinic/README.md)을 따른다.

학습 경보의 빨간 숫자는 현재 역할이 처리할 수 있는 미처리 건수다. 미처리·처리 완료 탭에 검색과 경보 사유, 원장의 반 유형·연합반 과정·실제 반, 강사의 담당 강의 필터를 조합한다. 검색 결과는 25건씩 보며 이전 목록으로 돌아오면 조회 조건을 복원한다. 업무 처리는 권한이 있는 원장과 담당 강사가 공유한다. 완료 처리 후 되돌릴 수 있고, 다른 시험이나 새 차시에서 같은 사유로 발생한 경보는 따로 확인한다.

### 교직원 프로그램 A · B · C

다원 데모의 `/a`, `/b`, `/c`는 각각 네 역할을 고르는 독립 진입점이다. 각 주소 뒤에 `/admin`, `/teacher`, `/student`, `/guardian`을 붙여 해당 역할로 바로 시작할 수 있다. 교직원은 데모 로그인 후 같은 역할의 대시보드로 들어간다. 직원·근태·급여는 관리자에게, 담당 강의·시험과 학생 기록은 선생님의 허용 범위에 제공한다. 학생과 학부모는 세 버전에서 같은 학습 홈을 사용한다.

| 버전 | 교직원이 업무를 여는 방식 |
|---|---|
| A 학원 행정 콘솔 | 학원플러스의 고정 업무 메뉴와 상단 검색·도구, 조회표를 사용한다. 남색 메뉴, 현재 업무 경로, 그룹별 업무 이동 선택기를 사용해 반복 조회 중 다른 업무로 전환한다. |
| B 업무 데스크 | PC의 왼쪽 업무 목록에서 메뉴를 이름이나 분류로 찾아 오른쪽에서 처리한다. 최근 연 업무 최대 네 개를 다시 열 수 있다. 휴대폰은 업무 선택기와 최근 목록을 쓴다. |
| C 업무 포털 | 대시보드의 분류별 전체 업무에서 검색하거나 항목을 누른다. 개별 화면에서는 전체 업무를 펼쳐 전환하고 PC의 우측 메뉴에서도 이동할 수 있다. 검색 결과가 비면 검색어를 수정하거나 지운다. |

버전은 화면 주소의 `edition` 값과 현재 탭에 유지된다. 직접 주소, 새로고침, 뒤로가기, 역할 변경에서도 같은 버전으로 돌아온다. 기존 역할 주소의 기본 버전은 A다. 교직원 헤더의 버전 링크에서 입구를 다시 연다. 종전 콘솔 탭은 제거했다. 이전에 저장한 강의·학생·경보 주소는 해당 업무 화면을 계속 열며 과거 탭 설정은 읽지 않는다. 버전 선택은 역할이나 데이터 범위를 변경하지 않는다. 최근 업무에는 메뉴 경로만 보관한다. 세 버전은 동일한 다원 데모 데이터와 인증을 사용한다.

모든 버전의 차시 출결에서 교직원은 출석·지각·동영상·결석을 기존 행에 저장한다. 좁은 명단에서는 상태 선택기를 사용하며 기존 기록과 선택 범위를 보존한다. 저장 실패 시 안내를 확인한 후 다시 선택한다. 학생은 QR 출석을 사용할 수 있고 학생·학부모 출결 현황은 조회용이다. 경보에서 학생 상세로 이동하면 근거를 확인할 수 있다. 상담 일정 등록과 경보 처리 완료는 각각 저장한다. 학생 명단의 상담 일정은 역할 범위의 기존 API로 읽고 실패하면 다시 시도한다. 학생 상세에서 담당 강의·학생에 해당하는 상담과 회차별 시험·과제·클리닉 기록을 확인한다.

배포 검증은 세 진입점마다 네 역할, 교직원 전체 메뉴, 출결 및 학생 상세·경보의 실제 데이터, 독립 탭·재진입과 390px/PC 표시를 점검한다. 역할별 메뉴의 원본 일치와 주소 보존은 `node --test scripts/dawon-review/test-staff-consoles.mjs`로 점검한다.
