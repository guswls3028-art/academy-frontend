# 학부모 전용 평가 코멘트

성적표의 시험/과제 메뉴에서 학부모 코멘트를 열면 해당 평가에 배정된 학생별
입력란과 수정 이력을 제공한다. 부모에게 공개되는 별도 정보임을 저장 전에
표시한다. 내부 메모와 출결 메모는 불러오거나 복사하지 않는다.

입력은 2000자까지 허용하고 저장 중에는 중복 저장을 막는다. 실패하면 입력을
유지하고 재시도할 수 있다. 충돌 시 최신 내용을 확인한 뒤 기존 입력으로 다시
저장할 수 있다. 빈 내용 저장은 학부모 화면에서 해당 코멘트를 지우며 수정
이력은 남긴다. 같은 창에서 다른 학생을 저장해 목록이 재조회되면 미편집
행은 최신 본문·버전·이력을 반영한다. 작성 중인 행은 초안과 기존 버전을 유지해
충돌 시 최신 내용 확인으로 복구한다. 초안을 기존 저장값으로 되돌리면 이미
조회된 최신 버전을 적용하며, 저장 응답보다 오래된 조회값은 무시한다. 같은
버전의 저장 확인 재조회는 공개 성공 안내를 유지한다.
‘최신 내용 확인’을 기다리는 동안에도 초안은 계속 편집할 수 있다. 응답이 오면
그 시점의 입력을 보존하므로 화면 이동 후 재진입해도 기다리는 동안 작성한 내용이
복구된다. 확인 중에는 중복 조회·공개·창 닫기를 잠그고, 실패하면 입력을 유지한
채 최신 내용 확인을 다시 시도할 수 있다.
배정이 해제되어 목록에서 사라져도 작성 중·저장 중인 행은 유지한다. 배정 해제
상태에서는 공개를 막고 입력을 편집·복사하거나 초안을 명시적으로 버릴 수 있다.
‘배정 다시 확인’으로 재조회해 다른 화면에서 복구한 배정을 확인할 수 있다.
초기 로딩·조회 실패는 배정 해제와 구분하고 확인될 때까지 공개를 막는다.
조회 실패 상태에서 초안을 버리면 입력도 기존 저장 기준으로 되돌리고 미저장 경고를 해제한다.
다시 조회한 뒤 정상 편집·공개할 수 있다.
재배정 확인 후에는 기존 초안과 버전으로 저장하며 동시 수정은 409로 복구한다.
실제 미저장 입력은 브라우저 새로고침·종료 경고로 보호한다. SPA 화면 이동 후
재진입을 위한 초안은 기존 학생 메모와 같은 tenant/user 범위 QueryClient 메모리에만
보관하며 저장·명시적 폐기·로그아웃 시 제거한다. 디스크에는 기록하지 않으므로
경고를 무시한 전체 새로고침·브라우저 종료 후 복구를 보장하지 않는다.
새로고침 경고는 편집 창이 열린 동안 적용되며, SPA로 다른 화면에 이동한 뒤에는
메모리 초안 복구만 제공한다. 그 다른 화면에서 새로고침하면 메모리 초안도 사라진다.
계정·학원·평가 범위가 바뀌면 편집 상태를 새로 만들며 이전 범위의 초안을 새 범위에 쓰지 않는다. 목록 로딩·실패·재시도·배정 학생 없음 상태를 제공한다.

학부모 성적 홈의 각 시험/과제 카드 아래에 해당 평가의 코멘트를 표시한다.
점수 입력 전 코멘트는 평가명·차시명과 함께 별도로 표시한다. 선택한 자녀에게
배정된 평가만 조회하며 종료 강의의 학습 이력은 유지한다. 학생 계정은 내용을 표시하거나 API를 요청하지
않는다. 자녀별 쿼리 키와 학생 범위 캐시 정리를 적용한다. API 또한 학부모
역할과 선택한 자녀의 소유권을 확인한다.

입력란과 코멘트는 가변 너비, 긴 내용 줄바꿈과 여러 줄 표시, 버튼 줄바꿈을
사용하여 390px에서도 읽고 수정할 수 있다. 기본 포커스 및 네이티브 details
동작으로 키보드 접근과 이력 확인을 지원한다. 데이터 정책과 API 계약의
소유자는 backend `apps/domains/results/README.md`의 Parent-only assessment
comments 절이다.

검증: 저장 → 새로고침 → 선택한 자녀 화면, 학생 미노출/API 403, 다른 자녀
차단, 동시 수정 409/입력 보존, 빈 내용 저장, 실패 후 재시도, desktop/390px
레이아웃을 확인한다. 백엔드 회귀 테스트는 `test_parent_assessment_comments.py`.
격리 실사용은 시험과 과제 각각에서 교사 공개 → 저장 후 재열기 → 학부모
새로고침·재로그인과 학생 미노출을 확인한다. 점수형 과제 총점의 제외·복구와
학부모의 동일 점수 조회, 여러 줄 코멘트의 desktop/390px 표시도 포함한다.
