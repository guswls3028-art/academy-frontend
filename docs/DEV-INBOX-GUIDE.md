# 개발자 문의함 사용 가이드

## 학원장·선생님

1. 관리자 또는 선생님 앱의 `버그 제보`·`피드백` 화면에서 제목과 내용을
   작성한다.
2. 스크린샷이나 파일을 첨부할 수 있다. 문의 등록 후 첨부만 실패하면 새 문의를
   다시 만들지 말고 화면의 `첨부만 다시 올리기`를 누른다.
3. 아래 `우리 학원 제보/피드백 내역`에서 처리 상태와 개발팀 답변 본문을
   확인한다. 이력은 같은 학원의 직원이 함께 보는 운영 기록이다.
4. 제출된 문의·대화·첨부는 기록 보존을 위해 수정하거나 삭제할 수 없다.
   답변 뒤 추가 확인이 필요하면 해당 문의에 후속 답변을 남긴다.

## 플랫폼 운영자

1. `/dev/inbox`는 기본적으로 미처리 문의를 보여준다.
2. 상단 집계에서 전체 도입 문의·버그·개선 의견·완료 건수를 확인하고, 검색과
   유형·상태 필터로 대상을 좁힌다.
3. 도입 문의와 빠른 신고는 내부 메모를 저장한 뒤 `처리 완료` 또는
   `미처리로 전환`한다. 내부 메모는 문의자에게 공개되지 않는다.
4. 지원 티켓은 개발팀 답변을 등록하면 완료된다. 문의자가 그 뒤 후속 답변을
   남기면 자동으로 미처리 상태로 돌아온다.
5. 실제 도입 문의의 전화번호와 내용은 운영 목적에만 사용하고, 검증 중 상태나
   메모를 임의로 변경하지 않는다.
