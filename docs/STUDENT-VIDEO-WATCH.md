# 학생 영상 시청

학생이 강의·차시 목록에서 허용된 영상을 열고 시청·복습하며 질문을 남기는 화면이다. 화면은 서버가 판정한 수강·직접 부여 권한과 재생 정책을 사용한다. 직접 부여 영상의 별도 경계는 [VIDEO-DIRECT-ACCESS.md](VIDEO-DIRECT-ACCESS.md), 공개 영상 준비는 [PUBLIC-VIDEO-WORKFLOW.md](PUBLIC-VIDEO-WORKFLOW.md), 정책 정본은 [backend 차시 영상 접근](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/session-video-access.md)을 따른다.

## 진입과 조작

- 제목 아래에 목록으로·좋아요·댓글·재생목록·다음 항목을 표시한다. 목록으로는 방문 이력과 관계없이 현재 차시 목록(선택 수강 포함)으로 이동하며, 차시 정보가 없으면 영상 홈으로 이동한다.
- 재생목록은 댓글 앞에 놓고 한 항목만 있어도 표시한다. 현재 영상과 서버가 반환한 허용 영상만 사용한다. 목록을 닫으면 링크를 화면과 키보드 탐색에서 함께 제외한다. 긴 목록은 내부 스크롤로 마지막 항목까지 접근할 수 있다.
- 댓글 버튼은 댓글 영역으로 이동해 초점을 전달한다. 초기 댓글 요청은 재생 준비 후 지연하지만 사용자가 댓글을 선택하면 즉시 시작한다. 목록 펼치기와 이동에는 짧은 전환을 사용하고 reduced-motion을 존중한다.
- PC와 390px 화면에서 제목 줄바꿈, 가로 넘침, 버튼 대비와 최소 44px 조작 영역을 확인한다. 영상 버튼 스타일은 학생 공통 button/link 초기화에 덮이지 않도록 영상 범위 안에서 지정한다.

## 재생과 권한

- HLS와 YouTube의 실제 재생 종료 이벤트에서 완료 진도를 즉시 저장하고 다음 영상이 있으면 5초 후 이동한다. 사용자는 카운트다운을 취소할 수 있다. 이전 시청 완료 상태나 탭 배경 전환·주기적 진도 저장은 자동 이동을 시작하지 않는다.
- 영상·수강 전환 및 화면 종료 시 이전 타이머·플레이어를 정리한다. 서버의 건너뛰기·배속 제한, 토큰 갱신과 권한 재검사를 유지한다.
- 일반 수강 영상의 좋아요·댓글은 해당 학생 권한으로 저장한다. 직접 부여 영상은 기존 정책대로 좋아요·댓글·서버 학습 진도 쓰기를 제공하지 않으며 로컬 이어보기를 사용한다. 다른 수강이나 테넌트로 우회하지 않는다.

### 터치와 임시 배속

- 배속이 잠긴 수업 영상에서도 가운데 탭은 정상적으로 일시정지·재개한다. 일반 탭과
  포인터 취소는 배속을 설정하거나 `SPEED_CHANGE_ATTEMPT`를 만들지 않는다.
- 허용된 영상의 오른쪽을 500ms 누르고 실제 임시 배속이 적용된 경우에만 원래 속도를
  기억한다. 손을 떼거나 취소하면 한 번 복원하며, 짧은 탭·발동 전 취소·중복 종료는
  배속을 쓰지 않는다. 영상·수강·컨트롤러 교체 시 남은 타이머와 복원값을 비운다.
- 임시 배속 중 정책이 잠기면 이전의 허용된 정책 안에서 1배속으로 먼저 돌아온 뒤
  새 잠금을 적용한다. 발동 전 정책 잠금은 타이머를 취소한다. 컨트롤러의 배속 제한과
  실제 위반 기록·서버 세션 회수는 그대로 유지한다.
- `video-watch-journey.mock.spec.ts`의 `monitored HLS gestures` 회귀는 합성 HLS를
  실제 재생하고 포인터 탭·길게 누르기, 취소/중복 종료 경계, native 배속 쓰기를 확인한다.
  모니터링 v2 ACK가 실제로 도착한 뒤 위반 없음·동일 세션 재생 지속을 확인한다.
  취소 이벤트 자체는 기존 실제 pointer down 뒤에 주입해 브라우저의 취소 경계를 검사한다.
  제어줄 높이가 바뀌어도 중앙·우측 제스처의 가로 영역은 유지하며, `elementFromPoint`로 실제
  노출된 영상 지점을 골라 입력 직전에도 같은 hit target을 확인한다. 이전 고정 좌표와 선택한
  지점을 함께 기록하며, 강제 입력·제어줄 숨김·DOM/CSS 변조로 제스처 성공을 만들지 않는다.

### 전체화면 버튼의 입력 완료

상단·하단 전체화면 버튼은 손을 뗀 뒤 발생한 버튼 클릭에서 한 번 전환한다.
터치 시작 중 레이아웃을 바꾸지 않아 취소·드래그를 전환으로 취급하거나 종료 터치를
뒤쪽 헤더의 가이드북 버튼에 전달하지 않는다. 마우스 클릭과 버튼에 초점을 둔
Enter·Space도 같은 경로를 사용하며, 버튼의 Space만 재생 단축키가 가로채지 않는다.
버튼 클릭·Enter·Space 뒤 초점이 남아 있어도 K(재생), F(전체화면), M(음소거), T(극장 모드),
J/L·좌우(기존 정책 안에서 탐색)는 유지한다. 입력창·textarea·contentEditable의 전역 예외는
그대로다. 탐색 회귀는 기존 허용 fixture에서 단축키와 실제 진행 값으로 확인하며, 잠긴
정책을 풀거나 영상 위치를 직접 써서 검사하지 않는다.
의도적으로 가이드북을 누르면 기존 안내가 정상적으로 열리고 닫힌 뒤에도 재생을 유지한다.

`video-watch-journey.mock.spec.ts`의 `fullscreen controls` 회귀는 390px·1366px의 실제 HLS와
모니터링 ACK에서 실제 미디어 조건에 따라 표시되는 상단·하단 버튼의 터치/마우스/Enter/Space
진입·종료, 가이드 오작동 없음과
의도된 가이드 진입, 위반 없는 재생 지속을 검증한다. Chromium에서는 CDP가 생성한
trusted touchCancel·touchMove도 사용해 취소·드래그 전환 0을 확인한다. 다른 엔진은
완료된 터치·마우스·키보드 경로를 검사하며 trusted 취소 검증으로 확대 해석하지 않는다.
전체화면은 현재 요청에 속한 대체 진입 타이머만 유지한다. 네이티브 진입 성공·종료(Escape 포함),
다음 요청, 화면 이탈 때 이전 요청과 타이머를 무효화한다. 이미 끝난 요청의 늦은 거절 응답도
화면을 다시 열 수 없다. 지원되는 네이티브 API가 거절되면 현재 요청에 한해 100ms 후 대체
전체화면을 열며, 네이티브 전환 확인용 350ms 보조 처리도 같은 수명을 따른다.
회귀는 가상 시계로 타이머만 정지한 상태에서 실제 터치로 진입·종료하고 351ms를 진행해
재진입이 없음을 검사한다. 이후 마우스·키보드 입력도 계속 검증한다. 터치 가능한 1366px에서도
`(hover: none)`이면 상단 버튼이 표시되므로, 실제 미디어 조건과 계산된 표시값을 기록하고
보이는 상단·하단 버튼을 모두 검사한다.

모바일·터치 화면의 하단 제어줄은 공간이 부족하면 재생·탐색·음량 그룹과 화질·배속·전체화면
그룹을 줄바꿈한다. 보이는 버튼의 기능·라벨·공통 터치 크기를 유지하며, 화질 선택이 불가능한
영상의 Auto는 기존 비활성 의미를 유지한다. 기존 focused 네 시나리오 안에서 정상 제어줄의
390·1100·1366px 가시 타깃 rect·중앙 hit target을 기록하고, 서로 겹치지 않음·viewport 안에
들어옴·중앙이 해당 타깃에 속함을 검사한다. 1100px는 짧은 배치 단계로만 확인하고 기존
390·1366px 전체화면·가이드·단축키·실제 HLS 재생 회귀를 반복 추가하지 않는다.

영상 stage와 하단 제어줄은 같은 플레이어 안의 별도 형제 영역이다. 중앙 재생 버튼·제스처·
상태 오버레이는 영상 영역 안에 있고, 음량·진행바 등은 그 아래의 흐름 영역을 사용한다.
중앙 재생 버튼과 보이는 제어줄을 모두 유지하며 서로의 입력을 가로채지 않는다. 제어줄 자동
숨김은 투명도만 바꾸므로 공간과 영상 요소를 유지한다. 일반 영상 16:9·극장 모드 21:9는
유지하며, 전체화면은 제목·제어줄을 제외한 남은 공간에 영상을 contain으로 맞춘다.
기존 focused geometry는 세 화면 폭에서 재생·일시정지 상태의 BigPlay까지 포함해 rect와
25/50/75% hit 소유를 검사한다. 정상 음량 클릭은 재생 상태를 유지하며 음소거만 토글하고,
허용된 진행바 입력은 위치만 바꾼다. 중앙·하단 재생 버튼 각각의 복귀, 영상 요소 유지·재생
지속·가로 넘침 없음과 전체화면 stage/제어줄 분리도 검사한다. 제스처는 상태가 바뀔 때마다
같은 가로 영역에서 실제 노출된 지점을 다시 확인한다.

### 전체화면의 배속·화질 메뉴

배속·화질 메뉴는 일반 화면에서 body 포털을 사용한다. 해당 버튼을 포함하는 네이티브
전체화면 요소가 있으면 그 요소 안에 표시해 영상 레이어에 가려지지 않도록 한다.
다른 플레이어의 전체화면 요소에 붙이지 않는다. 전체화면 진입·종료 때 열려 있던 메뉴는
닫고, 다시 누르면 현재 버튼 위치에서 연다. 항목 선택·버튼 재클릭·메뉴 바깥 입력도 닫기
경로를 유지한다. 메뉴 이동은 기존 배속 정책·화질 선택 콜백만 사용하며 재생 세션이나
영상 요소를 교체하지 않는다.

재생 중 전체화면 진입·종료는 제어줄의 기존 3초 자동 숨김 타이머를 새로 시작한다.
이전 화면의 타이머가 전환 직후 제어줄을 숨기지 않도록 하며, 일시정지·버퍼링의 표시
조건은 유지한다. 기존 회귀 흐름에서 자동 숨김 직전에 진입하고 이전 만료 시각을 지난
뒤에도 제어줄이 보이는지 확인한 다음 메뉴 선택을 계속한다.

배속 잠금은 그대로 적용한다. 화질은 Hls.js가 여러 level을 제공할 때 선택할 수 있으며,
브라우저 기본 HLS 경로와 단일 화질에서는 기존 Auto 비활성 표시를 유지한다. 비활성
버튼을 활성 화질 선택 검증으로 간주하지 않는다.
검증은 390·1366px에서 실제 fullscreen 요소, 메뉴의 25/50/75% hit 소유와 원본 화면을
확인하고, 정상 입력으로 배속의 실제 playbackRate 및 선택 표시를 대조한다. 활성 화질
경로에서는 선택 표시와 실제 variant 요청 또는 선택된 level을 함께 확인한다. 메뉴 닫기,
전체화면 종료·일반 화면 복귀, 재생 지속과 모니터링 위반 없음도 같은 흐름에서 확인한다.

전체화면 API·권한·모니터링 이벤트 수집과 서버의 위반 판정은 바뀌지 않는다.

## 복습 시청시간

모든 학원에서 영상 등록 시 복습시간 제한을 선택할 수 있으며 처음에는 꺼져 있다. 여러 파일을 올릴 때에는 각 파일의 체크박스로 정하며 순서를 바꿔도 선택은 해당 파일을 따른다. 선생님 앱의 파일 업로드와 YouTube 링크 등록에서도 영상마다 선택한다. 파일은 인코딩한 길이를 쓰며 YouTube는 제한을 선택했을 때에만 선생님이 원본 길이를 입력한다. 등록 후에는 영상 상세에서 적용 시간과 기준 도달 학생 수를 확인하고 제한을 변경하거나 취소한다. 학생별 집계는 아래 시청 로그 동선에서 확인한다.

YouTube 원본 길이를 잘못 입력한 경우 영상 상세에서 변경 후 한도와 기준 도달 인원을 확인하고 정정한다. 동시 편집 충돌은 최신 설정을 다시 표시하고 입력을 보존한다.

학생이 먼 구간으로 이동하면 해당 위치의 재생 준비가 끝난 뒤 이동한다. 일시적 연결 오류는 같은 순번으로 다시 확인하고, 복구될 때까지 안내한다. 한도를 모두 사용한 학생은 종료 화면에서 영상 목록으로 돌아갈 수 있다.

다른 기기에서 이어 열어 잠시 기다려야 하면 준비가 끝난 뒤 영상을 연다. 브라우저에서 추가 탭을 요구하면 재생 버튼으로 이어간다.

재생을 누르면 플레이어가 인증된 POST로 현재 위치(이어보기 포함)의 초기 조각을 요청한다. 파일을 다시 읽거나 범위 요청을 재시도해도 누적시간은 변하지 않는다. 버퍼링과 일시정지는 서버에 정지 상태와 현재 위치를 전달한다.

선생님은 영상 상세의 시청 정책을 열어 영상별 1.4배 제한을 켜거나 끌 수 있다.
정책 설정에 섞여 있던 학생별 누적 목록은 전용 시청 로그로 이동했다. 기존 기록이나
개별 영상의 제한 설정은 변경하지 않는다.

### 관리자 시청 로그 동선

- 영상 상세·영상 상세 드로어의 학생 시청 현황 상단 `시청 로그` →
  `/workspace/videos/:videoId/logs` → 학생 선택 → `/:studentId` 상세.
  기존 권한 창의 시청 로그 탭과 정책 설정의 링크도 같은 페이지로 연결한다.
- 간편 업무에서도 영상 상세 `시청 로그` → `/workspace/mobile/videos/:videoId/logs`
  → 학생 상세로 같은 컴포넌트와 API를 사용하며 복귀는 해당 간편 업무 영상으로 간다.
- 기본 화면은 해당 영상의 학생별 누적 시간과 원본 대비 배율만 보여준다. 이름 검색,
  1.4배 이상 필터, 30명 단위 페이지를 제공하며 선택 조건은 URL에 유지한다.
  학생 상세에서 목록 복귀·브라우저 뒤로가기·새로고침 후에도 맥락을 유지한다.
  원본 길이가 아직 없는 영상은 누적 시간을 그대로 보여주고 배율 비교가 불가함을
  안내한다. 이때 과거 URL의 배율 필터로 학생 목록을 숨기지 않는다.
- 학생 상세는 누적 시간·원본 대비 배율·현재 제한·집계 시작과 활동 기록을 보여준다.
  누적 시간은 30초마다 갱신하며 실패한 조회는 0명/기록 없음으로 바꾸지 않는다.
  새로고침·재시도를 제공하고 삭제되거나 집계가 없는 학생은 목록 복귀를 안내한다.
- 활동은 24시간/7일/전체 기간, 25건 단위로 읽고 CSV로 내려받는다. 기간 필터는
  누적 시간에 영향을 주지 않는다. 원본 이벤트·당시 정책은 기록 상세에서 추가로
  펼친다. 전체 학생 활동은 목록 하단의 접힌 항목으로만 제공한다.
- 누적 시간은 기존 `/media/videos/:id/review-watch/report/` 원장 값을 사용한다.
  활동은 `/media/video-playback-events/?video=:id&student=:studentId`의 수강 기록이다.
  직접 부여 영상은 누적 시간에 포함되지만 별도 수강 활동 로그를 생성하지 않는다.
  집계 시작을 최초 시청일·최근 접속으로 표시하거나 원장 이전 기간을 추정하지 않는다.
- 과다 시간은 확인을 위한 단서이며 계정 공유의 확정 판정이 아니다. 기존 위험점수
  상위 목록·원시 JSON 우선 화면을 학생 상세 중심으로 교체했으며 서버의 기존 API와
  저장 데이터는 유지한다. 접근과 tenant 격리는 backend가 결정한다.
- 기존 디자인 토큰을 사용하고 모바일에서는 한 학생을 세로 행으로 배치한다.
  키보드 링크/기본 details, 명확한 뒤로가기, reduced-motion을 존중하는 짧은 전환을 사용한다.
  Backend 데이터 정책: [session-video-access](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/session-video-access.md).

학생이 제한 영상을 열면 플레이어에 남은 시간이 표시된다. 되감아 다시 본 시간도 합산하고
일시정지와 버퍼링 중에는 멈춘다. 새 기기에서 열면 이전 플레이어를 종료하고 남은
시간을 이어 쓴다. 저장할 수 없으면 재생을 멈추고 다시 열도록 안내한다. 마지막 영상 조각 요청이 먼저 거절되더라도 서버에서 남은 시간이 0인지 확인해 시간 소진 안내를 표시한다.
업로드 영상의 보호된 재생목록과 조각은 학생 사이트의 `/review-media/`를 사용한다.
Pages Function은 등록된 운영 호스트와 테넌트 코드의 일치를 검사한 후 API 권한을 확인하고,
허용된 조각만 전용 비공개 영상 버킷에서 스트리밍한다. 미등록·미리보기 호스트는 운영 API에 요청하지 않는다.

## 실패와 복구

- 재생목록 조회 실패는 실패 메시지와 다시 시도를 표시한다. 실패를 빈 목록으로 숨기지 않는다.
- 댓글 조회 실패는 오류와 다시 시도를 표시하고 작성 중인 문구를 보존한다. 조회 실패를 댓글 0개로 표시하지 않는다.
- 좋아요 저장 실패는 낙관적 변경을 되돌리고 알림을 표시한다. 다시 누르면 재시도할 수 있다.
- 삭제된 원댓글은 내용 대신 삭제 표시를 남기며 기존 답글은 펼쳐 읽을 수 있다. 삭제된 원댓글에 새 답글 작성은 제공하지 않는다. 서버가 권한을 거부한 경우 접근을 복원하는 우회 동작을 만들지 않는다.
