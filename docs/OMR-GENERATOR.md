# OMR 답안지 생성기

## 목적과 진입점

관리자와 허용된 교직원은 `/workspace/tools/omr`에서 시험에 연결되지 않은
OMR 답안지를 만들 수 있다. 시험 답안 등록 화면도 같은
`OmrSheetBuilder`를 사용하되 시험 ID와 문항 구성을 백엔드 기본값에서 받는다.
백엔드의 테넌트 로고, 답안지 HTML·PDF 렌더링과 인식 좌표 계약은
`backend/docs/domain/omr.md`가 소유한다.

## 사용자 흐름과 상태

1. 시험명, 강의명, 차시명을 입력한다.
2. 객관식만, 혼합형, 서술형만 중 구성을 고르고 허용 범위 안에서 문항 수를
   입력한다. 객관식 전용 답안지는 문항 수가 허용할 때 서술형 풀이 공간을
   표시하거나 숨길 수 있다.
   시험 답안키의 비객관식 문항은 정답 형식과 관계없이 번호가 붙은 빈 서술형
   작성칸으로 출력한다. 종이 답안지에는 `0~999` 숫자 버블을 만들지 않으며
   모든 서술형 작성칸은 AI 인식·자동판정 대상에서 제외한다.
3. 입력이 바뀌면 짧은 대기 후 미리보기를 다시 요청한다. 사용자는
   `미리보기 새로고침`으로 같은 요청을 즉시 반복할 수 있다.
4. `이 구성으로 PDF 다운로드`는 현재 값으로 서버 PDF를 만들고 완료 또는
   실패 피드백을 표시한다.

문항 합계가 0이면 미리보기와 다운로드를 막는다. 미리보기 요청 중에는 로딩
문구를, 초기·빈 상태에는 준비 안내를 표시한다. 미리보기 실패는 정적 일반 오류
문서로 대체하고 내부 오류나 서버 응답 본문을 노출하지 않는다. PDF 실패도
일반 사용자 문구만 표시하며 입력값은 보존한다.

## API·권한·보안 경계

- 독립 도구: `POST /api/v1/tools/omr/preview/`,
  `POST /api/v1/tools/omr/pdf/`
- 시험 연결 화면: `POST /api/v1/exams/{examId}/omr/preview/`,
  `POST /api/v1/exams/{examId}/omr/pdf/`
- 테넌트·역할 권한과 시험 소유권은 백엔드가 최종 강제한다. 프론트엔드는
  기본 테넌트나 다른 시험으로 대체하지 않는다.
- HTML 미리보기는 script, 중첩 iframe, object, embed와 이벤트·javascript
  속성을 제거한 정적 `srcDoc`으로만 표시한다. PDF 파일 내용과 이름은 기존
  안전 다운로드 경계를 사용한다.

## 반응형 미리보기 계약

답안지의 정본 크기는 A4 가로 `297mm × 210mm`다. 미리보기 iframe도 이
고정 크기로 렌더링하고 바깥 프레임이 사용 가능한 폭보다 작을 때만 전체를
동일 비율로 축소한다. 따라서 답안지 내부에 별도 가로·세로 스크롤을 만들지
않으며, 축소는 화면 미리보기에만 적용되어 PDF 크기와 마킹 좌표를 바꾸지 않는다.

980px 초과에서는 설정과 미리보기를 두 열로, 그 이하에서는 한 열로 배치한다.
1100·1366px 데스크톱과 390px 모바일에서 문서 전체 overflow가 없어야 하며,
좁은 화면에서도 설정 아래의 전체 답안지와 다운로드·새로고침 버튼에 접근할 수
있어야 한다.

모바일 스크린샷을 확인한다. 변경 시 `pnpm typecheck`, 해당 파일 lint,
`pnpm build`도 함께 통과시킨다.
