# OMR 답안지 생성기

서술형 문항이 있으면 독립 생성기에서 연속 번호와 **서술형 별도 번호**를 선택한다.
시험에 연결된 생성기는 시험 운영 설정의 값을 보여 주며 HTML 미리보기와 PDF에
같이 적용한다. 번호 설정이 잘못되면 서버가 요청을 거부하므로 선택을 고쳐
다시 미리보기·다운로드한다. 버블 위치와 채점용 문항 번호는 바뀌지 않는다.

## 목적과 진입점

관리자와 허용된 교직원은 `/workspace/tools/omr`에서 시험에 연결되지 않은
OMR 답안지를 만들 수 있다. 시험 답안 등록 화면도 같은
`OmrSheetBuilder`를 사용하되 시험 ID와 문항 구성을 백엔드 기본값에서 받는다.
백엔드의 테넌트 로고, 답안지 HTML·PDF 렌더링과 인식 좌표 계약은
`backend/docs/domain/omr.md`가 소유한다.

## 사용자 흐름과 상태

1. 시험명, 강의명, 차시명을 입력한다.
2. 객관식만, 혼합형, 서술형만 중 구성을 고르고 허용 범위 안에서 문항 수를
   입력한다. 객관식 전용 답안지는 문항 수가 허용할 때 서술형 풀이 공간을
   표시하거나 숨길 수 있다.
   시험 답안키의 비객관식 문항은 정답 형식과 관계없이 번호가 붙은 빈 서술형
   작성칸으로 출력한다. 종이 답안지에는 `0~999` 숫자 버블을 만들지 않으며
   모든 서술형 작성칸은 AI 인식·자동판정 대상에서 제외한다.
3. 입력이 바뀌는 즉시 이전 답안지를 지우고 짧은 대기 후 현재 구성의 미리보기를 요청한다.
   이전 요청이 늦게 도착해도 새 구성에는 표시하지 않는다. `미리보기 새로고침`을 누르면
   예약된 요청을 즉시 실행하고, 오류 후에도 같은 입력으로 다시 시도할 수 있다.
4. 미리보기 대기 중에도 `OMR PDF 다운로드`는 현재 값으로 서버 PDF를 만들고 완료 또는
   실패 피드백을 표시한다.

문항 합계가 0이면 미리보기와 다운로드를 막는다. 미리보기 요청 중에는 로딩
문구를, 초기·빈 상태에는 준비 안내를 표시한다. 미리보기 실패는 정적 일반 오류
문서로 대체하고 내부 오류나 서버 응답 본문을 노출하지 않는다. PDF 실패도
일반 사용자 문구만 표시하며 입력값은 보존한다.

### 서술형 교사 채점란 (Beta)

시험 안의 OMR 답안지와 독립 생성기 모두 서술형 문항을 포함하면
**답안 영역 → 서술형 교사 채점란 (Beta) → 사용**을 선택할 수 있다.
켜면 서술형 문항 오른쪽에 객관식과 같은 규격의 `012 / 345 / 678` 배점 버블을 인쇄한다.
선생님이 0~8점은 해당 숫자 하나를, 9점 이상은 합이 되는 숫자를 칠한다. 예를 들어
15점은 7과 8을 칠한다. 빈칸은 미입력이다. 소수나 36점을 넘는 점수는 채점표에서
직접 입력한다. 문항별 점수 입력을 쓰고 서술형 배점을 지정한 시험에서는
스캔 후 **문항별 점수 입력**에서 제안을 확인하고 확정한다.
설정은 `GET/PATCH /api/v1/exams/{examId}/omr/essay-score-marks/`가 소유하며 다음 인쇄물부터
적용된다. 끄기 전에 이미 인쇄한 답안지는 문항 배치가 그대로라면 계속 스캔할 수 있다.
저장 중에는 PDF 다운로드가 기다리고, 저장 후에는 미리보기와 PDF가 같은 선택을 사용한다.
독립 도구와 스캔 설정을 사용할 수 없는 시험에서는 이번 출력물에 수기용 버블을 넣는다.
이 선택은 화면을 닫으면 초기화된다. 수기용 답안지에는 스캔 제안용 배치 표식을 인쇄하지 않는다.
조회 실패 시 화면에서 다시 불러올 수 있고, 설정 저장 실패 시 재시도하거나 이번 출력에만 적용할 수 있다.
지원 범위를 넘는 문항 배치는 서버가 인쇄 요청을 거부한다. 채점표 동작은
[채점·오답노트 계약](GRADING-WRONG-NOTE-WORKFLOW.md#omr-교사-채점란-beta), 좌표·판독
정책은 `backend/docs/domain/omr.md` "서술형 교사 채점란 (Beta)"가 소유한다.
격리 개발 canary는 로그인과 재접속에서 교사 역할을 확인한 계정으로
시험 화면에서 다운로드한 PDF를 실제 스캔·채점에 사용하고,
390px 독립 생성기에서 수기용 미리보기와 PDF 다운로드를 검증한다.

## API·권한·보안 경계

- 독립 도구: `POST /api/v1/tools/omr/preview/`,
  `POST /api/v1/tools/omr/pdf/`
- 시험 연결 화면: `POST /api/v1/exams/{examId}/omr/preview/`,
  `POST /api/v1/exams/{examId}/omr/pdf/`,
  `GET/PATCH /api/v1/exams/{examId}/omr/essay-score-marks/` (Beta, 교사·관리자만 변경)
- 테넌트·역할 권한과 시험 소유권은 백엔드가 최종 강제한다. 프론트엔드는
  기본 테넌트나 다른 시험으로 대체하지 않는다.
- HTML 미리보기는 script, 중첩 iframe, object, embed와 이벤트·javascript
  속성을 제거한 정적 `srcDoc`으로만 표시한다. PDF 파일 내용과 이름은 기존
  안전 다운로드 경계를 사용한다.

## 반응형 미리보기 계약

답안지의 정본 크기는 A4 가로 `297mm × 210mm`다. 미리보기 iframe도 이
고정 크기로 렌더링하고 바깥 프레임이 사용 가능한 폭보다 작을 때만 전체를
동일 비율로 축소한다. 따라서 답안지 내부에 별도 가로·세로 스크롤을 만들지
않으며, 축소는 화면 미리보기에만 적용되어 PDF 크기와 마킹 좌표를 바꾸지 않는다.

980px 초과에서는 설정과 미리보기를 두 열로, 그 이하에서는 한 열로 배치한다.
1100·1366px 데스크톱과 390px 모바일에서 문서 전체 overflow가 없어야 하며,
좁은 화면에서도 설정 아래의 전체 답안지와 다운로드·새로고침 버튼에 접근할 수
있어야 한다.
