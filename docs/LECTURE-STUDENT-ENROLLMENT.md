# 강의에 기존 학생 직접 등록

강의 상세 → 수강생 등록은 학원의 기존 학생 선택 명단을 바로 연다.
교직원은 차시·엑셀 없이 여러 학생을 선택하고 `N명 강의에 추가`로 저장한다.
학생 검색은 이름·학교·전화번호를 사용하며 전화번호의 공백·하이픈을 정규화한다.
이름이 같은 학생은 학교·학년·학생/학부모 연락처로 구분한다.

- 검색과 페이지 이동 중에도 선택 명단을 유지한다. 현재 페이지 선택은 해당
  페이지의 미등록 학생만 추가한다. 하단 선택 목록에서 개별/전체 해제한다.
- 기존 ACTIVE 수강생은 `등록됨`으로 표시하고 중복 선택하지 못한다.
  INACTIVE/PENDING 학생은 재등록/등록 대기로 구분하며 명시적 선택 시 ACTIVE로
  전환한다. 한 번에 최대 200명을 처리하고 초과 선택을 알린다.
- 엑셀은 별도 보조 동작으로 유지한다. 학생 선택 중 닫기·엑셀 이동은 미저장
  선택 취소를 확인한다. 등록 중 닫기·중복 제출을 막는다.
- 조회 실패는 빈 목록과 구별하고 재조회한다. 저장 또는 저장 확인 실패는 선택을
  보존하고 재시도를 제공한다. 성공 전 전체 수강 명단을 재조회해 선택한 학생의
  ACTIVE 상태를 확인한다. 강의 명단·인원·학생 목록 캐시를 갱신한다.

## API와 데이터 경계

`GET /students/`의 페이지 목록과 `GET /enrollments/?lecture=...`의 전체 명단을
사용하고, `POST /enrollments/bulk_create/`에 `{lecture, students}`를 보낸다.
기존 학원·교직원 권한 검증과 삭제 학생 차단, 수강료·첫 계정 안내 정책을 유지한다.
강의 수강만 저장하며 차시·차시 배정·출결은 만들지 않는다. 이후 각 차시의
`강의 수강생 불러오기`에서 출결 대상을 선택한다.
백엔드 정책: [학생 생명주기](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/student-lifecycle.md).

기존 방식 선택 화면의 차시 생성 유도는 직접 선택 UI로 대체했다. 차시 생성은
원래 강의의 수업 추가에서 계속 제공하며 기존 수강/차시/출결 데이터는 변경하지 않는다.

## 접근성·검증

키보드 체크박스, 검색 라벨, 선택 상태 안내, 저장 오류 안내, 모달 포커스 유지와
이탈 복귀를 제공한다. 390px에서 연락처를 다음 줄에 배치하고 명단·선택 목록을
독립 스크롤한다. 선택 칩의 짧은 전환은 reduced-motion에서 끈다.

`e2e/admin/lecture-student-picker.mock.spec.ts`는 1366/1100/390px 등록, 페이지·검색
선택 유지, 활성 중복 제외와 재등록, reload, 저장 확인 실패/재시도, 이탈 취소,
200명 한도를 검사한다. 기존 Excel 회귀도 같은 등록 버튼에서 시작한다.
`student-parent-learning-realuse.spec.ts`는 격리 개발 환경에서 차시 없는 강의에
UI로 학생을 등록하고 reload 및 이후 교사·학생·학부모 학습 화면까지 확인한다.

강의 상세 명단은 출결 matrix의 기존 차시 이력과 ACTIVE 강의 수강 명단을 학생 ID로
합쳐 표시한다. 차시 미배정 학생도 저장·reload 후 보이며 출결은 빈 값으로 유지한다.
기존 차시 이력은 제거하지 않는다. 출결 엑셀 다운로드는 기존 차시 출결 내보내기다.
