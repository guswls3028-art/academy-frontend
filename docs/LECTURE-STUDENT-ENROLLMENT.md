# 강의에 기존 학생 직접 등록

강의 상세 → 수강생 등록은 학원의 기존 학생 선택 명단을 바로 연다.
교직원은 차시·엑셀 없이 여러 학생을 선택하고 `N명 강의에 추가`로 저장한다.
학생 검색은 이름·학교·전화번호를 사용하며 전화번호의 공백·하이픈을 정규화한다.
이름이 같은 학생은 학교·학년·학생/학부모 연락처로 구분한다.
선택 화면은 학생의 실제 이름을 그대로 표시하며 페이지별 임시 번호를 붙이지 않는다.
키보드/스크린리더에서도 학교·연락처 설명으로 동명이인을 구분할 수 있다.

- 검색과 페이지 이동 중에도 선택 명단을 유지한다. 현재 페이지 선택은 해당
  페이지의 미등록 학생만 추가한다. 모두 선택한 페이지는 같은 버튼으로 해당
  페이지만 해제할 수 있다. 하단 선택 목록에서 개별/전체 해제한다.
- 기존 ACTIVE 수강생은 `수강 중`으로 표시하고 중복 선택하지 못한다.
  INACTIVE/PENDING 학생은 재등록 대상/등록 대기로 구분하며 명시적 선택 시 ACTIVE로
  전환한다. 한 번에 최대 200명을 처리하고 초과 선택을 알린다.
- 엑셀은 별도 보조 동작으로 유지한다. 학생 선택 중 닫기·엑셀 이동은 미저장
  선택 취소를 확인한다. 등록 중 닫기·중복 제출을 막는다.
- 조회 실패는 빈 목록과 구별하고 재조회한다. 저장 또는 저장 확인 실패는 선택을
  보존하고 재시도를 제공한다. 서버가 등록을 승인한 뒤 확인만 실패했다면 선택을
  고정하고 `등록 결과 다시 확인`으로 읽기만 재시도하며 등록 요청을 반복하지 않는다.
  성공 전 전체 수강 명단을 재조회해 선택한 학생의 ACTIVE 상태를 확인한다.
  확인된 명단은 즉시 반영하고 강의 인원·출결·학생 목록은 백그라운드 갱신한다.
  느린 주변 화면 조회 때문에 등록 완료를 지연시키지 않는다.
- 한글 조합 종료·Enter·추가 클릭을 기다리지 않고, 화면에 표시된 검색어의 입력이
  250ms 멈추면 검색한다. 마지막 한글 음절이 조합 중이어도 결과를 볼 수 있다.
  검색 대기/페이지 전환 중 이전 목록은
  선택할 수 없으며 검색 중임을 표시한다. 이전 검색 요청을 취소하고 30초 이내
  재방문한 학생 페이지는 캐시를 사용한다. 수강 상태는 별도로 최신 조회한다.
  격리 개발 실사용의 `student-parent-learning-realuse.spec.ts`도 390px·데스크톱에서
  조합 종료 전 실제 검색 응답을 확인하고, 등록·새로고침·학생/학부모 학습 화면까지 이어서 검사한다.
  학생 검색 실패는 이미 선택한 학생의 등록을 막지 않으며, 수강 상태 조회 실패는
  재조회 후 등록한다. 검색어 지우기는 검색창 포커스를 유지한다.

## API와 데이터 경계

`GET /students/`의 페이지 목록과 `GET /enrollments/?lecture=...`의 전체 명단을
사용하고, `POST /enrollments/bulk_create/`에 `{lecture, students}`를 보낸다.
기존 학원·교직원 권한 검증과 삭제 학생 차단, 수강료·첫 계정 안내 정책을 유지한다.
강의 수강만 저장하며 차시·차시 배정·출결은 만들지 않는다. 이후 각 차시의
`강의 수강생 불러오기`에서 출결 대상을 선택한다.
백엔드 정책: [학생 생명주기](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/student-lifecycle.md).

기존 방식 선택 화면의 차시 생성 유도는 직접 선택 UI로 대체했다. 차시 생성은
원래 강의의 수업 추가에서 계속 제공하며 기존 수강/차시/출결 데이터는 변경하지 않는다.

## 접근성·검증

키보드 체크박스, 검색 라벨, 선택 상태 안내, 저장 오류 안내, 모달 포커스 유지와
이탈 복귀를 제공한다. 390px에서 연락처를 다음 줄에 배치하고 명단·선택 목록을
독립 스크롤한다. 명단 높이를 남은 공간에 맞춰 검색창·선택 요약·저장 버튼을 유지한다.
선택 전후 요약 높이를 일정하게 해 화면이 밀리지 않게 한다. 낮은 창/가상 키보드에서는
본문 스크롤로 모든 항목에 접근한다. 선택 칩의 짧은 전환은 reduced-motion에서 끈다.

`e2e/admin/lecture-student-picker.mock.spec.ts`는 1366/1100/390px 등록, 페이지·검색
선택 유지, 활성 중복 제외와 재등록, reload, 저장 확인 실패/재시도, 이탈 취소,
200명 한도, 한글 조합/느린 응답/캐시, 검색 실패 중 저장, 지연된 출결 갱신,
낮은 모바일/다크 테마와 이름·전화번호 명단 검색을 검사한다.
기존 Excel 회귀도 같은 등록 버튼에서 시작한다.
`student-parent-learning-realuse.spec.ts`는 격리 개발 환경에서 차시 없는 강의에
UI로 학생을 등록하고 reload 및 이후 교사·학생·학부모 학습 화면까지 확인한다.
이 합성 QA 시나리오의 390px·데스크톱 스크린샷은 `development-release-evidence`
산출물에 정확한 파일명으로 보존해 동일 배포 후보의 화면을 검토한다. 운영 학생
정보나 다른 실사용 시나리오의 스크린샷을 이 업로드에 포함하지 않는다.

강의 상세 명단은 출결 matrix의 기존 차시 이력과 ACTIVE 강의 수강 명단을 학생 ID로
합쳐 표시한다. 차시 미배정 학생도 저장·reload 후 보이며 출결은 빈 값으로 유지한다.
기존 차시 이력은 제거하지 않는다. 출결 엑셀 다운로드는 기존 차시 출결 내보내기다.
강의 명단의 전화번호 검색은 숫자·공백·괄호·하이픈 입력에만 적용한다. 한글 이름이나
숫자를 포함한 이름이 빈 전화번호 검색 조건으로 전체 학생과 일치하지 않도록 한다.
명단에 표시된 동명이인 구분명도 검색할 수 있다.
