# 강의 순위 · 명예의 전당

## 목적과 사용자

원장·선생님이 여러 차시(주차)를 묶어 학생 순위를 확인하고, 상위 학생을 교실에
게시할 A4 **명예의 전당**으로 출력한다. 예: 1~4주 종합 순위로 상품 대상 선정,
매주 시험 1~3등·1~5등·1~10등 게시.

## 진입

- **강의 상세 헤더 → 순위·명예의 전당** (`/workspace/lectures/:lectureId/rankings`)
- **차시 성적 → 도구 → 명예의 전당**: 현재 차시 하나와 `시험` 기준을 미리 선택한
  `?from=<sessionId>&to=<sessionId>&scope=exam`으로 이동한다.

URL의 `from`·`to`·`scope`(`all`|`exam`|`homework`)는 새로고침·공유 시 같은 선택을
복원한다. 알 수 없는 값은 오늘 이전의 마지막 차시와 `종합`으로 대체한다.

## 흐름과 계산

1. 시작·끝 차시와 기준(종합·시험·과제)을 고른다. 범위는 한 번에 최대 20개 차시다.
2. 각 차시의 기존 성적 API(`GET /results/admin/sessions/{id}/scores/`)를 차시 성적
   화면과 같은 query key로 불러온다. 진행 수(`n/m차시`)를 표시한다.
3. 학생별로 서버가 계산한 차시 합계 `exam_total`·`homework_total`을 더한다.
   차시 성적의 **합산 설정**에 포함된 시험·점수형 과제만 반영되며, 서버 합계가 이미
   결시·서술형 대기·임시 점수를 0점으로 세지 않으므로 프론트가 다시 판정하지 않는다.
4. 순위는 합산 점수 내림차순, 동점은 같은 등수인 표준 공동 순위(`1, 2, 2, 4`)다.
   표시 순서의 동률은 이름·수강 ID로 고정한다. 확정 점수가 하나도 없는 학생은 등수
   `-`로 맨 아래에 둔다. 표에는 합산/만점과 반영 평가 수(미반영 수)를 함께 보여 준다.

## 명예의 전당 출력

- **1~3등 / 1~5등 / 1~10등** 중 선택한다. 공동 등수는 모두 포함한다(예: 공동 3등 2명).
- **점수 표시**를 끄면 이름과 등수만 출력한다. 기본값은 표시다.
- 미리보기는 A4 세로 iframe이며 **인쇄**는 같은 문서를 브라우저 인쇄로 보낸다.
  인원이 적을수록 큰 카드, 많을수록 촘촘한 목록으로 자동 조절한다.
- 출력물에는 강의명, 기간(예: `1차시 ~ 4차시`), 기준, 출력일만 넣는다. 학생 ID·연락처
  등 내부 정보는 넣지 않는다.

## 상태와 복구

- 차시 목록 로딩/실패(다시 시도)/차시 없음, 성적 로딩, 일부 차시 실패(실패한 차시만 다시
  시도), 20개 초과(범위 축소 안내), 확정 점수 없음 상태를 각각 표시한다.
- 확정 점수가 없거나 로딩·실패 중에는 출력 버튼을 비활성화한다.
- 이 화면은 조회 전용이며 성적을 쓰지 않는다. tenant·권한 경계는 기존 성적 API가 소유한다.

## 반응형·접근성

- 600px 이하에서 선택 필드는 한 줄씩 전체 폭으로 쌓이고, 표는 카드 안에서만 가로 스크롤한다.
- 기준·등수 선택은 `aria-pressed` 토글이며 키보드로 조작한다. 출력창은 Esc로 닫는다.
- 진입·출력창은 짧은 opacity/transform 전환을 쓰고 `prefers-reduced-motion`에서 끈다.

## 검증

- 정적: `pnpm typecheck`, `pnpm lint`, `pnpm build`
- 계산 규칙: `periodRanking.ts`의 공동 순위·미반영·범위 합산
- 실사용: 격리 개발 환경에서 차시 2개 이상에 시험·과제 점수를 넣은 뒤 범위·기준 변경,
  새로고침 복원, 출력 미리보기, 데스크톱 1366/390px 표시를 확인한다.
