# 설문·성적 취합 화면

## 진입과 역할

교직원은 학생 관리의 **설문·성적취합** 탭(`/workspace/students/surveys`)에서 설문을 만들고 응답을 모은다. 학생·연결된 학부모는 제출 화면의 설문 진입 또는 `/student/surveys`에서 응답한다. 학생별 설문 이력은 학생 상세의 **설문으로 받은 정보**에서 읽는다.

서버의 권한·대상 고정·동시성·데이터 보존은 [backend surveys.md](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/surveys.md)가 소유한다. 기존 성적표 제출 화면을 임베드해 원본/점수를 등록하고 교직원 확인 후 통계에 반영한다. 공통 메모를 자동 덮어쓰지 않는다.

## 정상 흐름

1. 일반 설문/성적 취합/학생 메모를 선택하고 제목, 안내, 전체 또는 개별 학생, 질문을 작성한다. 기간·정원·첨부는 접힌 추가 설정에서 연다.
2. 설문을 저장해 내용을 확인한 뒤 **응답 시작**을 누른다. 최초 시작 시 대상이 고정되며 이후 질문·대상·시험 설정은 변경하지 않는다.
3. 대상 학생 또는 명시적으로 선택한 자녀의 학부모가 응답한다. 성적 취합은 이전 성적표를 선택하거나 같은 화면에서 새 원본과 점수를 제출한 뒤 **응답 제출**로 끝낸다.
4. 저장 성공 상태, 학생 이름, 답변, 원본, 현재 검수 상태를 확인한다. 기간 내 다시 수정할 수 있고 새로고침 후에도 저장된 응답이 유지된다.
5. 교직원은 전체/응답 완료/미응답 목록, 선택형 통계, CSV와 원본을 확인한다. 학생별 상세 기록에도 같은 답변이 표시된다. 마감 후에도 조회와 내보내기는 가능하다.

학생 링크는 기존 로그인이 필요하다. 로그인 없는 공개 식별 경로나 자동 알림톡을 제공하는 것처럼 표시하지 않는다. 링크 복사 실패 시 화면에 실제 링크를 남겨 직접 복사할 수 있게 한다.

## 첨부 내보내기

학생별 원본 다운로드는 기존 인벤토리 presign을 사용한다. 교직원 응답 목록의 **현재 목록의 첨부 묶음 받기**는 학생명·학생ID 폴더로 ZIP을 만든다. 현재 페이지의 자료를 50MB·20개 이하의 묶음으로 나누고 다음 페이지 자료는 해당 페이지에서 받는다. 파일명 경로 문자를 제거하며 파일ID를 붙여 동명이인·동일 파일명을 보존한다.

묶음 준비 중 진행 표시와 취소를 제공한다. 하나라도 읽기 실패·크기 변경·시간 초과가 발생하면 불완전한 ZIP을 저장하지 않고 같은 묶음을 재시도할 수 있게 한다. CSV는 엑셀에서 열 수 있으며 서버의 수식 주입 방지 처리를 사용한다.

## 실패·복구와 반응형

- 응답 초안은 공통 `useDurableDraft`로 학원·로그인 사용자·학생·설문별 저장소에 최대24시간 보관한다. 이어쓰기/버리기, 다른 탭 충돌, 저장 실패 재시도를 제공하고 저장 성공 후 지운다. 다른 자녀로 전환해도 응답 요청은 해당 화면의 명시적 학생ID를 사용한다.
- 연결 오류·필수 질문·정원·마감·버전충돌은 입력을 유지하고 원인을 표시한다. 저장된 최신 응답/설문을 불러올 때만 작성 내용을 교체할지 확인한다.
- 파일 여러 개 중 일부 업로드 실패 시 성공한 파일을 유지하고 실패 파일을 다시 선택할 수 있다. 업로드 중에는 응답 완료를 누를 수 없다.
- 생성 재시도는 같은 요청 키를 사용하고, 응답 재시도는 서버의 동일 내용 확인으로 중복을 만들지 않는다.
- 390px에서는 질문·설정이 한 열로 바뀌고 버튼 줄바꿈, 긴 이름, 오류 문구, 표 대신 응답 목록을 유지한다. 키보드 focus, 상태 live region, reduced-motion을 지원한다.

검증은 교직원 생성/배포와 학생·학부모 응답, 저장 후 재조회, 원본·CSV/ZIP, 마감/충돌 복구, PC·390px의 오버플로를 포함한다. 라우트 모의 검증은 격리 개발의 실제 저장·권한·원본 검증을 대체하지 않는다.

`e2e/flows/survey-collection.realuse.spec.ts`는 동일 산출물 격리 개발 검증 목록에 등록한다. 실제 교직원 UI 생성/배포, 학부모 자녀 전환, 학생 성적표 제출, 재조회, R2 원본 ZIP 바이트 일치와 학생 상세 기록을 확인한다. 가족 정리는 응답·첨부를 지우고, 남은 설문 ID를 정리 영수증에 기록한다. 최종 잔여 0 확인은 기존 실행기의 해당 `qa-*` 테넌트 전체 정리가 담당한다.
