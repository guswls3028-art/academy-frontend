# 신과함께 공개 홈페이지

## 목적과 사용자 흐름

`godmin.kr`의 공개 첫 화면은 통합과학 강사 신민 선생님의 수업 철학과 학습
관리 방식을 학생·학부모에게 설명하고, 기존 수강생을 신과함께 학습
플랫폼으로 연결한다. 비로그인 사용자는 `/`에서 `/landing`으로 이동하며,
상단·히어로·마지막 CTA의 로그인 링크는 모두 `/login/godmin`을 사용한다.
전용 도메인에서는 기존 로그인 라우터가 `/login`으로 주소를 정리하며,
신과함께 테넌트와 로그인 화면은 새로고침 후에도 유지한다.

전용 페이지는 `src/landing/pages/GodminLandingPage.tsx`가 소유한다. 다른
테넌트의 설정 기반 공개 랜딩은 기존 `PublicLandingPage`를 그대로 사용한다.
godmin 전용 화면은 공개 랜딩 설정 API의 게시 여부와 무관하게 렌더링되어,
설정 미게시 상태에서도 홈페이지가 로그인 화면으로 되돌아가지 않는다.

## 정보 구조와 표현 계약

페이지는 다음 순서를 유지한다.

1. 통합과학 강의 경력과 대치동 현장 강의를 요약한 히어로와 대표 영상
2. 최근 공개 영상 네 편과 영상 모아보기
3. 물리·화학·생명·지구과학을 잇는 통합과학 지도
4. 이해 → 적용 → 복습의 학습 루프
5. 교재 연구와 학생 질문을 잇는 연구실 소개
6. 신민 선생님 프로필과 공개 근거 링크
7. 수강생·학부모 로그인 CTA

지정 게시자가 대표 영상을 공개하면 히어로 오른쪽에 영상 카드가 나타난다.
PC의 두 열 폭과 모바일 Safari 글꼴 폭에 맞춰 메인 제목 크기를 제한하고, 제목과 소개 문장의 한국어 어절을 유지한다. PC/390px 영상 히어로 테스트에서 강조 문구가 한 줄로 유지되는지 확인한다.
대표가 없으면 기존 인물 사진·궤도·과학 라벨을 유지한다. 링크 등록, 두 지정 계정의
관리 권한, 초안/공개, YouTube 재생과 공유는 [홈페이지 영상 계약](PUBLIC-VIDEOS.md)이 소유한다.

브랜드 색은 짙은 잉크 그린, 민트, 옅은 프로스트, 포인트 코럴을 사용한다.
인물 사진 주위의 궤도와 네 과학 영역 라벨이 전용 시각 서명이다. 장식은
콘텐츠 판독과 CTA보다 앞서지 않으며 `prefers-reduced-motion: reduce`에서는
모든 애니메이션을 사실상 제거한다. 390px에서는 공통 헤더의 주요 메뉴와 브랜드,
로그인, 본문, CTA를 유지하고 가로 스크롤을 만들지 않는다.
모바일 마지막 CTA 제목은 한글 어절을 보존해 마지막 글자만 별도 줄로
떨어지지 않도록 한다. 강사 소개와 출처 설명도 한국어 어절을 보존하며,
공백 없는 긴 문자열은 화면 밖으로 넘치지 않도록 마지막 수단으로 줄바꿈한다.

## 콘텐츠와 사진 출처

공개 프로필은 2026-10-15에 공식 강사진·학원 원문·방송사 보도·당사자 인터뷰를
확인해 갱신했다. 강의 분야와 학생 관리, 교재 연구와 학생 소통을 중심으로 소개한다.
본문의 출처 카드에는 자료 종류와 보도/게시일, 마지막 확인일을 표시한다.

- [두각 공식 강사진](https://dugak.net/info/teacher.do):
  통합과학·화학 담당, 대성마이맥 강의 및 두각 출강 프로필
- [명인학원 마포캠퍼스 공식 강좌 안내](https://mp.myunginedu.co.kr/branch/classinfo_detail.php?a_serial=4208&mode=read&page=4):
  2026-06-14 게시. 자체 교재, 주차별 자료/테스트, 홈페이지 결과 확인과 연구실 클리닉.
  과거 특강의 수업 구성 자료로 연결하며 현재 모집 중이라는 의미로 표시하지 않는다.

- [iMBC `구해줘! 홈즈` 소개](https://enews.imbc.com/News/RetrieveNewsInfo/457287):
  2025년 소개 당시 13년 차 통합과학 강사, 대치동 연구실의 교재 연구와 학생 질문 공간
- [르무통 인터뷰](https://m.lemouton.co.kr/article/%EB%A5%B4%EB%AC%B4%ED%86%B5-%EC%97%A0%EB%B2%84%EC%84%9C%EB%8D%94/18/78433/):
  2023-10-10 브랜드 인터뷰. 화학교육 전공과 뮤지컬 무대 경험, 학생과의 교류에 대한
  본인의 설명 및 기존 공개 프로필 사진. 대학명·학위·성과 수치는 추정하지 않는다.

2025년 보도의 `13년 차`는 해당 시점의 소개로만 표시하고 현재 경력 연수로
자동 환산하지 않는다. 출처의 `NO.1`, 성적 상승/수강생 수 등 홍보성 수치를
객관적 순위나 성과 보장으로 전재하지 않는다. 기존 강남대성 출강 강조는
두각의 현재 공식 소개에서 직접 확인할 수 있는 강의 분야와 대치동 현장 강의로
대체했다. 기사 본문·사진을 새로 복제하지 않고 짧은 자체 요약과 원문 링크를 사용한다.
영상 제목·소개·분류 등 게시자가 저장한 데이터는 이 정적 프로필 갱신의 대상이 아니다.

페이지의 공개 근거 링크는 새 탭에서 열고 `rel="noreferrer"`를 사용한다.
프로필 사진은 `public/tenants/godmin/landing-portrait.webp`가 소유하며 사진
바로 아래에 르무통 인터뷰 출처 링크를 표시한다. 운영자가 승인된 새 사진으로
교체할 때는 같은 파일 경로와 대체 텍스트를 유지해 레이아웃·접근성 계약을
보존한다.

## 검색·공유 메타데이터

초기 HTML, Cloudflare Functions 호스트 메타, 테넌트 레지스트리와 SPA
페이지 메타는 아래 값을 같은 의미로 유지한다.

- 제목: `신민T 통합과학 | 신과함께`
- 설명: 대치동 통합과학 강사 신민T의 수업 철학, 학습 관리와 수강생·학부모
  전용 플랫폼
- 대표 이미지: `/tenants/godmin/og-image.png`

SPA 진입 전에도 호스트별 제목·설명·파비콘·OG 값이 노출되고, 페이지가
마운트되면 현재 URL을 `og:url`로 반영한다.

## 실패 안전과 검증

- godmin 전용 페이지는 공개 랜딩 설정 API를 호출하지 않는다.
- 외부 프로필 링크나 Instagram이 실패해도 본문과 로그인 경로는 유지된다.
- 공통 메뉴에서 홈 섹션으로 이동할 때 대표 영상과 영상 목록의 첫 요청이 성공 또는
  실패로 끝난 뒤 앵커 위치를 맞춘다. 비동기 영상 높이 변경으로 목표 제목이 밀리는
  상황을 방지하며 같은 섹션 메뉴를 다시 누르는 경우에도 이동한다.
- 인물 사진에는 설명 가능한 대체 텍스트가 있고, 키보드 포커스는 모든 링크에
  보이는 외곽선을 제공한다.
- 로그인·약관·개인정보처리방침은 기존 제품 라우트를 재사용한다.

로컬 검증은 production build/preview를 우선 사용한다.

```powershell
pnpm typecheck
pnpm lint
pnpm build
$env:E2E_LANDING_BASE_URL = "http://127.0.0.1:4174"
pnpm exec playwright test e2e/godmin-landing.mock.spec.ts --project=chromium --workers=1 --retries=0
pnpm exec playwright test e2e/pwa-branding-contract.spec.ts e2e/root-routing-contract.spec.ts --project=chromium --workers=1 --retries=0
```
