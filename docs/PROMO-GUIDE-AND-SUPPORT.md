# 홍보 페이지 사용 가이드와 시작 안내

`/promo` 방문자는 프로그램을 계약하기 전에 역할별 사용 방법, 이용 시작 시 지원,
전화 문의 방법과 예정 기능을 확인한다. 홍보 콘텐츠는 테넌트 운영 데이터와 분리한다.

## 홈과 기능 소개

- 홈은 짧은 소개와 실제 프로그램 화면, 주요 기능 6개, 기능 상세 가이드,
  요금·이용 안내, 자주 묻는 질문과 문의 순서다. 반복되던 업무 흐름·도입 권유와 기관 로고 홍보 구역은
  기능을 찾는 데 집중하도록 홈에서 제거했다. 기능 자체와 상세 경로, 기존 자료는 유지한다.
- 주요 기능은 학생·수업, 시험·성적, 수업 영상, 알림톡, 칠판용 PPT·매치업,
  학원 홈페이지다. 각각 기존 설명 페이지 또는 해당 기능 위치로 이동한다.
- 홈과 기능 소개의 **기능 상세 가이드**는 `/promo/features/tour`로 이동한다.
  홈의 **43쪽 상세 가이드 보기**는 `guideBook=detail&guidePage=1`로 바로 연다.
  읽기 위치, 확대, 이미지 실패 시 재시도·글 안내, PDF 다운로드 계약은 유지한다.
- 시연 신청 폼으로 가는 링크는 **시연 신청**으로 표시한다. 클릭만으로 화면을
  볼 수 있는 링크와 구분하며, 문의·시연 신청의 필드·동의·접수 API는 변경하지 않는다.
- 헤더와 하단의 인스타그램 링크는 `https://www.instagram.com/hakwon_p/`를
  새 창으로 연다. `noopener noreferrer`와 새 창 안내를 제공하며, 로그인이나
  외부 페이지 로딩 여부에 관계없이 기존 프로모 페이지에서 계속 탐색할 수 있다.
  주소와 계정명은 `src/app_promo/domains/landing/business.ts`가 소유한다.
- 흰 바탕, 낮은 채도의 강조색, 짧은 제목으로 기능을 설명한다. 헤더 색 전환,
  홈의 배경 장식·과도한 강조는 제거했다. 링크와 메뉴 조작의 피드백, 키보드
  포커스와 모션 감소 설정은 유지하며 desktop/390px에서 가로 넘침을 확인한다.
- 변경 범위는 공개 홍보 화면이다. 테넌트 접근 제한, 업무 권한, 사용자 데이터와
  저장 API에는 변경이 없다. 홈 구역 제거에 따른 데이터 이관은 필요 없다.

## 전체 사용 가이드

### 읽기 부담과 질문 동선 (2026-10-27 보강)

- 기능 소개는 업무별 핵심 기능을 먼저 표시한다. 반복되던 대형 화면 소개는 각 업무의
  **실제 화면 보기**에, 사용 단계는 **사용 순서 보기**에 모았다. 자료와 기능은 제거하지 않는다.
  세부 화면 가이드는 해당 책의 관련 쪽으로 바로 연결한다. 학생/수업·성적·영상·알림톡·홈페이지·
  클리닉·PPT/매치업·학부모 상담의 기존 hash와 별칭을 유지한다. `alimtalk-guide` 직접 진입과
  reload는 해당 설명을 자동으로 펼친다. 현재 경로와 관계없는 특정 기능 강조는 제거했다.
- 주요 메뉴에 **자주 묻는 질문**을 배치한다. 활용 사례는 기능 소개와 하단에서 계속 접근한다.
  FAQ는 요금/시작/기능으로 분류하고 질문을 펼치면 짧은 답변과 관련 화면 링크를 제공한다.
  기존 FAQ의 가격·지원 범위·자료 이전·권한·상담 내용을 유지하며 요금 답변은 `business.ts`의
  같은 상수를 참조한다. 답변 원본은 `promoQuestions.ts`, 공통 표시는 `PromoQuestions`가 소유한다.
  질문 ID hash는 직접 접속/reload 시 자동으로 펼친다. 키보드 Enter/Space와 기본 details 동작을 유지한다.
- 홈에서 부가세 포함 결제금액과 기본 용량, 별도 협의 항목을 먼저 확인할 수 있다. 요금 페이지는
  신규 가입 결제금액 198,000원, 공급가 180,000원과 VAT 18,000원을 한 번씩 명확히 표시한다.
  별도 비용은 펼치지 않아도 보인다. 종료된 8월 신규 혜택의 조건은 기존 가입자용 펼침 영역으로
  옮겼으며 `#existing-contract`로 직접 열 수 있다. 145,000/14,000/159,000의 고정 세액과 지속
  적용 조건, 기능/계정/용량/이전 정책은 변경하지 않는다. 비교 차액의 반복 홍보만 제거했다.
- 역할별 사용 가이드의 이미지 설명서는 기본적으로 접어 검색과 업무 목록을 먼저 찾게 한다.
  기존 `guideBook`/`guidePage`가 포함된 주소는 책을 자동으로 열며, 읽던 위치·역할·검색·주제의
  URL 계약은 그대로다. 전체 이미지 설명서는 `/promo/features/tour`에서도 항상 접근할 수 있다.
- 후속 리뷰에서 가이드를 닫은 뒤 책/쪽의 뒤로가기·앞으로가기가 숨겨진 상태로 남는 문제를 수정했다.
  책/쪽 URL이 바뀌면 해당 설명서를 다시 펼친다. 검색어만 바꿀 때에는 사용자가 닫은 상태를 유지한다.
  기능 메뉴는 기존 별칭 링크와 **그 밖의 운영 기능**에도 현재 위치를 표시한다. 높이가 낮은 PC에서는
  메뉴 안에서 스크롤해 모든 항목을 선택할 수 있고 키보드 포커스도 가려지지 않는다. 모바일은 기존 줄바꿈 목록을 유지한다.
  섹션 링크의 초기 위치 보정은 유지하되, 사용자가 휠·터치·포인터·키보드를 조작하면 남은 보정을 취소해
  읽으려고 이동한 위치를 되돌리지 않는다. 경로 변경 시 입력 리스너와 예약 보정도 정리한다.
- 공개 문서 탐색만 변경한다. 업무 API, 인증·권한, 저장 데이터와 문의 접수 계약은 동일하다.
  새로운 영속 데이터나 이관은 없다. 모든 펼침은 기본 HTML controls로 작동하며, 설명서 이미지
  오류는 기존 가이드의 재시도와 글 안내로 복구한다. 짧은 펼침/화살표 피드백은 모션 감소를 존중한다.
- 검증은 기존 프로모/가이드/가격 테스트와 함께 질문→설명→화면 가이드→뒤로가기/reload,
  신규/기존 가격 및 세액, 이미지 책 직접 링크, 수납 검색, 키보드 펼침과 390/1100/1366px를 확인한다.

- 상단·모바일 메뉴의 **사용 가이드**, 홈·요금의 **전체 사용 가이드 보기**는
  `/promo/guide`로 연결한다. 기존 `/promo/faq`는 도입 전 질문 페이지로 유지한다.
- Cloudflare Functions의 공개 경로 목록에도 `/promo/guide`를 등록해 직접 접속과
  새로고침을 허용한다. 서버 응답의 제목·설명·canonical과 운영 sitemap에 같은 경로를
  제공한다. 읽던 위치의 query는 유지하며, 등록되지 않은 홍보 경로는 계속 404로 거부한다.
- 관리자·선생님 / 직원·강사 / 학생을 선택하면 프로그램 내 가이드와 동일한
  전체 원문을 읽는다. 축약본을 별도로 복사하지 않는다.
- 원문은 `src/shared/ui/guide/content/`의 역할별 데이터가 소유한다. 기존 앱의
  데이터 경로는 re-export로 호환한다. 프로그램 내 가이드 계약은
  [IN-APP-GUIDE.md](IN-APP-GUIDE.md)를 따른다.
- `GuideCatalog`의 기본 `app` 모드는 기존 실행 링크를 유지한다. `public` 모드는
  설명·준비·단계·완료·복구·다음 안내를 동일하게 제공하면서 로그인 후 이용하는
  업무 화면 실행 링크를 노출하지 않는다. 익명에게 업무 권한을 부여하지 않는다.
- `role`, `q`, `category`, `topic`을 URL에 보존하여 reload/back으로 이어 읽는다.
  검색 직후 즉시 안내를 선택해도 이전 렌더의 검색조건으로 덮어쓰지 않도록
  이벤트 처리에서는 BrowserRouter가 반영한 현재 주소를 기준으로 변경한다.
  역할을 바꾸면 검색·분류·선택 주제를 초기화해 다른 역할의 같은 ID와 혼동하지 않는다.
  없는 역할은 관리자 가이드로 표시하고 없는 주제/검색 결과는 전체 보기·검색 초기화로 복구한다.
- 정적 원문을 사용하므로 가이드 조회에 인증·업무 API나 서버 저장은 필요 없다.
  페이지 로딩·자산 오류 복구는 기존 PromoRouter의 lazy loading 계약을 따른다.
  같은 원문 목록의 검색 색인은 재사용하여 입력·주제 선택마다 모든 단계 문장을 다시 조합하지 않는다.
- 공개 가이드 본문 끝의 **이 기능 문의하기**는 `/promo/contact`로 바로 연결한다.
  `guideRole`, `guideTopic`에는 정적 역할·주제 ID만 전달하며 검색어나 개인정보는 붙이지 않는다.
  문의 화면은 정적 원문에 실제 존재하는 조합만 제목으로 해석한다. URL의 임의 제목·외부
  주소·없는 ID는 사용하지 않는다. 정상 조합은 기능 문의와 수정 가능한 본문으로 처음 한 번
  채우고, 입력 중 재렌더에서 덮어쓰지 않는다. 읽던 가이드로 돌아가는 내부 링크를 제공한다.

## 시작 지원과 상담

- 서비스 이용료 결제 후 사용 개시 시 개발자가 직접 프로그램 소개와
  직원·강사 대상 홈페이지 사용법 안내를 진행한다고 홈·요금·문의·데모·FAQ에 설명한다.
- 기존 상담 전화번호를 유지한다. 부재 시에는 **문자를 남겨주시면 확인 후 연락드리겠습니다**로
  안내한다. 확정되지 않은 상담 요일·시간·회신 기한이나 방문/원격 방식을 약속하지 않는다.
- 문의/데모 입력, 개인정보 동의, 접수, 오류 시 입력 유지 흐름은 기존 계약을 유지한다.
  이 변경은 신규 문자 발송 API나 자동 회신을 추가하지 않는다.
- 문의·데모는 사용자가 작성한 모든 필드를 먼저 조합한다. 공개 상담 API의 2,000자
  한도에서 유입 정보 전체가 들어갈 여유가 있을 때만 덧붙인다. 유입 정보 때문에 고객의
  질문을 잘라 접수하지 않는다. 사용자 필드 자체가 한도를 넘으면 전송 전에 안내하고 입력을
  유지한다. 정상 화면의 각 필드 최대 길이와 모든 관심 기능을 선택해도 사용자 내용은 들어간다.
- 전송 중 상태를 `aria-busy`로 알리고 오류는 alert와 포커스로, 성공은 결과 제목 포커스로
  전달한다. 오류 후 내용을 유지한 채 재전송할 수 있다. 서버 응답의 예상하지 못한 오류
  자료형은 일반 오류 문구로 복구한다. 익명 전송·동의 버전·테넌트/API 경계는 유지한다.

## 예정 기능 구분

원비·교재비 **온라인 결제**는 홈·요금·FAQ에 도입 예정이며 현재 미지원임을 명시한다.
서비스 이용료 결제 및 현재의 수납 기록 관리와 구분한다. 출시일·결제 수단·수수료를
임의로 제시하지 않는다. 현재 수납 기능의 정본은 [FEES-OPERATIONS.md](FEES-OPERATIONS.md)이다.

## 검증

`e2e/promo-navigation.spec.ts`와 `e2e/promo-business-readiness.spec.ts`는
홈 기능 링크, 상세 가이드 직접 진입·다음 기능 선택·reload, 인스타그램 새 창과
원래 페이지 유지, 모바일 메뉴 포커스·스크롤과 화면 너비를 검증한다.
인스타그램 응답만 mock하여 외부 로그인 상태에 의존하지 않는다.

`e2e/promo-guide.mock.spec.ts`는 PR route-mock gate에서 데스크톱과 390px의 익명
진입, 역할별 전체 목차, 원문 단계/완료/복구 표시, 키보드 선택, URL/reload,
역할 전환, 검색/없는 주제 복구, 내부 업무 링크 부재, 홈→가이드→FAQ와 상담
문구·예정 상태·가로 넘침을 확인한다. 화면 캡처는 해당 CI artifact에 보존한다.
가이드→기능 문의의 제목 전달·reload·변조된 ID 거부, 문의/데모 실패 후 입력 유지와
재전송 성공·포커스도 route mock으로 검증한다. `scripts/tests/promo-lead.test.mjs`는
필드 최대 길이·긴 유입 정보·동의 거부·API 한도 초과와 오류 자료형 경계를 검증한다.
실제 Cloudflare handler로 직접 접속 응답·메타데이터·query·끝 슬래시·sitemap과
미등록 경로 거부도 검증하여 로컬 SPA fallback만 통과하는 누락을 방지한다.
운영 반영은 동일 산출물 development-canary/cleanup zero와 운영 revision 확인 후
공개 페이지를 데스크톱·390px로 다시 확인한다.
