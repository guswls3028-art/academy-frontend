# 강의 목록과 기본정보 편집

관리자는 `/workspace/lectures`와 `/workspace/lectures/past`에서 강의를 찾고,
행의 설정 메뉴로 기본정보 수정·종료·복원·삭제를 수행한다. 담당 강사 선택과
데이터 변경 권한, tenant 경계는 기존 API가 판단한다.
강의·차시의 데이터 정책은 [backend 강의·차시](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/lecture-sessions.md),
종료 후 학생 표시 정책은 [학생 이름의 현재 강의 표시](STUDENT-LECTURE-STATUS.md)를 따른다.

## 목록에서 작업하기

- 제목은 강의 상세로 이동하는 링크다. 색상 딱지는 유지하며 긴 제목은 한 줄로
  줄이고 전체 제목을 접근 가능한 이름과 툴팁에 남긴다. 수강생 수는 장식 없는 숫자로 표시한다.
- 설정은 행에 붙은 드롭다운이다. 활성 강의는 수정·종료, 지난 강의는 복원·삭제를 제공한다.
  기존 중간 선택 모달은 클릭 단계와 큰 선택 카드의 시각적 부담 때문에 제거했다.
  API와 저장된 데이터에는 마이그레이션이 없다.
- 종료·삭제 확인창은 강의명을 표시한다. 종료는 이력을 유지하고 지난 강의로 이동하며,
  복원은 활성 목록으로 이동한다. 삭제는 관련 데이터 제거 경고와 서버의 보호 정책을 유지한다.
  확인/처리 중 중복 요청을 막고, 실패하면 오류 안내 후 같은 메뉴에서 다시 시도할 수 있다.
- 메뉴는 클릭·Enter·아래 방향키로 열며 Escape로 닫고 설정 버튼으로 초점을 돌린다.
  열 정렬은 키보드로 조작할 수 있다. 목록 로딩 실패에는 재시도, 검색 결과가 없으면 검색 초기화를 제공한다.
- 1100/1366px에서는 가용 표 너비를 사용하고 390px에서는 표 내부만 가로 스크롤한다.
  설정 메뉴는 화면 안에 배치하고, 상태 전환은 짧게 표시하며 reduced-motion을 존중한다.

## 수정과 저장

`GET /lectures/lectures/{id}/`의 제목·담당자·과목·설명·날짜·시간·색상·딱지를
모달을 열 때 최신 조회를 마친 뒤 한 번 채운다. 캐시가 있는 재진입에서도 초기화로 지우지 않으며,
편집 중 쿼리 갱신이나 강사 목록 갱신은 작성 중인 값을 덮어쓰지 않는다.
닫은 모달의 미저장 초안은 폐기하고 다음 열기에서 저장된 정보를 읽는다.
필수 조회가 실패하면 빈 편집 폼 대신 재시도를 제공한다.

입력 필드는 값이 있어도 라벨이 남는다. 시작일보다 이른 종료일은 저장하지 않으며,
종료일 지우기는 PATCH에 `end_date: null`을 명시한다. 저장 실패 시 입력값과 오류를
유지한다. 저장 중 닫기/중복 제출을 막고 성공하면 목록·상세·차시 및 학생 표시 캐시를 갱신한다.
등록은 기존 최종 확인 과정을 유지하고 수정은 변경한 정보를 바로 저장한다.

## 교사 강의 목록·상세

`/workspace/mobile/classes`는 교사의 PC·모바일 강의 진입점이다. 현재/지난 강의
선택(`tab=past`)과 강의명·과목·담당자 검색(`q`)을 주소에 유지해 상세 복귀와
새로고침에도 이어서 찾는다. 검색은 현재 가져온 목록 안에서 수행해 입력마다
API를 호출하지 않는다. 검색 결과가 없으면 검색 지우기를 제공한다.

강의 상세는 조회 실패 시 편집 화면을 열지 않고 재시도·강의 목록 이동을 제공한다.
차시 조회 실패도 실제 빈 목록과 구분하고 건수를 ‘확인 필요’로 표시한다. 성공 후
차시로 진입하거나 수강생을 확인할 수 있고, `tab=students`는 reload에도 유지한다.
권한·등록·삭제·출석 데이터와 API는 변경하지 않는다. 조회 정상화 뒤 기존 업무를
계속하며, 데이터 마이그레이션은 없다. 검색·추가·뒤로 이동은 44px 터치 영역과
명시적인 라벨을 사용하고 목록 반응 효과는 reduced-motion을 존중한다.

`e2e/teacher/lecture-navigation-recovery.mock.spec.ts`는 390/1366px에서 검색 중
추가 API 요청 없음, 상세 복귀·reload, 실패 재시도와 수강생 탭 복원을 검증한다.
