# 업무 화면 빠른 이동

## 목적과 진입점

빠른 이동은 관리자와 선생님이 긴 메뉴를 펼치지 않고 권한 안의 업무 화면으로
이동하는 공용 탐색 기능이다. 데이터 조회·저장 기능을 새로 만들지 않으며, 기존
라우트와 메뉴 권한을 더 짧은 동선으로 제공한다.

- PC 버전: 상단 **빠른 이동** 또는 `Ctrl+K`/`Cmd+K`, 모바일 폭에서는 전체
  메뉴의 **빠른 이동**
- 모바일 버전: 상단 돋보기 또는 `Ctrl+K`/`Cmd+K`

모바일 버전의 학원 브랜드 버튼이 홈 이동을 소유한다. 같은 홈으로 이동하던
별도 집 모양 버튼은 제거하고 그 자리를 빠른 이동에 사용한다.

## 검색과 이동 규칙

1. 처음 열면 현재 계정이 최근 사용한 내부 메뉴를 최대 4개 보여준다.
2. 검색어는 메뉴명, 업무 구역, 사용자가 자주 쓰는 표현을 함께 찾는다. 예를 들어
   `문자`는 메시지, `원생`은 학생, `점수`는 성적을 찾는다.
3. 데스크톱에서는 위·아래 화살표로 결과를 고르고 `Enter`로 이동한다. `Esc`는
   아무 이동 없이 닫는다.
4. 검색 결과는 `오늘 업무`, `수업 운영`, `자료·메시지`처럼 실제 메뉴 구역을 함께
   표시한다. 같은 목적지가 중복 등록돼도 한 번만 보인다.
5. 외부 링크는 최근 사용과 빠른 이동 대상에서 제외한다. 선택하면 기존 내부
   라우터로 이동하므로 새 권한이나 데이터 접근을 만들지 않는다.

## 권한과 저장 경계

- PC 버전은 사이드바와 같은 권한 필터를 사용한다. 직원 관리자, 학원
  관리자, 기능 플래그가 허용하지 않은 메뉴는 검색 결과에도 나타나지 않는다.
- 모바일 버전은 드로어와 빠른 이동이 한 메뉴 목록을 공유한다. 원장/관리자
  전용 수납·직원·학원 설정은 일반 직원에게 노출되지 않는다.
- 최근 사용에는 내부 메뉴 목적지만 저장한다. 학생명, 문서명, 검색어, 상세 ID는
  저장하지 않는다.
- 최근 사용 키는 업무 화면 종류, 테넌트 코드, 인증 사용자 ID로 분리한다. 다른
  계정이나 학원의 기록을 자동으로 가져오지 않는다.
- 브라우저 저장소가 차단되거나 손상되면 최근 사용만 초기화되고 검색과 이동은
  현재 세션에서 계속 동작한다.

## 화면과 접근성 계약

- 검색창은 열릴 때 자동으로 포커스를 받는다.
- 결과 행은 최소 58px, 390px 화면에서는 최소 62px의 터치 영역을 가진다.
- 선택·현재 화면·키보드 포커스는 색과 윤곽으로 함께 구분한다.
- 390px에서는 화면 폭 안의 하단 시트로 표시하고 결과 영역만 세로 스크롤한다.
- 열기 전환은 짧은 투명도·이동 효과만 사용하며 `prefers-reduced-motion`에서는
  제거한다.
- 결과가 없으면 다른 업무 표현으로 검색하라는 다음 행동을 안내한다.

## 분석과 검증

빠른 이동 결과는 기존 `data-analytics-destination` 계약을 사용한다. 배치는
`admin.quick-navigation`과 `teacher.quick-navigation`으로 구분되며, 별도 사용자
데이터를 전송하지 않는다.

```powershell
pnpm exec playwright test e2e/admin/workspace-quick-navigation.mock.spec.ts --project=chromium --reporter=list
pnpm guard:test-coverage
pnpm typecheck
pnpm lint
pnpm build
```

회귀 검증은 데스크톱 검색·키보드 이동, 새로고침 후 최근 사용 복원, 390px 버튼과
가로 넘침, 중복 홈 제거를 확인한다.

## 모바일 PC 버전 고급기능 허브

모바일 버전의 `PC 버전` 메뉴는 모바일 전용 구현이 없는 정적 고급 업무를
검색하고 카테고리별로 찾는 진입 허브다. 이 허브는 별도 업무 상태나 API를 만들지
않고 현재 실행 가능한 `/workspace` 목적지로 직접 이동한다. 따라서 이동한 뒤에도
각 PC 화면의 라우트 권한과 기능 플래그가 최종 접근 권한을 소유한다. 모바일 폭의
PC 화면에서는 기존 메뉴의 `모바일 버전` 버튼으로 모바일 홈에 돌아온다.

허브 노출도 같은 경계를 먼저 적용해 실패 시 숨긴다.

- 일반 학원 직원에게는 공용 학습·자료·도구 목적지만 노출한다.
- 홈페이지 관리 목적지는 학원장/관리자, 기능 플래그는 학원장만 노출한다.
- 직원 근태·급여 운영은 `/staffs/me/`의 `is_payroll_manager`가 확인된 경우만
  노출한다. 조회 실패나 미확인 상태에서는 숨긴다.
- 수납 목적지는 `useFeesEnabled`와 학원장/관리자 조건을 모두 만족해야 한다.
- 검색 결과가 없거나 유효한 학원 직원 역할이 아니면 다음 행동이 있는 빈 상태를
  표시한다. 카테고리와 모든 목적지는 키보드로 이동할 수 있다.

이 범위는 **정적 고급 라우트 패리티 1차분**이다. 학생 상세처럼 ID가 필요한 동적
흐름, 화면별 모바일 조작성 개선, 모든 PC 업무의 완전한 기능 패리티를 의미하지
않는다. 이후 도메인별 감사와 배치에서 별도로 검증한다.

```powershell
$env:E2E_BASE_URL="http://127.0.0.1:5174"
pnpm exec playwright test e2e/teacher/full-workspace-parity.mock.spec.ts --project=chromium --reporter=list
pnpm guard:test-coverage
pnpm verify:routes
pnpm typecheck
pnpm lint
pnpm build
```
