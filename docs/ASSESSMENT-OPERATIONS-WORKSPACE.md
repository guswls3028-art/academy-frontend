# 시험·과제 운영 준비 워크스페이스

## 목적과 사용자 흐름

관리자와 선생님은 **강의 → 차시 → 시험/과제**에서 평가를 선택한 뒤 운영에
필요한 정책, 문항·자료와 대상 학생을 한 화면에서 확인한다. 생성 모달의 일괄
생성, 이전 평가 가져오기와 현재 차시 수강생 자동 등록 흐름은 유지한다. 이
문서는 생성 이후 설정·대상자 UX를 소유한다.

화면 상단의 **운영 준비 점검선**은 현재 서버 데이터를 읽어 다음 상태를
계산한다. 별도 발행 상태를 저장하거나 레거시 `OPEN/CLOSED` 값을 해석하지
않는다.

- 시험: 점수 정책, 채점 방식, 학생 성적 공개, 문항·답안, 대상 학생
- 과제: 기본 정보, 점수 정책, 제출기한, 대상 학생

확인이 필요한 항목을 누르면 같은 화면의 소유 설정으로 이동한다. 경고는 운영
준비를 돕는 안내이며, 서버가 허용하는 저장을 프런트가 임의로 차단하는 새
비즈니스 상태가 아니다.

시험·혼합 채점의 저장 규칙은 백엔드
[`exam-grading.md`](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/exam-grading.md),
과제 점수 판정은
[`homework-grading.md`](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/homework-grading.md)가
소유한다.

## 시험 운영 설정

시험 설정은 다음 항목을 한 번의 `PATCH /exams/{id}/`로 저장한다.

- 만점과 합격 기준
- OMR 자동 채점, 직접 정오 입력, 직접 점수 입력, OMR+직접 채점
- 혼합형의 앞쪽 선택 문항 수와 나머지 문항 입력 방식
- 응시 시작·마감 시각
- 학생·학부모 성적 공개 또는 교직원 전용
- 정답 비공개, 마감 후 공개, 항상 공개
- 재응시 허용과 최대 응시 횟수

채점 방식 변경은 기존 문항·답안·성적을 삭제하지 않는다. 실제 문항이 생성된
혼합형 시험은 선택형 경계를 잠그고 이유를 표시한다. `마감 후 공개`는 마감
시각이 있어야 저장할 수 있고, 합격 기준은 만점을 넘을 수 없다. 과거 시험의
혼합형 경계가 0으로 남아 있어도 실제 문항이 선택형·답변형으로 함께 구성되어
있으면 문항 유형에서 경계를 복구해 저장한다. 문항 구성이 모두 한 유형이거나
조회에 실패한 경우에는 실행 불가능한 혼합형 전환을 비활성화한다. 만점·합격
기준처럼 필수인 숫자 입력을 비우면 0으로 변환하지 않고 저장을 막는다.

**학생 성적 공개**는 정답 공개와 별도다. 끄면 교직원의 채점·성적표·통계는 유지하고,
학생·학부모의 성적 목록·추이·분석·개별 결과에서만 점수와 문항 정보를 숨긴다. 상단
점검선은 현재 공개/비공개를 바로 표시하고 같은 설정으로 이동한다. 비공개 결과 화면은
미응시나 오류로 가장하지 않고 공개 전임을 안내하며, 재응시 가능 여부는 서버 응답을
계속 사용한다.

문항·답안은 기존 답안 등록 화면이 소유한다. 시험지 원본은 별도 **시험지
원본** 섹션에서 자산 API와 문항 분리 상태를 표시한다. **시험 자료 올리기**는
통합 문제+해설 HWP/HWPX, 문제 PDF/이미지, 문제 PDF/이미지+해설 HWP/HWPX를
한 진입점에서 받는다. 자동 분리 뒤에는
**문항·해설 맞춤 확인**이 문제 이미지와 선생님 원본 해설을 좌우로 보여준다.
번호 수정·수록/제외를 검수해 확정하기 전에는 채점 문항으로 사용하지 않는다. 재채점은 일반
설정에서 분리해 **다음 작업 → 고급 작업** 안에 둔다.

## 과제 운영 설정

과제는 과제명, 제출기한, 만점, 합격 기준과 퍼센트 반올림 단위를 한 화면에서
한 번의 `PATCH /homeworks/{id}/`로 저장한다. 제출기한은 기존
`meta.due_date`에 보존하며 다른 `meta` 값은 덮어쓰지 않는다.

개별 기준이 없는 과제는 차시 기본 기준을 표시한다. 제목 또는 제출기한만
바꿀 때는 변경한 필드만 전송하므로 차시 기본 기준을 그대로 상속한다. 만점이나
합격 기준을 직접 바꿔 저장할 때만 선택 과제의 개별 기준으로 고정된다.
퍼센트 기준은 0~100, 점수 기준은 0~과제 만점이며 최종 합불·클리닉 판정은
서버 응답을 사용한다. 제출기한을 비운 것은 누락이 아니라 **기한 없이 운영**
하는 유효한 준비 상태다.

시험·과제 설정을 편집한 뒤 다른 평가 또는 운영 탭으로 이동하면 미저장
내용을 버릴지 확인한다. 브라우저를 닫거나 새로 고침할 때도 기본 이탈 경고를
사용한다. 저장 요청은 처음 읽은 `updated_at`을 함께 보내며, 다른 선생님이
먼저 저장한 경우 현재 입력을 덮어쓰지 않는다. 사용자는 변경 안내에서 최신
설정을 불러온 뒤 다시 편집한다.

미저장 정책은 500ms 뒤 브라우저에도 임시 저장한다. 저장 키는 tenant 코드,
로그인 사용자 ID, 평가 종류와 평가 ID로 분리하고 서버에서 처음 읽은
`updated_at`을 함께 기록한다. 같은 계정·같은 평가라도 서버 버전이 달라졌거나
7일이 지난 초안은 자동 폐기해 과거 입력을 최신 설정 위에 되살리지 않는다.
유효한 초안은 자동 적용하지 않고 **이어서 편집**과 **초안 지우기**를 제공한다.
정상 저장 또는 최신 설정 불러오기 뒤에는 초안을 제거한다. 저장소 사용이
차단된 브라우저에서는 기존 이탈 경고만 유지한다.

지원되는 시험 수정 진입점은 모두 `X-Expected-Updated-At`을 필수로 보낸다.
여기에는 관리자 운영 설정, 성적표 시험 헤더 빠른 편집, 선생님 모바일 시험
관리와 클리닉의 재시험 허용이 포함된다. 빠른 단일 동작은 저장 직전에 최신
시험을 읽고 변경 필드만 전송하며, 폼 편집은 화면에 표시한 버전을 기준으로
저장한다. 이 규칙은 서버가 호환 목적으로 유지하는 무헤더 외부 클라이언트의
동작을 프런트 내부 경로가 우회하지 않게 한다.

## 대상 학생 관리

시험과 과제는 공용 대상자 편집기를 사용하지만 각 도메인의 API와 캐시 키는
유지한다.

- 후보는 현재 tenant와 차시의 활성 수강 등록으로 제한한다.
- 저장 식별자는 `student_id`가 아니라 서버가 준 `enrollment_id`다.
- 검색은 이름, 전화번호, 학교, 학년을 지원한다.
- 검색 결과 전체 선택·해제와 개별 선택을 지원한다.
- 우측에는 기존, 추가, 제외, 저장 후 인원을 표시한다.
- 편집기를 열 때 최신 후보와 선택 상태를 다시 읽고 완료 전에는 저장할 수
  없다. 조회에 실패하면 기존 목록을 참고용으로 유지하되 다시 불러오기 전까지
  저장을 막는다.
- 닫을 때 변경사항이 있으면 버릴지 확인하고, 저장 성공 뒤 서버 목록을 다시
  읽어 요약 인원을 갱신한다.

`현재 수강생 전체`는 현재 후보 ID를 완전 치환 요청으로 저장한다. 이후 차시
수강생 변경을 자동 동기화한다는 의미가 아니다. 과제 대상 제외가 클리닉
연결에 미치는 영향과 정본 처리는 백엔드 응답이 소유한다.

전체 일괄배정은 현재 인원, 저장 후 인원과 다시 포함되는 제외 학생 수를
확인한 뒤 실행한다. 시험 재채점도 기존 성적·통계·클리닉 판정에 미치는
영향을 확인한 뒤 요청한다.

기존 시험 전용·과제 전용 선택 모달 중 과제 복제본은 제거하고 공용 편집기로
대체했다. 저장된 시험 대상자와 과제 배정 행은 변경·이전·삭제하지 않는다.

## 로딩·실패·반응형

- 설정, 문항, 자료, 대상자 조회마다 로딩·실패 상태를 분리한다.
- 문항 조회 실패는 등록 필요로 가장하지 않고 **다시 불러오기**를 제공한다.
- 저장 실패는 편집값을 유지하고 서버 오류를 표시한다.
- 1366px·1100px에서는 점검선을 4열로, 좁은 화면에서는 2열과 1열로
  재배치한다.
- 대상자 편집기는 데스크톱에서 명단과 변경 요약을 나란히, 760px 이하에서
  세로로 배치한다.
- 모든 선택 카드와 점검 항목은 키보드 포커스를 표시하고, 모션 감소 설정에서는
  전환 애니메이션을 제거한다.
