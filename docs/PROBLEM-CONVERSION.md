# 시험지 변환 화면 계약

## 목적과 진입

학원 staff가 PDF·이미지 시험지를 올리고 원본 대조, 문항 수정, 한글 다운로드를
한 흐름에서 끝낸다. `/workspace/tools/problem-studio`는
`ConversionStudioPage`를 사용한다. [GhostWriter 가이드](https://ghostwriter.solutions/guide)의
작업 구성을 Academy의 로그인·테넌트·AI 연결 안에 적용한다.

기존에 분산돼 있던 작업을 새 변환, 최근 작업, 완료 목록, 설정으로 재구성한다.
기존 원본 이관·Beta 해설·재작성·개인 글꼴·문서 스타일·브라우저 초안은 삭제하지
않는다. 설정의 `이전 도구 및 문서 스타일 열기`는
`/workspace/tools/problem-studio/legacy`로 연결된다. 기존 API와 저장 키를 유지하며
문제 리뷰 리포트는 별도 도구로 남는다.

## 흐름과 상태

공식 development canary의 `problem-conversion-realuse.spec.ts`는 합성 PDF를 실제
AI worker로 처리하고 수정 제안·저장·HWPX 세 종류·원본 다운로드·desktop/390px
재진입을 확인한다. 다운로드/그림은 인증된 응답에서 받은 개발 버킷의 정확한
tenant/conversion 경로와 900초 서명만 허용하며, runner의 QA tenant 정리 대상이다.

1. PDF/PNG/JPG/WebP를 선택하거나 끌어놓는다. 파일당 120MB, 총 512MB,
   최대 40개다. 이름·과목, 문제지만/해설까지/꼼꼼하게, 그림 다시 그리기를
   선택한다. 여러 PDF는 서로 다른 시험지/같은 시험지 사본을 구분한다.
   일부 파일만 시작됐으면 성공한 작업을 목록에 남기고 미시작 파일만 유지한다.
2. 외부 AI·글로벌 처리·마스킹 안내에 동의해야 시작한다. 동의를 기본값으로
   저장하지 않는다. 원본 확인 → 글·그림 옮기기 → 검사·검수 → 문서 만들기 →
   마무리를 서버 단계로 표시한다. 브라우저를 닫아도 작업은 계속된다.
3. 결과는 원고본/배열본/평가원 A3, 확인할 문항, 문항 목록 순서다. 원본 ZIP도
   내려받을 수 있다. 사용자
   클릭으로만 다운로드하며 URL을 갱신한다. 현재 수정본과 산출물 버전이
   다르면 다시작성을 안내하고 오래된 파일을 최신 결과로 제공하지 않는다.
4. 문항을 열면 원본 페이지와 편집기를 나란히 본다. 원본 페이지 선택, 그림
   영역 드래그/백분율 입력, 문항·보기·정답·해설 편집을 제공한다. 편집 영역을
   벗어나거나 저장을 누르면 서버에 저장한다. 실패 시 입력을 보관한다.
   동시 수정 충돌은 최신 내용과 비교한 뒤 다시 저장하며 자동 덮어쓰지 않는다.
   장시간 검수 중에는 10분마다, 화면 복귀 시에도 이미지 서명을 갱신한다.
   서버 버전이 달라졌으면 입력을 유지하고 최신 내용 비교를 안내한다.
5. 그대로 둠/모두 그대로 둠은 교사 확인이다. AI로 고치기, 다시 분석, 그림
   다시 그리기는 제안을 만들고 교사가 적용/유지를 선택한다. 제안의 확인 필요
   사유를 함께 표시하며 적용 후에도 기존 사유와 함께 보관한다. 수정하면
   미검수로 돌아가고, 한글 문서 다시작성으로 산출물에 반영한다.
6. 설정은 계정·테넌트별 브라우저 기본값이다. 기본 수준, 그림 다시 그리기,
   2차 검수 후 문서 만들기를 저장한다. AI는 Academy에 설정된 연결을 쓰며
   개인 키를 브라우저에 받지 않는다. 기존 개인 글꼴·문서 스타일을 재사용한다.

## 경계와 복구

데이터/API 정책은 [backend owner](https://github.com/guswls3028-art/academy-backend/blob/main/docs/domain/problem-conversion.md)가 소유한다.
원본·문항 정본·이력은 서버에, 기본값만 브라우저에 저장한다. 작성자와 테넌트가
일치해야 접근 가능하다. 저장되지 않은 입력이 있으면 작업/문항 이동과
새로고침에 경고한다. 실패한 작업은 저장된 페이지/문항 단계부터 재개한다.

그림 재구성은 흑백 도형·한글 라벨의 검수용 결과이며 과학적·배치 무손실을
보장하지 않는다. 배열본은 네 문항마다 쪽을 나누며 긴 문항을 자르지 않는다.
A3는 세로 2단이다. Windows 앱의 업데이트·로컬 폴더 열기·개인 API 키 설정은
웹 기능으로 복제하지 않는다. 원본/오류를 외부 지원 서버로 자동 전송하지 않는다.

## 검증

1366px/390px의 업로드, 진행, 검수 저장, 재생성, 다운로드, 재조회, 실패 후
재개, 가로 넘침은 `e2e/admin/problem-conversion.mock.spec.ts`에서 검사한다.
기존 도구 계약은 `e2e/problem-studio-ai-typing.spec.ts`의 legacy 경로로 유지한다.
390px에서는 메뉴를 상단에 두고 원본/편집기를 세로로 쌓는다. label/focus,
키보드 조작, 상태 알림, reduced-motion을 유지한다.
Mock 검증은 실제 AI 품질·Hancom 조판·개발 및 운영 runtime 확인을 대신하지 않는다.
실사용 검증은 PDF/JPEG에서 보존한 JPEG와 PNG 원본 미리보기를 모두 읽는다.
검증 경계는 작성자 API 응답의 정확한 테넌트·변환·파일·900초 서명과 MIME,
실제 이미지 바이트를 대조한다. 기존 JPEG의 `.png` 이름도 저장된 MIME으로 읽으며
다른 테넌트, HTML 응답, 자격증명이 포함된 이미지 요청은 계속 거부한다.
