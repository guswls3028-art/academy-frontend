# AI 작업 상황판

`/dev/agent-sessions`는 1번 테넌트 admin97 개발자 본인의 Codex·Claude 작업
현황을 확인하는 읽기 전용 화면이다. 개발자 콘솔의 **분석과 시스템 → AI 작업
상황판**에서 진입한다. 다른 계정에는 메뉴를 표시하지 않으며 직접 진입도
거부한다. 최종 권한 검사는 서버가 수행한다. 지원 미리보기·대리 로그인으로
이 계정의 이름을 갖게 되어도 API는 접근을 허용하지 않는다.

- 상단에서 세션 수, 하위 에이전트 수, 작업 중·대기·응답 완료·중단/종료·확인
  필요 상태를 본다. 상태별 수에는 두 종류가 모두 포함된다.
- 진행 중인 하위 에이전트를 가진 묶음을 먼저 보여준다. 조직도는 실제 부모
  ID로만 연결한다. 상위 기록이 없으면 이를 표시하며 임의의 담당자를 만들지
  않는다. 세션 이름을 선택하면 담당 역할·상위·하위 수·시각·상태 근거를 본다.
- 제공자, 상태, 이름/역할로 필터링한다. 일치하는 하위 항목의 상위 경로는
  맥락을 위해 유지한다. 기본 목록 20묶음 이후는 명시적으로 더 본다.
- ‘응답 완료’는 마지막 응답이 끝났다는 뜻이다. 업무·배포 성공으로 해석하지
  않는다. 오래되거나 불완전한 로컬 기록은 ‘확인 필요’로 남는다.
- 보이는 화면은 30초마다 GET으로 갱신하고 숨겨진 화면에서는 주기 조회를
  중지한다. 90초 이상 오래된 자료나 조회 실패는 연결 끊김과 마지막 수집 시각을
  표시한다. 실패를 정상 0건으로 바꾸지 않으며 기존 자료는 마지막 기록으로
  명시한다. 새로고침·실패 후 다시 불러오기로 복구한다.
- 각 제공자의 수집 실패, 아직 연결된 자료 없음, 정상 빈 목록, 검색 결과 없음,
  표시 한도를 구분한다. 대화 본문·도구 실행 내용·인증정보는 응답에 포함되지
  않는다. 실행·중지·명령 전달·작업 수정 기능은 없다.

잘못된 개별 Claude 레코드는 정상 Codex·Claude 기록을 지우지 않는다. 일부 레코드
수집 실패는 제공자별 불완전 경고로 표시하고, 원본이 복구되면 다음 수집에서
해제된다. 수집 실패 때문에 읽을 수 있는 항목이 하나도 없을 때는 정상 0건 요약을
표시하지 않고 기록 확인 실패와 새로고침 복구 안내를 표시한다.

1366px에서는 조직도와 담당 상세를 나란히, 390px에서는 한 열과 접이식 조직도를
사용한다. 상태는 색과 문구를 함께 제공하고 키보드·reduced-motion을 지원한다.
API·수집·저장소·권한·복구의 소유 문서는
[`backend/docs/domain/agent-session-board.md`](../../backend/docs/domain/agent-session-board.md)다.
